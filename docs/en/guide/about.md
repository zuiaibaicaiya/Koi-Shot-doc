# About Us

koiShot is a cross-platform (Windows / macOS / Linux) capture tool with annotation, pin-to-desktop, long screenshots, GIF and MP4 recording, and local offline OCR and table recognition — all local, no ads, watermarks or sign-in.

## Reporting Issues

When reporting an issue in the group, please include:

1. A screenshot or screen recording of the problem;
2. Your OS (Windows / macOS / Linux) and koiShot version;
3. Steps to reproduce, so we can locate it faster.
