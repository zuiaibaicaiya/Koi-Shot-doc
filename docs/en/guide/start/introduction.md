# Introduction

**koiShot** is a cross-platform desktop screenshot and pin tool for Windows, macOS and Linux. Beyond regular screenshots, it combines annotation, screen pinning, scrolling capture, OCR, table recognition (screenshot to Excel) and GIF recording in one app — all recognition runs locally, no network required.

## Key Features

| Feature | Description |
| --- | --- |
| Capture | Multi-screen capture, region selection, square selection, UI-element highlight & click-to-select, magnifier color picking |
| Annotation | Rectangle, ellipse, arrow (8 styles), pen, highlighter, text, numbered badge, mosaic, Gaussian blur |
| Output | Copy to clipboard, save to file, pin to desktop |
| Pin | Keep a screenshot on top of your desktop; zoom, adjust opacity, keep annotating |
| Long screenshot | Scroll and auto-stitch for web pages, chats and long lists |
| GIF recording | Record a selected region; frame & pixel limits keep files small |
| OCR | Local PaddleOCR engine, row-numbered results, one-click copy |
| Table recognition | Screenshot to editable grid, export to xlsx / CSV / TSV |
| Extras | Global hotkeys (customizable), system tray, light/dark theme, English & Chinese UI |

## Use Cases

- **Communication**: annotate a problem and paste straight into chat or tickets.
- **Tutorials**: numbered steps, arrows and text for quick how-tos.
- **Data reuse**: capture a table, recognize it, export to Excel.
- **Reference**: pin a screenshot on the desktop while working elsewhere.
- **Demonstration**: short GIFs for feedback and docs.

## Requirements

| Platform | Requirement |
| --- | --- |
| Windows | Windows 10 or later |
| macOS | Screen Recording permission required (see [FAQ](/en/guide/faq)) |
| Linux | X11 session (global hotkeys unavailable on Wayland) |

## Three Steps to Start

1. Press `F1` — start a capture;
2. Select a region, then click Copy / Save / Pin;
3. Press `Alt + Q` — show or hide the main window.

See the [shortcut reference](/en/guide/shortcuts) for the full list — all hotkeys are customizable.
