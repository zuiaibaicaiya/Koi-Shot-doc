# Introduction

## What is koiShot

**koiShot** is a small capture tool for your computer, on Windows, macOS and Linux. It does more than take a picture: mark up the important part, pin it next to your work, capture a whole page, record a demo, copy text out of an image, turn a table into Excel, or read a foreign-language screen — all in one app. Text and table recognition run **on your machine**: no network, no account, no image uploads.

Once installed it only leaves an icon in the system tray / menu bar — no window sitting around. You start a capture from the tray, a hotkey or a shortcut, without interrupting what you are doing.

## What it helps you do

| What you want | Use |
| --- | --- |
| Capture a region and mark the important bit | Capture + nine annotation tools (pen, arrow, mosaic, text, numbered badges…) |
| Work while looking at a reference | Pin: keep a screenshot on top, zoom it and fade it |
| Capture a whole page or chat log | Long screenshot: scroll and get one stitched image |
| Show someone how something works | GIF (a few seconds, loops) or MP4 recording (with audio, up to 10 minutes) |
| Copy text you cannot select | OCR, copy everything or just one line |
| Understand a foreign UI or error | Screenshot translation, image and translation side by side, switch languages any time |
| Turn a table screenshot into Excel | Table recognition, export `.xlsx` / `.csv` |
| Read a QR code | QR decoding, content straight to the clipboard |

The UI comes in Chinese and English with light / dark themes, all 5 global hotkeys can be rebound, and updates install themselves.

## When it comes in handy

- **Everyday communication**: mark the problem area and paste it into chat or a ticket.
- **Tutorials & docs**: number, arrow and label steps to build an illustrated guide quickly.
- **Data entry**: screenshot a table → editable grid → export to Excel, no retyping.
- **Clipping**: long screenshots for whole pages, OCR for text inside pictures.
- **Foreign content**: select a foreign UI, error or paper excerpt and get the translation.
- **Reference while working**: pin an image to a corner of the screen.
- **Demos**: GIF for a short interaction, MP4 when you need narration or audio.

## System requirements

| Platform | Good to know |
| --- | --- |
| Windows | Windows 10 or later (video capture needs 1903+); per-user install by default, no admin rights |
| macOS | Grant Screen Recording on first use and Accessibility for UI-element highlight; macOS asks for the microphone when you record with audio (denial just means no sound). Video recording needs macOS 12.3+ — see the [FAQ](/en/guide/faq) |
| Linux | A `.deb` package is provided; hotkeys need an X11 session (Wayland is not supported yet), and it starts at login after install |

Only **screenshot translation** needs your own Alibaba Cloud machine translation AccessKey and network access (setup: [Screenshot translation](/en/guide/features/translate)). Text, table and QR recognition are fully local — no account needed.

## Three moves to get going

1. Press `F1` — start a capture;
2. Select a region, then click Copy / Save / Pin on the toolbar;
3. Press `Alt + Q` — show or hide the capture overlay (press again to cancel).

See [Shortcuts](/en/guide/shortcuts) for the full list; all hotkeys can be rebound. Language and theme live under Settings → General — switching language restarts the app, while the theme applies instantly.
