# Annotation

## Tools

| Tool | Usage |
| --- | --- |
| Pen | Freehand drawing; color, size and opacity adjustable |
| Rectangle / Ellipse | Drag to draw; selectable, resizable and movable afterwards |
| Arrow | Drag to draw; use the dropdown beside the button to pick one of 8 arrow styles |
| Highlighter | Semi-transparent highlighting |
| Mosaic / Blur | Paint over sensitive areas; only brush size applies |
| Text | Click to place, type away; `Ctrl + Enter` to commit, `Esc` to cancel; scroll wheel while editing adjusts the stroke width |
| Number badge | Click to place an auto-incrementing badge; the dropdown sets the start number and toggles auto-increment |

## Property Panel

Selecting most tools shows a panel with three rows: **color** (9 swatches), **width** (4 steps) and **opacity** (5%–100% slider). Mosaic and blur show only the width row.

## Editing

- Click an existing shape (rectangle, ellipse, arrow, badge) to select it;
- Drag the eight outer handles to resize, or drag the shape to move it;
- Annotations are strictly clipped to the selection, so exports never lose a corner.

## Undo / Redo

`Ctrl/Cmd + Z` to undo, `Ctrl/Cmd + Shift + Z` to redo. Number badges stay consistent: undoing rewinds the counter instead of skipping numbers.
