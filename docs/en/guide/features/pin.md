# Pin to Desktop

A pin keeps a screenshot as an **always-on-top floating window** — ideal for referencing an image while working elsewhere.

## Create a Pin

- Click "Pin" on the capture toolbar;
- Press `Alt + P` (capture then pin);
- Or choose "Capture & pin" from the tray menu.

## Pin Window

| Action | Effect |
| --- | --- |
| Drag | Move the pin |
| Mouse wheel | Zoom (0.3–4.0x) |
| `Alt` + wheel | Adjust opacity (5%–100%) |
| Right-click menu | Copy, save, close and more |

The pin window includes the **full annotation toolbar** (including highlighter), so you can keep adding arrows, text and badges directly on the pin.

## Right-click Menu

Right-click a pin to access all pin actions:

| Menu item | Effect |
| --- | --- |
| Copy | Copy the pin (with annotations) to the clipboard |
| Save original | Save the screenshot **without** annotations |
| Save annotated image | Save the final image **with** annotations |
| Hide / Show toolbar | Collapse or restore the annotation toolbar on the pin |
| Hide / Show shadow | Toggle the drop-shadow frame around the pin |
| Close | Close this pin |

Saved files follow the shared naming rules — see [Saving & Output](/en/guide/features/output).

## Close

Right-click → Close, or press `Esc` while the pin is focused.

:::tip
Use "Save annotated image" to share the marked-up version and "Save original" to keep a clean copy — one pin, two deliverables.
:::

:::tip
Lower the pin's opacity with `Alt` + wheel to see what is underneath without moving it.
:::
