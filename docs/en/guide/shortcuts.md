# Shortcuts

## Global

Available system-wide (customizable in Settings → Hotkeys — see [Settings & Tray](/en/guide/settings) for rebind details):

| Shortcut | Action |
| --- | --- |
| `F1` | Capture |
| `Alt + S` | Capture and save |
| `Alt + P` | Capture and pin |
| `Alt + Q` | Show / hide main window |

## During Capture

| Key | Action |
| --- | --- |
| Drag | Select region |
| `Shift` + drag | Square selection |
| Click | Select highlighted UI element |
| `Enter` | Run default action (copy / save / pin) |
| `Esc` | Cancel |
| `Ctrl/Cmd + Z` | Undo annotation |
| `Ctrl/Cmd + Shift + Z` | Redo annotation |

## Text Editing / Pin

| Key | Action |
| --- | --- |
| `Enter` | New line (text editing) |
| `Ctrl + Enter` | Commit text |
| `Esc` | Discard edit |
| Wheel | Adjust stroke width (text editing) / pin zoom (0.3–4.0x) |
| `Alt` + wheel | Pin opacity (5%–100%) |
