# 设置与托盘

打开设置：托盘图标右键菜单 →「设置」，或按 `Alt + Q` 呼出主窗口进入。设置窗口侧栏底部会显示当前版本号。

## 通用设置

| 设置项 | 说明 |
| --- | --- |
| 界面语言 | 中文 / English，默认跟随系统；切换后 koiShot **自动重启**以应用新语言 |
| 界面主题 | 跟随系统 / 浅色 / 深色，切换即时生效 |
| 保存路径 | 截图默认保存位置（默认为「图片」下的 `koiShot` 文件夹），点「浏览」修改 |
| 保存后打开文件夹 | 开启后，保存成功自动打开文件所在文件夹（默认关闭） |
| GIF 体积预设 | 高质量 / 均衡（默认）/ 小体积（详见[GIF 录制](/zh/guide/features/long-capture-gif)） |
| GIF 帧率 | 5–30 帧/秒（默认 15），帧率越高越流畅、文件越大 |
| OCR 自检 | 一键检查识别模型与运行环境；可打开模型目录 |

## 快捷键设置

「设置 → 快捷键设置」中可查看并修改全部全局快捷键（各快捷键的默认值与作用见[快捷键总表](/zh/guide/shortcuts)）：

1. 点击要修改的快捷键右侧「编辑」；
2. 直接按下新的组合键；
3. 确认后**立即生效**，无需重启。

若新组合已被其他功能占用（如「截图」「贴图到桌面」），会明确提示冲突，换一个组合即可。组合键也可能被系统级快捷键（如 macOS 的 `Cmd + Shift + 3/4/5`、Windows 的 `Win + Shift + S`）或其他常驻软件的全局热键占用。

**改键后不生效？** 部分软件（游戏、远程桌面、虚拟机等）会以独占方式截获按键，导致全局热键收不到，可换一组按键或关闭相应软件后重试。

**macOS 上 `F1` 这类功能键冲突？** `F1`–`F12` 默认是亮度、音量等系统功能键，如需用作快捷键，请在「系统设置 → 键盘」中开启「将 F1、F2 等键用作标准功能键」，或改用包含 `Ctrl` / `Alt` / `Shift` 的组合。

:::tip
建议使用包含 `Ctrl` / `Alt` / `Shift` 的组合，避免与系统或其他软件的快捷键冲突。
:::

## 系统托盘

koiShot 启动后常驻系统托盘，托盘图标：

- **左键单击**：直接开始截图；
- **右键菜单**：

| 菜单项 | 作用 |
| --- | --- |
| 截图 | 开始截图 |
| 截图并保存 | 截图后直接保存到设置中的保存路径 |
| 贴图到桌面 | 截图并贴图 |
| 显示/隐藏窗口 | 呼出或隐藏主窗口 |
| 设置 / 关于 | 打开设置或关于页 |
| 退出 | 完全退出程序 |

## 关于 AI 功能

koiShot 预留了 AI 图像编辑与视觉问答能力（支持阿里云百炼、火山引擎服务商，可在设置中配置 API Key、模型与代理）。该入口当前处于隐藏状态，普通用户无需关心；后续版本启用时会在此文档同步说明。
