# 设置与托盘

打开设置：**托盘图标右键菜单 →「设置」**。设置窗口侧栏底部会显示当前版本号。

侧栏共四页：**通用设置 / 快捷键设置 / 标注设置 / 关于**。设置窗口不是置顶窗口，被其他窗口挡住时，再从托盘菜单点一次「设置」即可把它唤到最前。

## 通用设置

| 分区 | 设置项 | 说明 |
| --- | --- | --- |
| 语言设置 | 界面语言 | 中文 / English，默认跟随系统；切换后 koiShot **自动重启**以应用新语言 |
| 外观 | 界面主题 | 跟随系统 / 浅色 / 深色，切换即时生效，所有窗口同步换肤 |
| 截图保存路径 | 保存路径 | 截图、长截图、GIF、录屏、表格导出的统一落点，默认为系统「图片」下的 `koiShot` 文件夹，点「浏览」修改 |
| 截图保存路径 | 保存后打开文件夹 | 开启后，保存成功自动打开文件所在文件夹（默认关闭） |
| GIF 录制 | 体积预设 | 高质量 / 均衡（默认）/ 小体积，详见[GIF 录制](/zh/guide/features/long-capture-gif#gif-录制) |
| GIF 录制 | 帧率 | 5–30 帧/秒（默认 15），帧率越高越流畅、文件越大 |
| 录屏（MP4） | 帧率 | 10–30 帧/秒（默认 30） |
| 录屏（MP4） | 麦克风 | 「录制时采集麦克风声音」，默认开启；关闭或未授权时录成无声视频 |
| OCR 自检 | 状态 / 一键自检 / 打开模型目录 | 检查识别模型与运行环境；可打开内置模型所在目录 |

## 快捷键设置

「设置 → 快捷键设置」中可查看并修改 **5 个全局快捷键**（默认值与作用见[快捷键总表](/zh/guide/shortcuts)）：

| 动作 | 默认键 |
| --- | --- |
| 截图 | `F1` |
| 截图并保存 | `Alt + S` |
| 贴图到桌面 | `Alt + P` |
| 显示 / 隐藏窗口（截图界面） | `Alt + Q` |
| 录屏 | `Alt + R` |

改键步骤：

1. 点击该行右侧「编辑」，弹出「编辑快捷键 · <动作>」窗口；
2. 直接按下新的组合键（窗口会显示识别到的按键）；
3. 点「确认」——**立即保存并重新注册**，无需重启。

若新组合已被其它 koiShot 动作占用，会提示「「<组合>」已被「<动作>」使用，请换一个」；也可能是被系统级快捷键（如 macOS 的 `Cmd + Shift + 3/4/5`、Windows 的 `Win + Shift + S`）或其他常驻软件的全局热键占用。

**改键后不生效？** 部分软件（游戏、远程桌面、虚拟机等）会以独占方式截获按键，导致全局热键收不到，可换一组按键或关闭相应软件后重试。

**macOS 上 `F1` 这类功能键冲突？** `F1`–`F12` 默认是亮度、音量等系统功能键，如需用作快捷键，请在「系统设置 → 键盘」中开启「将 F1、F2 等键用作标准功能键」，或改用包含 `Ctrl` / `Alt` / `Shift` 的组合。

:::tip
建议使用包含 `Ctrl` / `Alt` / `Shift` 的组合，避免与系统或其他软件的快捷键冲突。
:::

## 标注设置

「设置 → 标注设置」为 **9 个标注工具各准备一组出厂默认值**：颜色、粗细（文字工具下为字号、马赛克 / 模糊下为笔刷大小）、不透明度、箭头样式、序号起始值与自动递增。

- 与工具栏属性弹窗用的是**同一套颜色 / 粗细 / 不透明度控件与取值**（9 个预设色、4 档粗细），不是自由数值；
- 默认值在**开始标注时**铺开：新一轮截图、或切换到某个工具时生效；当前截图里的临时调整不会写回设置；
- 截图浮层与贴图窗口**共用**这一套默认值；
- 点页面顶部「恢复默认设置」可把所有工具一次性恢复为出厂值（需二次确认）。

各工具的出厂默认值见[标注默认值](/zh/guide/features/annotation#标注默认值)。

## 关于

「设置 → 关于」展示应用图标、名称、版本号、功能描述与版权信息，并提供「**开源许可协议**」入口：点击弹出许可窗口，列出 Qt 6 与 ONNX Runtime、PaddleOCR 等第三方组件的许可与全文链接（链接交给系统浏览器打开），可用右下「关闭」或 `Esc` 关掉。

## 系统托盘

koiShot 启动后常驻系统托盘，托盘图标：

- **左键单击**：直接开始截图；
- **右键菜单**：

| 菜单项 | 作用 |
| --- | --- |
| 截图 | 开始截图，默认动作为复制 |
| 截图并保存 | 截图框选松手后直接保存到设置中的保存路径 |
| 贴图到桌面 | 截图框选松手后直接贴图 |
| 显示/隐藏窗口 | 呼出或收起截图界面 |
| 设置 | 打开设置窗口（「关于」也在设置里） |
| 退出 | 完全退出程序 |

托盘图标悬停会显示应用名 koiShot。菜单项右侧同时展示当前快捷键，方便对照。

## 关于 AI 功能

koiShot 预留了 AI 图像编辑与视觉问答能力（支持阿里云百炼、火山引擎服务商，可在设置中配置 API Key、模型与代理）。该入口当前处于**隐藏**状态：设置里不显示「大模型设置」分区，贴图窗口也没有「AI 编辑 / AI 理解」按钮与菜单项。普通用户无需关心；后续版本启用时会在此文档同步说明。
