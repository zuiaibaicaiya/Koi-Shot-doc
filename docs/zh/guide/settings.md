# 设置与托盘

打开设置：**托盘图标右键菜单 →「设置」**。设置窗口侧栏底部会显示当前完整版本号（含 git 提交，如 `v1.1.0+g1a2b3c4`）。

侧栏共四页：**通用设置 / 快捷键设置 / 标注设置 / 关于**。设置窗口不是置顶窗口，被其他窗口挡住时，再从托盘菜单点一次「设置」即可把它唤到最前。

## 通用设置

| 分区 | 设置项 | 说明 |
| --- | --- | --- |
| 语言设置 | 界面语言 | 中文 / English，默认跟随系统；切换后 koiShot **自动重启**以应用新语言 |
| 翻译设置 | 服务商 | 固定为「阿里云机器翻译」，无需选择 |
| 翻译设置 | AccessKey ID / AccessKey Secret | 阿里云机器翻译凭据；两栏默认掩码显示，点右侧「眼睛」可临时查看明文、再点恢复掩码；点「保存」写入本机配置 |
| 翻译设置 | 目标语言 | 中文 / 英语 / 日语 / 韩语 / 法语 / 德语 / 西班牙语 / 俄语，作为「翻译」按钮的默认目标语言（结果窗里也能临时切换） |
| 翻译设置 | 测试翻译 | 用一句样例文本真发一次请求，成功或失败都直接显示在卡片里，用来验证凭据是否可用；改完凭据立即生效，无需重启 |
| 外观 | 界面主题 | 跟随系统 / 浅色 / 深色，切换即时生效，所有窗口同步换肤 |
| 截图保存路径 | 保存路径 | 截图、长截图、GIF、录屏、表格导出的统一落点，默认为系统「图片」下的 `koiShot` 文件夹，点「浏览」修改 |
| 截图保存路径 | 保存后打开文件夹 | 开启后，保存成功自动打开文件所在文件夹（默认关闭） |
| GIF 录制 | 体积预设 | 高质量 / 均衡（默认）/ 小体积，详见[GIF 录制](/zh/guide/features/long-capture-gif#gif-录制) |
| GIF 录制 | 帧率 | 5–30 帧/秒（默认 15），帧率越高越流畅、文件越大 |
| 录屏（MP4） | 帧率 | 10–60 帧/秒（默认 30），可选 10 / 15 / 20 / 24 / 25 / 30 / 50 / 60；越高越流畅、越吃性能。录制条上的帧率下拉与设置页双向同步，GIF（5–30）与录屏（10–60）各自独立保存、互不覆盖，改动在下一轮录制生效 |
| 录屏（MP4） | 麦克风 | 「录制时采集麦克风声音」，默认开启；关闭或未授权时录成无声视频 |
| OCR 自检 | 状态 / 一键自检 / 打开模型目录 | 检查识别模型与运行环境，自检结果会列出引擎实际加载的模型与字典；可打开内置模型所在目录 |

## 快捷键设置

「设置 → 快捷键设置」中可查看并修改 **5 个全局快捷键**（默认值与作用见[快捷键总表](/zh/guide/shortcuts)）：

| 动作 | 默认键 |
| --- | --- |
| 截图 | `F1` |
| 截图并保存 | `Alt + S` |
| 贴图到桌面 | `Alt + P` |
| 显示 / 隐藏窗口（截图界面） | `Alt + Q` |
| 录屏 | `Alt + R` |

改键步骤：

1. 点击该行右侧「编辑」，弹出「编辑快捷键 · <动作>」窗口；
2. 直接按下新的组合键（窗口会显示识别到的按键）；
3. 点「确认」——**立即保存并重新注册**，无需重启。

若新组合已被其它 koiShot 动作占用，会提示「「<组合>」已被「<动作>」使用，请换一个」；也可能是被系统级快捷键（如 macOS 的 `Cmd + Shift + 3/4/5`、Windows 的 `Win + Shift + S`）或其他常驻软件的全局热键占用。

**改键后不生效？** 部分软件（游戏、远程桌面、虚拟机等）会以独占方式截获按键，导致全局热键收不到，可换一组按键或关闭相应软件后重试。

**macOS 上 `F1` 这类功能键冲突？** `F1`–`F12` 默认是亮度、音量等系统功能键，如需用作快捷键，请在「系统设置 → 键盘」中开启「将 F1、F2 等键用作标准功能键」，或改用包含 `Ctrl` / `Alt` / `Shift` 的组合。

:::tip
建议使用包含 `Ctrl` / `Alt` / `Shift` 的组合，避免与系统或其他软件的快捷键冲突。
:::

## 标注设置

「设置 → 标注设置」为 **9 个标注工具各准备一组出厂默认值**：颜色、粗细（文字工具下为字号、马赛克 / 模糊下为笔刷大小）、不透明度、箭头样式、序号起始值与自动递增。

- 与工具栏属性弹窗用的是**同一套颜色 / 粗细 / 不透明度控件与取值**（9 个预设色、4 档粗细），不是自由数值；
- 默认值在**开始标注时**铺开：新一轮截图、或切换到某个工具时生效；当前截图里的临时调整不会写回设置；
- 截图浮层与贴图窗口**共用**这一套默认值；
- 点页面顶部「恢复默认设置」可把所有工具一次性恢复为出厂值（需二次确认）。

各工具的出厂默认值见[标注默认值](/zh/guide/features/annotation#标注默认值)。

## 关于

关于信息**只有这一个入口**：托盘「设置」→ 设置侧栏第 4 页「关于」。托盘菜单里没有单独的「关于」项，也没有独立的关于窗口。页面展示应用图标、名称、版本号、更新状态、功能描述、**QQ 交流群**、开源许可入口与版权信息：

- **版本号**：关于页显示完整构建版本并追加平台标识（如 `1.1.2+g1a2b3c4 · windows-x64`），与安装包命名同口径；侧栏底部的 `v…` 是同一来源的完整版本；
- **更新状态行**：版本号下方只有一行状态，依次可能显示「检查更新 / 正在检查更新… / 已是最新版本 · 重新检查 / 发现新版本 vX · 查看更新内容 / 正在下载新版本 vX（… MB）… N% / 正在校验安装包… / 等待系统空闲，或正在安装并自动重启… / 更新失败：<原因> · 重试 · 打开发布页」。在 macOS / Linux 上还会出现「安装包已下载 · 打开安装包」；
- 「**检查更新 / 重新检查**」是唯一的手动入口，**不受一天一次的检查节流限制**；下载或安装失败后点「重试」会续传已下载的分片、不重新请求接口，「打开发布页」可手动下载；
- **QQ 交流群**：展示加群二维码与群号 **1134581312**，点击群号即复制到剪贴板；
- 「**开源许可协议**」：点击弹出只读许可窗口，逐条列出组件名、许可、用途与「许可全文」链接（交给系统浏览器打开），包括 Qt 6（LGPL-3.0 / GPL-3.0）、ONNX Runtime（MIT）、PaddleOCR PP-OCRv6 与 SLANet_plus、zxing-cpp（Apache-2.0）、`gif.h`（公有领域）、X11/xcb（MIT）等；完整清单见发行包内 `THIRD_PARTY_NOTICES.md`。可用右下「关闭」或 `Esc` 关掉，弹窗配色跟随界面主题。

## 自动更新

装好后**不需要手动检查或下载新版本**：启动约 6 秒后，koiShot 会在后台查询 GitHub Releases 的最新正式版本，成功检查后 24 小时内不重复；长期不重启时也会每 10 分钟巡检一次，补查更新或接着下载。只有远端版本严格高于本机版本时才会更新，不提示预发布 / 草稿版本。

- **全程自动、没有开关**：检查、下载、安装都不询问，设置里也**没有**「自动检查更新」「自动安装」之类的开关，更不会弹确认框；发现新版即装，装完继续用；
- **后台下载与校验**：托盘气泡会提示「发现新版本（正在后台下载…）」「更新已就绪，将在系统空闲时安装」「正在安装更新，koiShot 将自动重启」「更新失败」。安装包分片并行下载、支持断点续传，下载后按发布方提供的 SHA-256 摘要校验完整性；每次都是**完整安装包**（约 60 MB），不做增量更新；
- **Windows**：下载并校验完成后，等系统连续 2 分钟无键鼠操作，应用会自行退出并静默安装，装完自动把新版本拉起来，无需运行安装向导；
- **macOS / Linux**：安装包自动下载后交给系统默认程序打开，按系统向导完成安装（DMG 需拖入「应用程序」，`.deb` 需要管理员权限），应用本身继续运行；部分 Linux 桌面的托盘气泡不可点击，此时到「关于」页看状态即可；
- **失败时**：没网、接口限流等检查失败会静默跳过，不打扰使用；下载 / 校验 / 安装失败才会提示，并在「关于」页给出「重试」与「打开发布页」退路。断网或中途退出应用，下次启动会从已下载的分片继续。

:::tip
想立刻确认有没有新版，到「设置 → 关于」点「检查更新 / 重新检查」即可，它不受一天一次的节流限制。更多问答见[常见问题](/zh/guide/faq)。
:::

## 系统托盘

koiShot 启动后常驻系统托盘，托盘图标：

- **左键单击**：直接开始截图；
- **右键菜单**：

| 菜单项 | 作用 |
| --- | --- |
| 截图 | 开始截图，默认动作为复制 |
| 截图并保存 | 截图框选松手后直接保存到设置中的保存路径 |
| 贴图到桌面 | 截图框选松手后直接贴图 |
| 显示/隐藏窗口 | 呼出或收起截图界面 |
| 设置 | 打开设置窗口（「关于」也在设置里） |
| 退出 | 完全退出程序 |

托盘图标悬停会显示应用名 koiShot。菜单项右侧同时展示当前快捷键，方便对照；菜单里没有「关于」项，版本、更新状态与开源许可都在「设置 → 关于」。除截图动作外，托盘也会用气泡提示自动更新的下载与安装进度（部分 Linux 桌面不支持点击气泡）。

## 关于 AI 功能

koiShot 预留了 AI 图像编辑与视觉问答能力（支持阿里云百炼、火山引擎服务商，可在设置中配置 API Key、模型与代理）。该入口当前处于**隐藏**状态：设置里不显示「大模型设置」分区，贴图窗口也没有「AI 编辑 / AI 理解」按钮与菜单项。普通用户无需关心；后续版本启用时会在此文档同步说明。
