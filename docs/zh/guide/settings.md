# 设置与托盘

想改界面语言、主题、文件存哪、快捷键，或者让标注默认就用你顺手的颜色？都在这里：**托盘图标右键 →「设置」**，侧栏四页：通用设置 / 快捷键设置 / 标注设置 / 关于。

## 通用设置

| 你想改什么 | 在哪里改 | 说明 |
| --- | --- | --- |
| 界面语言 | 语言设置 → 界面语言 | 中文 / English，默认跟随系统；切换后应用会自动重启，配置都保留 |
| 界面主题 | 外观 → 界面主题 | 跟随系统 / 浅色 / 深色，切换立刻生效，所有窗口一起换 |
| 文件存哪 | 截图保存路径 → 保存路径 | 截图、长截图、GIF、录屏、表格导出的统一位置，默认在系统「图片」下的 `koiShot` 文件夹；点「浏览」换 |
| 保存后自动打开文件夹 | 截图保存路径 → 保存后打开文件夹 | 默认关闭；开启后每次保存会打开所在文件夹 |
| GIF 画质 / 帧率 | GIF 录制 | 体积预设「高质量 / 均衡 / 小体积」，帧率 5–30（默认 15），详见[GIF 录制](/zh/guide/features/long-capture-gif#gif-录制) |
| 录屏帧率 / 声音 | 录屏（MP4） | 帧率 10–60（默认 30）、麦克风默认开；点「开始录制」前在录制条上改，这一轮就生效 |
| 翻译用的账号 | 翻译设置 | 填阿里云机器翻译的 AccessKey ID / Secret，选目标语言，点「保存」后用「测试翻译」验证；详见[截图翻译](/zh/guide/features/translate) |
| 识别环境是否正常 | OCR 自检 | 点「一键自检」看结果，或点「打开模型目录」查看文件 |

## 快捷键设置

「设置 → 快捷键设置」里能改 **5 个全局快捷键**（默认值见[快捷键总表](/zh/guide/shortcuts)）：

| 动作 | 默认键 |
| --- | --- |
| 截图 | `F1` |
| 截图并保存 | `Alt + S` |
| 贴图到桌面 | `Alt + P` |
| 显示 / 隐藏截图界面 | `Alt + Q` |
| 录屏 | `Alt + R` |

点该行右侧「编辑」→ 直接按下新组合键 → 点「确认」，**立刻生效**，不用重启。

| 你遇到什么 | 可以怎么做 |
| --- | --- |
| 提示已被其他动作占用 | 换一组按键 |
| 按下没反应 | 检查是否被其他软件占用；游戏、远程桌面、虚拟机等可能独占按键，换一组或先关掉它们 |
| macOS 上 `F1` 没反应 | 到「系统设置 → 键盘」开启「将 F1、F2 等键用作标准功能键」，或改用带 `Ctrl` / `Alt` / `Shift` 的组合 |

:::tip
尽量用带 `Ctrl` / `Alt` / `Shift` 的组合，少和系统或其他软件的快捷键撞车。
:::

## 标注设置

「设置 → 标注设置」里，**9 个标注工具各有一组出厂默认值**：颜色、粗细（文字是字号、马赛克 / 模糊是笔刷大小）、不透明度、箭头样式、序号起始值与自动递增。

- 这里选的，就是工具栏属性弹窗里那一套（9 个预设色、4 档粗细）；
- **新一轮截图、或重新选中某个工具时**才会按默认值铺开，截图过程中的临时调整不会写回设置；
- 截图和贴图共用这一套默认值；
- 点顶部「恢复默认设置」可一次全部还原（会再确认一次）。

各工具的出厂值见[标注默认值](/zh/guide/features/annotation#标注默认值)。

## 关于

关于信息只在**托盘「设置」→ 侧栏第 4 页「关于」**，托盘菜单里没有单独的「关于」。这一页能看到：

- **版本号**（和安装包命名一致），侧栏底部也显示完整版本；
- **一行更新状态**：「已是最新版本」「发现新版本」「正在下载」「等待系统空闲安装」「更新失败」等，进度都看这一行；
- **「检查更新 / 重新检查」**：想立刻确认有没有新版就点它；下载失败后点「重试」会接着下，不用重来；「打开发布页」可以手动下载；
- **QQ 交流群 1134581312**：点群号即复制，扫码可加群；
- **「开源许可协议」**：弹出只读窗口，列出用到的第三方组件与许可全文链接，点链接会用浏览器打开；`Esc` 或右下「关闭」退出。

## 自动更新

**装好之后不用管更新**：koiShot 启动后会在后台检查有没有新版，有就自动下载并安装，不会弹确认框，设置里也没有开关。

| 你的系统 | 更新怎么完成 |
| --- | --- |
| Windows | 下载完、你暂时没在用电脑时，自动装好并重新打开 koiShot，不用点安装向导 |
| macOS / Linux | 下载好的安装包会交给系统打开，按系统提示完成即可；应用本身继续运行 |

:::tip
下载中断、断网或中途退出都不会丢进度，下次启动会接着下；也可以到「设置 → 关于」点「重试」立刻继续。没网时会静默跳过，不会打扰你。想马上知道有没有新版，点「检查更新 / 重新检查」即可。
:::

## 系统托盘

koiShot 启动后只常驻托盘，没有主窗口。

- **左键单击**托盘图标：直接开始截图；
- **右键菜单**：

| 菜单项 | 作用 |
| --- | --- |
| 截图 | 开始截图，默认复制 |
| 截图并保存 | 框选松手即保存 |
| 贴图到桌面 | 框选松手即贴图 |
| 显示/隐藏窗口 | 呼出或收起截图界面 |
| 设置 | 打开设置（「关于」也在里面） |
| 退出 | 完全退出 |

前四项右侧会显示当前快捷键，改键后同步更新。托盘图标悬停显示应用名，更新进度也会用气泡提示（部分 Linux 桌面的气泡点不动，去「关于」页看状态即可）。

:::tip
设置窗口被别的窗口挡住时，从托盘菜单再点一次「设置」，或点任务栏上那个 koiShot 按钮，就能把它叫回来；在 Windows 上，这是唯一会出现在任务栏里的 koiShot 窗口，关掉设置按钮就没了。
:::
