# 常见问题

按你**看到的现象**找下面对应的问题，照着做就行。

## 安装与启动

### 启动后怎么没有窗口？

koiShot 没有常驻主窗口，启动后只在系统托盘 / 菜单栏留一个图标，这是正常的。左键点图标就截图，右键菜单可以打开设置或退出。

在 Windows 上，截图、贴图这些窗口都不会占任务栏；**只有打开「设置」时，任务栏里才会出现一个 koiShot 按钮**，关掉设置它就没了。macOS 上不进 Dock，也不进 `⌘ + Tab`。

### `Alt + Q` 是干什么的？

呼出 / 收起截图界面：按一次进入截图，再按一次取消。托盘菜单里对应「显示/隐藏窗口」。

### Linux 上快捷键按了没反应？

Wayland 会话下全局快捷键暂不可用，在登录界面切换到 X11 会话即可。

### Linux 装完没自动启动 / 不想让它开机启动？

`.deb` 装完就会在登录时自动启动，对所有用户生效，设置里没有开关。重新登录后没起来，先确认能从应用菜单正常启动 koiShot，再检查 `/etc/xdg/autostart/koishot.desktop` 是否还在。

不想自启的话，用管理员权限删掉这个启动项即可：`sudo rm /etc/xdg/autostart/koishot.desktop`。详见[获取与安装](/zh/guide/start/getting-started#开机自启)。

### 主题怎么改都不变？

检查系统里是否设置过环境变量 `KOISHOT_THEME`：它会强制指定主题，优先级高于设置页。删掉这个变量后重启 koiShot 即可。

### 切换语言后应用「重启」了？

正常行为。切换中文 / English 会自动重启以应用新语言，设置和快捷键都保留。

### 再运行一次 koiShot 没开新窗口？

koiShot 是单实例应用：已经在运行时再次启动，会**直接触发一次截图**，方便把任何入口都变成截图快捷方式。

## 更新与升级

### 需要我手动更新、点确认吗？

不用。koiShot 启动后在后台检查有没有新版，有就自动下载安装，不弹确认框，设置里也没有开关。托盘气泡会告诉你「正在后台下载」等进度，完整流程见[设置与托盘](/zh/guide/settings)。

### 能关掉自动更新吗？

当前版本没有关闭开关，也没有「只提醒不安装」。没网时检查会静默跳过，只有下载 / 安装失败才会提示。

### Windows 会自动重启吗？我正用着呢

会，但分两种情况：**后台自己发现的新版**会等你连续两分钟没动键鼠才安装，等待期间照常使用；**你自己在「设置 → 关于」点了「检查更新 / 重新检查 / 重试」**发现的新版，下载校验完就立即安装并重启（下载状态行会写明「完成后自动安装并重启」）。点之前先保存正在编辑的内容。

### macOS / Linux 会自动装好吗？

安装包会自动下载并交给系统打开，但你得按系统提示完成：macOS 把 koiShot 拖进「应用程序」，Linux 按包管理器 / 管理员授权装完 `.deb`。应用本身继续运行。

### 下载中断 / 提示「更新失败」？

断网或中途退出都不会丢进度，下次启动会自动接着下。想立刻继续，到「设置 → 关于」点「重试」；如果访问 GitHub 不稳定，点「打开发布页」手动下载安装包覆盖安装即可。

### 想立刻检查或手动升级？

到「设置 → 关于」点「检查更新 / 重新检查」；Windows 上这样发起的更新下载完就直接装好重启，不用等空闲。三个平台也都支持直接运行新版安装包覆盖安装，配置会保留。

## 权限问题（macOS）

### 截图全黑、截不到内容？

给「屏幕录制」权限：打开「系统设置 → 隐私与安全性 → 屏幕录制」，勾选 koiShot，然后退出并重启 koiShot。没授权时截图全黑且不报错，这是系统限制。

### 单击选中控件不生效？

「区块高亮」还需要**辅助功能**权限：到「系统设置 → 隐私与安全性 → 辅助功能」勾选 koiShot。没授权时会静默退回普通框选，不影响其他功能。

### 录屏没有声音？

1. 确认「设置 → 通用设置 → 录屏（MP4）」里麦克风开关是开的（默认开）；
2. 第一次带声音录屏时系统会弹窗请求麦克风，允许即可；改过授权后重启一次 koiShot。

麦克风不可用时会自动录成无声视频，画面不受影响，不会因为没声音就录不出来。

## 快捷键

### 按下没反应？

1. 确认托盘图标还在，koiShot 正在运行；
2. 换一组按键试试，可能和其他软件的全局快捷键撞了；
3. 到「设置 → 快捷键设置」重新设置并确认；
4. macOS 上 `F1` 默认是系统功能键，到「系统设置 → 键盘」开启「将 F1、F2 等键用作标准功能键」，或改用带 `Ctrl` / `Alt` / `Shift` 的组合。

Windows 上如果某个组合被别的程序独占了（比如显卡面板常占 `Alt + R`），改键时会直接提示注册失败，换一组就好。

## 截图与标注

### 之前画的图形改不了了？

标注只有**最近画的那一个**能编辑：再画新图形、切换工具或撤销 / 重做之后，旧的就冻结了，按上去等同按在空白处。要改旧标注，撤销后重画；趁它还是选中态时可以直接拖控制点调整。详见[画完还能改吗](/zh/guide/features/annotation#画完还能改吗)。

### 属性面板去哪了？

画笔 / 矩形 / 圆形 / 箭头 / 荧光笔 / 文字 / 序号的属性在按钮右侧的**下拉弹窗**里（点小三角，或再点一次当前工具的主按钮）。工具栏下方的小面板只剩马赛克与高斯模糊在用；打开弹窗时它会暂时让位，关掉弹窗再出现。

### 在设置里改了标注默认值，这次截图没变化？

默认值只在**开始标注时**生效：新一轮截图，或重新选中那个工具。当前这一轮仍按你在截图里临时选的来。

### 文字输入到一半切换工具，字会丢吗？

不会。除 `Esc` 外，切换工具、点画布别处、点色块都会自动提交已输入的内容。

## 贴图

### 贴图挡住内容了？

用 `Alt` + 滚轮降低透明度；也可以点「隐藏工具栏」只留画面。

### 贴图突然不见了？

贴图在获焦状态下按 `Esc`（或 `Ctrl/⌘ + W`）会关闭，这是设计行为；文字输入中按 `Esc` 只退出输入。误关了重新贴一次即可。

### 贴图能旋转 / 镜像吗？

当前版本不行，只有缩放和透明度。

## 长截图 / GIF / 录屏

### 长截图提示「未检测到有效滚动」？

先点一下目标窗口（浏览器或文档）让它处于前台，再点「开始」，然后匀速滚动。页面本身不能滚、或选区已经覆盖全部内容时也会这么提示；滚动幅度太小不会马上拼进去，继续滚就行。

### 长截图拼歪了？

匀速滚动，别猛地一甩；页面有动画、视频或视差效果容易错位，建议分段截取。完成后长图会自动保存并复制，也能接着标注修整。

### 长截图录到一半想放弃？

点控制条上的「取消」（✕）：已截的全部丢弃，不出图也不进剪贴板。按 `Esc` 反而等同「完成」，会出图。

### GIF 录到一半自己停了？

一次最多约 30 秒，画面越大能录的时间越短，到上限会自动停止并导出已录部分。想录更久请用录屏（MP4）。

### 录屏到 10 分钟自动停了？

单次最长 10 分钟（暂停不计时），到点自动停止并导出，属正常行为。

### 点了「开始录制」却一直没动静？

约 5 秒还没进入录制时会提示「视频编码器启动超时」，可以这样试：

1. 到「设置 → 通用设置 → 录屏（MP4）」把帧率降到 30 或更低，或先关掉麦克风；
2. 关掉占用显卡 / 编码器的软件（别的录屏、直播工具），确认显卡驱动较新；
3. 还不行就退出 koiShot 重新打开再试；
4. **Linux**：老版本安装包可能没带录屏组件，重装发布页的新版 `.deb` 即可，不用另装系统软件。

### 提示「上一段视频仍在导出中」？

停止后要把视频写成文件，片段越长、画面越大越久。等提示消失再开新录制即可。

### HDR 屏幕上截图或录屏发白？

Windows 上会自动处理 HDR 画面，截出来的亮部不再一片白。如果还是发白，先确认系统的 HDR 开关和显卡驱动，或换个区域 / 应用对比；老机器上录屏可能仍会泛白，但录制不会中断。录到一半去改系统 HDR 开关，这段可能录不到画面，重新录一次就好。

### GIF 和录屏怎么选？

几秒的短演示、要发聊天 / 工单，用 GIF（自动循环、体积小）；要声音、超过 30 秒或更清晰，用录屏 MP4。

## OCR 与表格识别

### 识别不了？

识别引擎和模型都随安装包提供，正常开箱即用。先到「设置 → 通用设置 → OCR 自检」点「一键自检」；有异常就点「打开模型目录」看看文件是否齐，必要时重装。

### 识别慢、内存占用高？

koiShot 启动后会在后台提前加载识别模型，常驻占用一些内存是**正常的，不是泄漏**；识别时短暂冲高再回落也正常。开机后第一次按截图快捷键也不用等模型加载，界面会很快出现。觉得明显不对时：

1. 从托盘完全退出 koiShot 再打开；
2. 到「设置 → OCR 自检」确认环境正常；
3. 想省这部分内存，可在启动前设置环境变量 `KOISHOT_OCR_PRELOAD=0`，改为第一次识别时才加载（第一次会慢一点）；
4. 仍无改善，按文末「还是没解决？」反馈，并附上自检结果。

### 表格识别结果错位？

- 框选时贴近表格边界，别带多余内容；
- 框线清晰的规整表格最准；复杂底色、倾斜表格导出前人工核对，用「合并 / 拆分」修一下；
- 导出以窗口里现在这张表为准，改完再导出。

## 截图翻译

### 提示「请先填写…凭据」？

翻译服务需要你自己的凭据：到「设置 → 通用设置 → 翻译设置」看清当前**服务商**，阿里云填 AccessKey ID / Secret，百度翻译填 APP ID / API Key；点「保存」，再点「测试翻译」验证。改完立刻生效，不用重启。两家凭据各自保存，换服务商不用重填。

### 翻译失败？

右栏状态行会给出原因，常见三种：

1. **文字太长**：阿里云一次约 5000 字，百度建议 2000 字以内；把画面分成几块分别框选翻译；
2. **凭据无效 / 未开通 / 欠费**：确认所选服务商的账号已开通机器翻译，用「测试翻译」验证；
3. **网络不通**：不会自动重试，换语言或再点一次「翻译」即可。

### 会把我的图片上传吗？

不会。识别在本机完成，**图片不出本机**；只有识别出来的那段文字会送去翻译。处理敏感内容时留意这一点。

### 译文不准？

多数「翻错」是识别错了：先看结果窗左图里的字对不对，再框一块更干净的区域重试。竖排、艺术字、低对比度、被遮挡的文字容易认错。右栏只有译文，需要原文对照就另开一个 OCR 结果窗。

### 换了目标语言要重新截图吗？

不用。结果窗底部「翻译为」一改，就会用同一段原文按新语言重翻。

## 保存的文件

### 截图存哪去了？

1. 「设置 → 通用设置 → 保存路径」看当前位置，默认在系统「图片」下的 `koiShot` 文件夹；
2. 文件按 `名称_日期_时间` 命名（截图 `koiShot_…png`、长截图 `long_…`、GIF `gif_…`、录屏 `koiShot_….mp4`、表格 `table_…`），按时间排序很好找；
3. 想每次保存后自动打开文件夹，开启「保存后打开文件夹」。详见[保存与输出](/zh/guide/features/output)。

### 表格导出的文件在哪？

直接存到保存目录（不弹另存对话框），文件名形如 `table_20261002_153045.xlsx`。开了「保存后打开文件夹」时会顺带打开该目录。

## 目前做不到的

| 功能 | 现状 |
| --- | --- |
| macOS 权限 | 屏幕录制、辅助功能要手动授予；麦克风按需弹窗授权 |
| macOS 录屏 | 需要 macOS 12.3 及以上 |
| Linux Wayland | 全局快捷键暂不可用，控件高亮未实现；整体体验以 Windows 最完整 |
| 贴图 | 不能旋转 / 镜像 |
| 标注 | 只有最近画的那一个能编辑 |
| 二维码 | 只认 QR 系列，不支持条形码与 DataMatrix 等 |
| GIF | 单次约 30 秒，或画面太大时更短 |
| 录屏 | 单次最长 10 分钟，最高 60 帧/秒；实际流畅度看机器性能 |
| Linux 录屏 | 可能只有约 10 帧/秒；录屏组件已随安装包提供 |
| 长截图 | 页面有动画 / 视频时可能错位 |
| 表格识别 | 不还原字体、精确颜色、公式；不支持斜线表头、嵌套表格、竖排文字；至少 2 行 2 列 |
| 截图翻译 | 需自备阿里云或百度翻译凭据并联网；一次约 5000 字（百度建议 2000 字以内）；只显示译文 |
| 自动更新 | 没有开关、没有确认；Windows 自动完成，macOS / Linux 需按系统提示装完 |
| AI 功能 | 图像编辑、视觉问答入口暂未开放，界面上看不到 |

## 还是没解决？

- 先到 GitHub 仓库的 Issues 看看有没有同类问题；
- 提新 Issue 时附上：操作系统版本、复现步骤、报错或截图（**注意脱敏，不要包含个人隐私数据**）。
