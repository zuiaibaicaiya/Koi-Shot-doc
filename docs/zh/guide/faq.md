# 常见问题（FAQ）

## 安装与启动

### 启动后看不到主窗口？

koiShot 启动后**最小化到系统托盘**，这是正常行为。点击托盘图标即可截图，右键菜单可打开主窗口或设置。

### 双击快捷键没反应（Linux）？

Linux 全局快捷键基于 X11 实现，**Wayland 会话下暂不支持**。可在登录界面切换为 X11 会话。

### 切换界面语言后应用「重启」了？

这是正常行为：切换中文 / English 后 koiShot 会自动重启以应用新语言，设置与快捷键配置均会保留。

### 再次运行 koiShot 没有打开新窗口？

koiShot 是**单实例**应用：程序已在运行时再次启动（如双击桌面图标），不会开新窗口，而是**直接触发一次截图**，便于把任何入口都变成截图快捷方式。

## 权限问题（macOS）

### 截图全黑、截不到内容？

macOS 需要授予屏幕录制权限：打开「系统设置 → 隐私与安全性 → 屏幕录制」，勾选 koiShot，然后重启 koiShot。**未授权时截图为全黑且不报错**，这是系统限制。

### 单击选中控件不生效？

「区块高亮（控件识别）」还需要**辅助功能**权限：在「系统设置 → 隐私与安全性 → 辅助功能」中勾选 koiShot。未授权时不会弹提示，会静默降级为普通框选，不影响其他功能。

## 快捷键

### 快捷键按下没反应？

1. 确认 koiShot 正在运行（托盘有图标）；
2. 检查是否与其他软件的全局快捷键冲突——更换一个组合试试；
3. 在「设置 → 快捷键设置」中重新设置并确认注册成功。

## OCR 与表格识别

### OCR 或表格识别不能用？

识别引擎与模型已随安装包内置，正常情况下开箱即用。先在「设置 → OCR 自检」点「一键自检」确认环境状态；若异常，可点「打开模型目录」检查模型文件是否完整，或重新安装软件。

### OCR 识别慢或内存占用高？

识别引擎默认在打开截图时预热以加快首次识别。如希望省内存，可设置环境变量 `KOISHOT_OCR_PRELOAD=0` 关闭预热（首次识别会稍慢）。

### 表格识别结果错位？

- 框选时尽量贴近表格边界，避免带入多余内容；
- 对规整表格效果最好，复杂背景 / 倾斜表格建议导出前人工核对，并用合并 / 拆分功能修正。

## 保存文件

### 保存的截图找不到了？

1. 打开「设置 → 通用设置 → 保存路径」查看当前保存位置（默认在系统「图片」文件夹下的 `koiShot` 子目录）；
2. 文件按 `名称_日期_时间` 命名（如 `koiShot_20261002_153045.png`），按时间排序很容易找到；
3. 可开启「保存后打开文件夹」，每次保存后自动定位到文件所在文件夹。详见[保存与输出](/zh/guide/features/output)。

## 功能限制说明

| 限制 | 说明 |
| --- | --- |
| macOS 权限 | 首次使用必须授予屏幕录制；控件高亮需辅助功能授权 |
| Linux Wayland | 全局快捷键暂不可用；置顶贴图等体验以 Windows 最完整 |
| 贴图变换 | 贴图暂不支持旋转 / 镜像（后续版本提供） |
| AI 功能 | 图像编辑与视觉问答入口当前隐藏，未开放 |
| 长截图 | 页面含动画 / 视频时可能拼接错位，建议滚动匀速 |

- 提交新 Issue 时请附上：操作系统版本、复现步骤、报错或截图（**注意脱敏，不要包含个人隐私数据**）。
