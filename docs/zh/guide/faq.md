# 常见问题（FAQ）

## 安装与启动

### 启动后看不到主窗口？

koiShot **没有常驻主窗口**，启动后只驻留系统托盘 / 菜单栏，这是正常行为。点击托盘图标（左键）即可截图，右键菜单可打开设置或退出。

### `Alt + Q` 是干什么的？

呼出 / 收起**截图界面**（不是主窗口）：按一次进入截图状态，再按一次取消。托盘菜单里对应「显示/隐藏窗口」。

### 双击快捷键没反应（Linux）？

Linux 全局快捷键基于 X11 实现，**Wayland 会话下暂不支持**。可在登录界面切换为 X11 会话。

### 界面主题改了却没反应？

koiShot 支持环境变量 `KOISHOT_THEME=light|dark` **强制指定主题**，其优先级高于设置页里的主题选择。若设置里切主题没反应，请检查系统环境变量中是否设置过该变量，删除后重启 koiShot 即可。

### 切换界面语言后应用「重启」了？

这是正常行为：切换中文 / English 后 koiShot 会自动重启以应用新语言，设置与快捷键配置均会保留。

### 再次运行 koiShot 没有打开新窗口？

koiShot 是**单实例**应用：程序已在运行时再次启动（如双击桌面图标），不会开新窗口，而是**直接触发一次截图**，便于把任何入口都变成截图快捷方式。

## 权限问题（macOS）

### 截图全黑、截不到内容？

需要授予屏幕录制权限：打开「系统设置 → 隐私与安全性 → 屏幕录制」，勾选 koiShot，然后退出并重启 koiShot。**未授权时截图为全黑且不报错**，这是系统限制。

### 单击选中控件不生效？

「区块高亮（控件识别）」还需要**辅助功能**权限：在「系统设置 → 隐私与安全性 → 辅助功能」中勾选 koiShot。未授权时不会弹提示，会静默降级为普通框选，不影响其他功能。

### 录屏没有声音？

1. 确认「设置 → 通用设置 → 录屏（MP4）」中「录制时采集麦克风声音」为开启（默认开）；
2. 到「系统设置 → 隐私与安全性 → 麦克风」中授权 koiShot；
3. 修改授权后需重启 koiShot。

麦克风不可用时 koiShot 会**自动降级为无声录制**并在录制后提示，画面不受影响——不会因为没声音就录不出视频。

## 快捷键

### 快捷键按下没反应？

1. 确认 koiShot 正在运行（托盘有图标）；
2. 检查是否与其他软件的全局快捷键冲突——换一个组合试试；
3. 在「设置 → 快捷键设置」中重新设置并确认注册成功；
4. macOS 上 `F1` 默认是系统功能键，可在「系统设置 → 键盘」中开启「将 F1、F2 等键用作标准功能键」。

在 Windows 上，若某个组合已被其他程序**独占注册**（如显卡驱动面板常占用 `Alt + R`），在设置里改成该组合时会直接提示注册失败——换一个组合即可。程序启动时若默认组合被占用，同样需要手动改键。

## 截图与标注

### 之前画的图形改不了了？

标注遵循「只有最近画的那一个可编辑」的规则：再画新图形、切换工具或撤销 / 重做之后，旧图形会**冻结**，按下它等同于按下空白处。要修改旧标注请撤销后重画，或在它仍是选中态时拖动控制点调整。详见[编辑已有标注](/zh/guide/features/annotation#编辑已有标注)。

### 属性面板去哪了？

画笔 / 矩形 / 圆形 / 箭头 / 荧光笔 / 文字 / 序号这 7 个工具的属性都放在按钮右侧的**下拉弹窗**里（点小三角，或再点一次已选中的主按钮），工具栏下方的小面板只剩马赛克与高斯模糊在用。

### 在设置里改了标注默认值，当前截图没变化？

默认值只在**开始标注时**生效：新一轮截图、或重新选中该工具时才铺开。当前这一轮截图里的颜色 / 粗细仍按你会话内的选择走。

### 文字输入到一半切换工具，字会丢吗？

不会。除 `Esc` 外，切换工具、点画布别处、点色块都会自动提交已输入的内容。

## 贴图

### 贴图挡住了内容？

用 `Alt` + 滚轮降低透明度；也可以用工具栏或右键菜单「隐藏工具栏」只保留画面。

### 贴图莫名其妙消失了？

贴图窗口在获焦状态下按 `Esc`（或 `Ctrl/⌘ + W`）会关闭当前贴图，这是设计行为；文字标注编辑中按 `Esc` 只退出编辑，不会关掉贴图。误关后重新贴一次即可。

### 贴图能旋转 / 镜像吗？

当前版本暂不支持，只提供缩放与透明度调整。

## 长截图 / GIF / 录屏

### 长截图提示「未检测到有效滚动」？

请先让目标窗口在前台（点一下浏览器或文档），再点控制条「开始」，然后匀速滚动内容；页面本身无法滚动、或选区高度已覆盖全部内容时也会得到这个提示。

### 长截图拼歪了？

保持匀速滚动，避免快速拖动与惯性滚动；页面含动画 / 视频 / 视差效果时容易错位，建议分段截取。长截图完成后会自动保存并复制到剪贴板，可以接着用标注工具修整。

### 长截图录到一半想放弃？

点控制条上的「取消」（✕）：已采样的帧直接丢弃，不生成文件、也不写剪贴板。若按 `Esc`，运行中会等同点「完成」并出图，不想留文件时请用取消。

### GIF 录到一半自己停了？

GIF 有双重上限：帧数 = 帧率 × 30（约 30 秒）与累计总像素预算（约 3.2 亿像素，选区越大越快触顶），任一触顶即自动停止并导出已录内容。想录更长请用**录屏（MP4）**。

### 录屏也在 10 分钟时自动停了？

录屏单次最长 10 分钟（按实际录制时间累计，暂停期间不计时），到达上限自动停止并导出，属预期行为。

### 录屏点了开始却一直停在待开始？

约 5 秒内没进入录制状态时，koiShot 会提示「视频编码器启动超时」并自动收尾，通常与帧率过高、编码器异常或麦克风设备有关：

1. 在「设置 → 通用设置 → 录屏（MP4）」把帧率降到 30 或更低，或暂时关闭麦克风后重试；
2. 关闭占用显卡 / 编码器的程序（录屏软件、直播工具等），并确认显卡驱动为最新；
3. 仍然失败时退出 koiShot 后重新启动再试。

### 录屏提示「上一段视频仍在导出中」？

停止录制后需要把 H.264 视频写入文件，片段越长、选区越大，导出越久（长片段可能十几秒）。导出期间不能再开新录制，等提示消失即可；若导出超过约 30 秒仍无结果，koiShot 会强制结束编码——文件已成形时按完成处理，否则提示失败。

### HDR 显示器上截图或录屏发白？

Windows 上 koiShot 会自动识别 HDR 显示器，并对截图、GIF 与录屏画面做色调映射，输出仍是标准 SDR 内容（亮部不再一片白）。若仍然发白，请确认系统 HDR 开关状态与显卡驱动，或改用其他区域 / 应用对比；极老的系统在 FP16 抓帧不可用时会退回 8 位抓帧，可能仍有轻微泛白。

### GIF 和录屏怎么选？

几秒的短演示、要贴进聊天 / 工单，用 GIF（体积小、自动循环）；需要声音、超过 30 秒或更清晰，用录屏 MP4。

## OCR 与表格识别

### OCR 或表格识别不能用？

识别引擎与模型已随安装包内置，正常情况下开箱即用。先在「设置 → 通用设置 → OCR 自检」点「一键自检」确认环境状态；若异常，可点「打开模型目录」检查模型文件是否完整，或重新安装软件。

### OCR 识别慢或内存占用高？

识别引擎在打开截图时会预热，以保证首次识别的速度——预热后常驻数百 MB 内存（约 185 MB）**不是内存泄漏**；识别过程中瞬时冲高再回落也属正常。若感觉明显偏慢或内存占用偏高：

1. 完全退出 koiShot（托盘图标 → 退出）后重新启动再试；
2. 在「设置 → OCR 自检」中确认识别环境状态正常；
3. 想省内存可在启动 koiShot 前设置环境变量 `KOISHOT_OCR_PRELOAD=0` 关闭预热，改为首次识别时才加载（首次会慢一些）；
4. 仍无改善时，请按[反馈与支持](#仍无法解决)提交问题，并附上自检结果。

### 表格识别结果错位？

- 框选时尽量贴近表格边界，避免带入多余内容；
- 对规整、有清晰框线的表格效果最好；复杂背景 / 倾斜表格建议导出前人工核对，并用「合并 / 拆分」修正；
- 导出的内容以窗口里修改后的表格为准，改完再导出即可。

## 保存文件

### 保存的截图找不到了？

1. 打开「设置 → 通用设置 → 保存路径」查看当前保存位置（默认在系统「图片」文件夹下的 `koiShot` 子目录）；
2. 文件按 `名称_日期_时间` 命名（截图如 `koiShot_20261002_153045.png`，长截图 `long_…`、GIF `gif_…`、录屏 `koiShot_….mp4`、表格 `table_…`），按时间排序很容易找到；
3. 可开启「保存后打开文件夹」，每次保存后自动定位到文件所在文件夹。详见[保存与输出](/zh/guide/features/output)。

### 表格导出的文件在哪？

导出时直接写入保存目录（不弹系统另存对话框），并自动打开该目录；文件名形如 `table_20261002_153045.xlsx`。

## 功能限制说明

| 限制 | 说明 |
| --- | --- |
| macOS 权限 | 首次使用必须授予屏幕录制；控件高亮需辅助功能；录屏声音需麦克风授权 |
| macOS 录屏版本 | 录屏（MP4）依赖 ScreenCaptureKit，需 macOS 12.3 及以上 |
| Linux Wayland | 全局快捷键暂不可用；控件高亮未实现；置顶贴图等体验以 Windows 最完整 |
| 贴图变换 | 贴图暂不支持旋转 / 镜像 |
| 标注编辑 | 只有当前选中（最近绘制）的图形可编辑，旧图形冻结 |
| 二维码 | 只识别 QR 系列二维码，不支持条形码与 DataMatrix / Aztec / PDF417 |
| GIF 时长 | 单次约 30 秒（帧率 × 30 帧）或累计约 3.2 亿像素，任一触顶自动停止 |
| GIF 内容 | Windows 上半透明窗口可能不会出现在 GIF 画面里（抓屏性能取舍） |
| 录屏时长 | 单次最长 10 分钟（暂停不计时），超出自动停止 |
| 录屏帧率 | 最高 60 帧/秒；实际帧率受机器性能与编码器影响 |
| Linux 录屏 | 暂无原生抓帧，回退兼容抓帧（约 10 帧/秒） |
| 长截图 | 页面含动画 / 视频时可能拼接错位，建议匀速滚动 |
| 表格识别 | 只还原文字、合并与尺寸，不重建字体 / 精确颜色 / 公式；不支持斜线表头、嵌套子表格与竖排文字；至少 2 行 2 列才能成表 |
| AI 功能 | 图像编辑与视觉问答入口当前隐藏，未开放 |

## 仍无法解决？

- 查看 GitHub 仓库的 Issues 是否有同类问题；
- 提交新 Issue 时请附上：操作系统版本、复现步骤、报错或截图（**注意脱敏，不要包含个人隐私数据**）。
