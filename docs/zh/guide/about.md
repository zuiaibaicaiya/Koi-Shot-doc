# 关于我们

koiShot 是一款跨平台（Windows / macOS / Linux）截图工具，支持截图标注、贴图、长截图、GIF 与 MP4 录屏、本地离线 OCR 文字识别与表格识别，全程本地运行，无广告、无水印、无需登录。
