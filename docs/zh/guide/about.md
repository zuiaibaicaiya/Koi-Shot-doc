# 关于我们

koiShot 是一款跨平台的截图小工具（Windows / macOS / Linux）：截图标注、贴图对照、长截图、GIF 与 MP4 录屏、把图片里的字复制出来、把表格变成 Excel，都能用它完成。识别在本机进行，不用登录，没有广告和水印。

## 版本更新与开源许可

koiShot 会自动更新：Windows 上装完自己重启就好，macOS / Linux 会打开下载好的安装包让你按提示完成。想看进度或重试，到「设置 → 关于」看那一行状态（见[设置与托盘](/zh/guide/settings)）；也可以自己下载新版覆盖安装（见[获取与安装](/zh/guide/start/getting-started)）。

想看用到的开源组件和许可，点「设置 → 关于 → 开源许可协议」即可。
