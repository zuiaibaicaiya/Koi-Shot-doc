# 产品介绍

## koiShot 是什么

**koiShot** 是一款跨平台的桌面截图与贴图工具，支持 Windows、macOS 与 Linux。除了常规截图，它把标注、贴图、长截图、文字识别（OCR）、表格识别（截图转 Excel）和 GIF 录制整合在同一款软件里，所有识别均在本地完成，无需联网、不上传图片。

## 主要功能

| 功能 | 说明 |
| --- | --- |
| 截图 | 多屏截图、框选截图、正方形选区、悬停高亮界面控件并一键选中、放大镜取色 |
| 标注 | 矩形、圆形、箭头（8 种样式）、画笔、荧光笔、文字、序号、马赛克、高斯模糊 |
| 输出 | 复制到剪贴板、保存到文件、贴图到桌面 |
| 贴图 | 将截图固定在桌面上，可缩放、调透明度、继续标注 |
| 长截图 | 滚动拼接，适合截取网页、聊天记录等超长内容 |
| GIF 录制 | 录制选区动画，帧数与体积双重限制，不会生成超大文件 |
| OCR 文字识别 | 本地 PaddleOCR 引擎，识别结果带行号，可一键复制 |
| 表格识别 | 截图转可编辑表格，支持导出 xlsx / CSV / TSV |
| 其他 | 全局快捷键（可自定义）、系统托盘常驻、浅色 / 深色主题、中英文界面 |

## 适用场景

- **日常沟通**：截图标注问题位置，复制后直接粘贴到聊天窗口或工单系统。
- **教程与文档**：用序号、箭头、文字标注操作步骤，快速产出图文说明。
- **数据整理**：截图表格 → 表格识别 → 导出 Excel，免去手动录入。
- **资料摘录**：长截图保存整页网页或对话记录；OCR 提取图片中的文字。
- **多任务对照**：贴图功能把参考图固定在桌面角落，边看边做。
- **录制演示**：GIF 录制简短操作动画，用于反馈与说明。

## 适用平台与系统要求

| 平台 | 要求 |
| --- | --- |
| Windows | Windows 10 及以上 |
| macOS | 需授予「屏幕录制」权限；首次使用请见[常见问题](/zh/guide/faq) |
| Linux | X11 环境（Wayland 下全局快捷键暂不可用） |

## 三个上手动作

装好 koiShot 后，只需记住三个默认快捷键：

1. 按 `F1` —— 开始截图；
2. 框选区域后在工具栏点「复制 / 保存 / 贴图」—— 完成输出；
3. 按 `Alt + Q` —— 随时呼出或隐藏主窗口。

更多快捷键见[快捷键总表](/zh/guide/shortcuts)，全部可在设置中自定义。

## 界面语言与主题

在「设置 → 通用设置」中可将界面切换为中文 / English（默认跟随系统语言，切换后应用自动重启生效）；界面主题提供跟随系统 / 浅色 / 深色三种，切换即时生效。
