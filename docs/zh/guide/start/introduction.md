# 产品介绍

## koiShot 是什么

**koiShot** 是一个装在电脑上的截图小工具，Windows、macOS、Linux 都能用。它不只是「截张图」：圈重点、贴图对照、截长网页、录操作演示、把图片里的字复制出来、把表格变成 Excel、看懂外文界面，都在同一个软件里完成。文字和表格识别**在本机完成**，不用联网、不用登录，图片不会上传。

装好后它只在系统托盘 / 菜单栏留一个图标，没有常驻窗口；截图从托盘、快捷键或桌面快捷方式发起，不打扰你正在做的事。

## 能帮你做什么

| 你想做的事 | 用这个 |
| --- | --- |
| 截一块区域、圈出重点 | 截图 + 九个标注工具（画笔、箭头、马赛克、文字、序号…） |
| 边看图边写东西 | 贴图：把截图钉在桌面最上层，还能缩放、调透明度 |
| 截下整个网页 / 聊天记录 | 长截图：滚动页面自动拼成一张长图 |
| 做一段操作演示 | GIF（几秒、自动循环）或 MP4 录屏（可带声音，最长 10 分钟） |
| 把图片里不能选中的字复制出来 | OCR 文字识别，可整段或单行复制 |
| 看懂外文界面 / 报错 | 截图翻译，左图右文对照，随时换语言 |
| 把截图里的表格做成 Excel | 表格识别，导出 `.xlsx` / `.csv` |
| 扫二维码 | 二维码识别，内容直接进剪贴板 |

界面有中文 / English、浅色 / 深色主题，5 个全局快捷键都能按习惯改；装好之后更新会自动完成，不用操心。

## 什么时候用得上

- **日常沟通**：截图圈出问题位置，直接粘到聊天窗口或工单里。
- **写教程 / 文档**：用序号、箭头、文字标出操作步骤，图文说明一次做好。
- **整理数据**：截图表格 → 变成能改的网格 → 导出 Excel，不用手敲。
- **摘录资料**：长截图存整页网页或对话，OCR 取出图片里的文字。
- **阅读外文**：框选外文界面或论文片段，直接拿到译文。
- **多任务对照**：把参考图钉在桌面角落，边看边做。
- **录制演示**：短演示用 GIF，要讲解或配音就用 MP4。

## 系统要求

| 平台 | 需要留意 |
| --- | --- |
| Windows | Windows 10 及以上；录屏抓帧需 Win10 1903+。安装默认只给当前用户，不需要管理员权限 |
| macOS | 首次使用要给「屏幕录制」权限，控件高亮还要「辅助功能」；录屏带声音时系统会弹窗问麦克风（拒绝也能录，只是没声音）。录屏需 macOS 12.3+，详见[常见问题](/zh/guide/faq) |
| Linux | 提供 `.deb` 安装包，X11 会话下快捷键才可用（Wayland 暂不支持）；装完会随登录自动启动 |

只有**截图翻译**需要你自备阿里云机器翻译的 AccessKey 并联网（配置见[截图翻译](/zh/guide/features/translate)）；文字、表格与二维码识别全程本地离线，不需要任何账号。

## 三个动作就能上手

1. 按 `F1` —— 开始截图；
2. 框选区域，点工具栏「复制 / 保存 / 贴图」—— 拿走结果；
3. 按 `Alt + Q` —— 呼出或收起截图界面（再按一次取消）。

完整按键见[快捷键总表](/zh/guide/shortcuts)，全部可在设置中改。界面语言和主题在「设置 → 通用设置」里，切换语言会自动重启，主题即时生效。
