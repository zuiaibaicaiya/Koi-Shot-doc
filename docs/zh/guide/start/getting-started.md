# 获取与安装

从项目发布页下载你系统的安装包，双击装好就能用。运行库、文字识别、录屏需要的组件都已随包提供，**不用另外装东西，也不用配置**。

装好后不用手动检查更新：koiShot 会在后台下载并安装新版，Windows 上自动完成，macOS / Linux 会打开下载好的安装包让你按提示完成。设置里没有更新开关，进度可以在「设置 → 关于」里看。

## Windows 安装

1. 下载 `koiShot-<版本>-windows-x64-setup.exe`，双击运行；
2. 跟随**简体中文安装向导**完成，无需管理员权限；
3. 保持「运行 koiShot」勾选并点「完成」，koiShot 启动并驻留系统托盘。

### 安装向导里会问什么

**装到哪**：默认在当前用户的程序目录，可以自己改。首次安装还会问安装范围，默认「仅当前用户安装」（无需管理员权限），也可改成「为所有用户安装」。

**附加任务**：

![选择附加任务](/images/install/windows-wizard-tasks.png)

- **创建桌面快捷方式**：默认不勾选，需要就勾上；
- **开机自动启动 koiShot**：默认勾选，装完随系统启动并驻留托盘，卸载时会自动移除。

**确认并安装**：

![准备安装](/images/install/windows-wizard-ready.png)

如果 koiShot 正在运行（比如升级时），向导会提示自动关闭后继续，不用手动退出：

![关闭运行中的 koiShot](/images/install/windows-wizard-close-apps.png)

![安装完成](/images/install/windows-wizard-finish.png)

### 升级与卸载

| 你想做什么 | 怎么做 |
| --- | --- |
| 升级 | 什么都不用做，koiShot 会在你没操作电脑时自动装好新版并重新打开，配置保留 |
| 手动升级（备用） | 直接运行新版本安装包覆盖安装，不用先卸载 |
| 卸载 | 系统「设置 → 应用 → 安装的应用」里找到 koiShot 卸载，或用开始菜单程序组里的卸载入口 |

## macOS 安装

1. 按芯片下载并双击打开安装映像：Apple 芯片用 `-macos-arm64.dmg`，Intel 用 `-macos-x86_64.dmg`；如果发布的是 `-macos-universal.dmg`，两种机型都能装；
2. 按界面引导，把 **koiShot 拖进「应用程序」**：

![macOS 安装界面：把 koiShot 拖到右侧「应用程序」完成安装](/images/install/macos-dmg-install.png)

3. 从「启动台」或「应用程序」启动 koiShot。

### 首次打开提示「无法验证开发者」

macOS 会拦截未经公证的应用，任选一种放行，只需一次：

- 弹窗里点「完成」，打开「**系统设置 → 隐私与安全性**」，在页面底部点 koiShot 旁边的「**仍要打开**」；
- 或在「应用程序」里**右键 koiShot → 打开**，再点一次「打开」。

### Dock 里没有 koiShot 是正常的

koiShot 是纯托盘应用：不进 Dock，也不进 `⌘ + Tab`，只在**屏幕右上角的菜单栏**显示图标。看到菜单栏图标就说明它在正常运行。

### 需要给的两项权限

第一次使用时，到「系统设置 → 隐私与安全性」把下面两项打开，然后**退出并重启 koiShot**（菜单栏托盘图标右键 →「退出」）：

| 权限 | 不给会怎样 |
| --- | --- |
| 屏幕录制 | 截图全黑，而且不报错 |
| 辅助功能 | 鼠标悬停时不会高亮界面控件，只能手动框选 |

![在「录屏与系统录音」权限列表中开启 koiShot](/images/install/macos-permission-screen-recording.png)

![在「辅助功能」权限列表中开启 koiShot](/images/install/macos-permission-accessibility.png)

录屏要带声音时，**第一次开录系统会弹窗问你要不要用麦克风**，允许即可；拒绝也能录，只是没有声音。

### 开机自启

从发布页下载的 DMG 拖进「应用程序」后**不会**自动随登录启动。需要的话：

- 打开「**系统设置 → 通用 → 登录项**」，点「+」把 koiShot 加进去；
- 不想让它自启，回到同一个界面把 koiShot 移除或关掉即可；
- 用官方打包脚本安装的机器会自带登录启动项，同样在这个界面里管理。

### 升级与卸载

- **升级**：koiShot 会自动下载新版 DMG 并打开，把它拖进「应用程序」覆盖即可，配置保留。升级后如果截图或控件高亮不灵，重新勾选上面两项权限；
- **手动升级（备用）**：自己从发布页下载新版 DMG，按同样步骤覆盖；
- **卸载**：先在菜单栏托盘图标右键「退出」，再把「应用程序」里的 koiShot 拖进废纸篓。

## Linux 安装

下载 Debian / Ubuntu 系的 `.deb` 包，在下载目录打开终端：

```bash
sudo apt install ./koishot_<版本>-1_amd64.deb
```

系统依赖已齐时也可以 `sudo dpkg -i koishot_<版本>-1_amd64.deb`（提示缺依赖就再执行 `sudo apt -f install`）。

装完就能从应用菜单启动，桌面也会有快捷方式。录屏需要的组件已随包提供，不用另装系统软件；万一出现「编码器启动超时」或录出 0 字节文件，通常是装了旧包，重装发布页的新版即可。异常崩溃后 koiShot 会自动重新打开，从托盘正常退出不会。

### 开机自启

`.deb` **装完就会在登录时自动启动**，对所有用户生效，设置里没有开关。

| 你想做什么 | 怎么做 |
| --- | --- |
| 关掉所有人的自启 | 用管理员权限删除启动项：`sudo rm /etc/xdg/autostart/koishot.desktop` |
| 装完没自动启动 / 重登后没起来 | 确认能从应用菜单正常启动 koiShot，再检查上述文件是否存在 |

### 升级与卸载

自动更新会下载新版 `.deb` 并交给系统打开，按包管理器 / 管理员提示完成即可，应用本身继续运行。也可以手动执行 `sudo apt install ./koishot_<新版本>-1_amd64.deb` 覆盖升级，配置保留。

卸载：`sudo dpkg -r koishot` 保留配置；`sudo dpkg -P koishot`（或 `apt purge`）连配置一起清除。

## 第一次启动

启动后**只驻留系统托盘**，不会弹出任何窗口：

1. 左键单击托盘图标，开始截图；
2. 到「设置」里确认保存位置、界面语言、主题和快捷键（5 个全局动作都能改）；
3. 拿不准识别能不能用时，到「设置 → OCR 自检」点「一键自检」（通常不用管）；
4. 录屏要带声音，确认「设置 → 通用设置 → 录屏（MP4）」里的麦克风开关是开的；
5. 要用截图翻译，到「设置 → 通用设置 → 翻译设置」填入阿里云机器翻译的 AccessKey，点「测试翻译」验证（见[截图翻译](/zh/guide/features/translate)）。
