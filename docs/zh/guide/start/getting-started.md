# 获取与安装

从项目发布页下载对应平台的安装包。无需任何构建或额外配置——运行库、OCR 识别引擎与录屏编码后端已全部打包，装好即用。

装好后**不用手动检查更新**：koiShot 启动后会自动查询 GitHub Releases 的最新正式版本，在后台下载并校验完整安装包；Windows 会在系统空闲时静默安装并自动重启，macOS / Linux 会打开下载好的安装包供你按向导完成。设置里没有更新开关，「设置 → 关于」可查看进度与手动重试，详见[常见问题](/zh/guide/faq)。

## Windows 安装

1. 下载安装向导 `koiShot-<版本>-windows-x64-setup.exe`，双击运行；
2. 跟随**简体中文安装向导**完成安装，无需管理员权限；
3. 安装完成后保持「运行 koiShot」勾选并点击「完成」，koiShot 启动并驻留系统托盘。

### 安装向导步骤

**选择安装位置**：默认安装到当前用户的本地程序目录（`%LOCALAPPDATA%\Programs\koiShot`），可自行修改。首次安装时向导会先询问安装范围，默认「仅当前用户安装」、无需管理员权限，也可切换为「为所有用户安装」（此时需要管理员权限确认）。

**选择附加任务**：

![选择附加任务](/images/install/windows-wizard-tasks.png)

- **创建桌面快捷方式**：默认不勾选，可按需勾选；
- **开机自动启动 koiShot**：默认勾选。勾选后 koiShot 随系统启动并驻留托盘，随时一键截图；卸载时会自动移除该设置。

**确认并安装**：向导汇总安装位置与所选任务，确认无误后点击「安装」：

![准备安装](/images/install/windows-wizard-ready.png)

若检测到 koiShot 正在运行（例如升级安装），向导会提示自动关闭后继续，无需手动退出：

![关闭运行中的 koiShot](/images/install/windows-wizard-close-apps.png)

**完成安装**：

![安装完成](/images/install/windows-wizard-finish.png)

### 升级与卸载

- **升级（默认方式）**：koiShot 自动检查到新版后，在后台下载并校验安装包，等系统连续 2 分钟无键鼠操作即自行退出、静默安装，装完自动把新版本拉起来，无需运行安装向导；已有配置保留；
- **手动升级（备用）**：也可直接运行新版本安装包覆盖安装，无需先卸载，向导会沿用已有配置；
- **卸载**：在系统「设置 → 应用 → 安装的应用」中找到 koiShot 卸载，也可使用开始菜单中 koiShot 程序组的卸载入口。卸载会自动清理开机自启项与相关文件。

## macOS 安装

1. 按芯片下载对应安装映像并双击打开：Apple 芯片用 `koiShot-<版本>-macos-arm64.dmg`，Intel 机型用 `koiShot-<版本>-macos-x86_64.dmg`（若发布的是通用包则只有一个 `-macos-universal.dmg`，两种机型都能装）；
2. 按安装界面的引导，将 **koiShot 拖入右侧「应用程序」文件夹**：

![macOS 安装界面：把 koiShot 拖到右侧「应用程序」完成安装](/images/install/macos-dmg-install.png)

3. 安装完成后，从「启动台」或「应用程序」启动 koiShot。

### 首次打开提示「无法验证开发者」

macOS 会拦截未经公证的应用，属正常现象。任选一种方式放行：

- 在弹窗中点「完成」取消，然后打开「**系统设置 → 隐私与安全性**」，在页面底部找到关于 koiShot 的提示，点击「**仍要打开**」；
- 或在「应用程序」文件夹中**右键 koiShot → 打开**，在弹窗中再点「打开」。此操作只需一次，之后可正常启动。

### Dock 里没有 koiShot 是正常的

koiShot 是**纯托盘应用**：启动后不出现在 Dock，也不会出现在 `⌘ + Tab` 切换列表中，只在**屏幕右上角的菜单栏**显示托盘图标。看到菜单栏图标，就说明程序在正常运行。

### 系统权限授权

macOS 的截图与录制能力依赖三项独立的系统授权，需要手动开启：

| 授权 | 入口 | 未授权时的现象 |
| --- | --- | --- |
| 屏幕录制 | 系统设置 → 隐私与安全性 → 屏幕录制 | 截图全黑且不报错 |
| 辅助功能 | 系统设置 → 隐私与安全性 → 辅助功能 | 悬停高亮控件（区块选择）不出现，静默降级为普通框选 |
| 麦克风 | 系统设置 → 隐私与安全性 → 麦克风 | 录屏（MP4）没有声音，画面正常 |

在列表中找到 koiShot，打开右侧开关：

![在「录屏与系统录音」权限列表中开启 koiShot](/images/install/macos-permission-screen-recording.png)

![在「辅助功能」权限列表中开启 koiShot](/images/install/macos-permission-accessibility.png)

勾选后**退出并重启 koiShot**（菜单栏托盘图标右键 →「退出」）即可生效。麦克风仅在开启「录制时采集麦克风声音」并实际录屏时才会请求，拒绝后自动降级为无声录制。更多细节见[常见问题](/zh/guide/faq)。

### 开机自启

- 通过官方打包脚本 / 安装流程安装的 koiShot 会写入**登录项（LaunchAgent）**，登录后自动启动并驻留菜单栏，不会弹出窗口打扰操作；可用同一脚本的卸载参数移除。
- 手动拖入「应用程序」安装时，可自行添加：打开「**系统设置 → 通用 → 登录项**」，点击「+」添加 koiShot。

### 升级与卸载

- **升级（默认方式）**：koiShot 自动下载新版 DMG 并打开，把 koiShot 拖入「应用程序」**覆盖安装**即可，已有配置会保留。若升级后某项系统权限失效，到上面三个授权入口重新勾选一次；
- **手动升级（备用）**：也可自行从发布页下载新版 DMG，按同样步骤覆盖安装；
- **卸载**：先在菜单栏托盘图标右键选择「退出」，再将「应用程序」中的 koiShot 拖入废纸篓。

## Linux 安装

提供 Debian / Ubuntu 系的 `.deb` 安装包（`koishot_<版本>-1_amd64.deb`）：

```bash
sudo apt install ./koishot_<版本>-1_amd64.deb
```

系统库已齐时也可用 `sudo dpkg -i koishot_<版本>-1_amd64.deb`（若提示依赖不满足，再执行 `sudo apt -f install` 补齐）。

- 安装后可在应用菜单中启动 koiShot，每个用户的桌面也会创建 koiShot 快捷方式图标；也可直接运行 `koiShot`；
- 包内自带 Qt 运行库、OCR 模型与**录屏所需的 Qt Multimedia / FFmpeg 编码后端**，不依赖系统 Qt6 或系统 ffmpeg，装好即可录 MP4；若点「开始」后报「编码器启动超时」或录出 0 字节文件，多为旧包缺少该后端，重装新版即可；
- 附带 systemd 用户服务，**异常崩溃后 2 秒自动重启**（从托盘正常退出不会被拉起；5 分钟内连续崩溃超过 5 次会暂停自动重启以防死循环）；
- 卸载：`sudo dpkg -r koishot` 保留配置文件；`sudo dpkg -P koishot`（或 `apt purge`）连同配置与服务一并清除。

### 升级

自动更新会下载新版 `.deb` 并交给系统打开，按包管理器 / 管理员授权提示完成即可；应用本身继续运行。也可手动执行 `sudo apt install ./koishot_<新版本>-1_amd64.deb` 直接覆盖升级——安装前会先停止正在运行的实例，配置文件保留。

## 首次启动

程序启动后**只驻留系统托盘**，不显示任何窗口（koiShot 没有常驻主窗口）：

1. 点击任务栏 / 菜单栏托盘图标（左键单击）即可开始截图；
2. 到「设置」中确认保存路径、界面语言、主题与快捷键（5 个全局动作均可改键）；
3. 可在「设置 → OCR 自检」中点「一键自检」，确认识别环境一切正常（通常无需操作）；
4. 需要带声音录屏时，先确认「设置 → 通用设置 → 录屏（MP4）」中的麦克风开关，并在系统里放行麦克风权限；
5. 需要用截图翻译时，到「设置 → 通用设置 → 翻译设置」填入阿里云机器翻译的 AccessKey（点「测试翻译」可立即验证，见[截图翻译](/zh/guide/features/translate)）。
