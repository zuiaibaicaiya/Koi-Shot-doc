# 标注与编辑

## 选择标注工具

框选完成后，选区下方弹出**工具栏**，当前使用的工具会**高亮显示**；选中支持样式调节的工具后，工具栏下方还会弹出**属性面板**，调整即时生效。标注仅作用于框选区域，随时可用「撤销 / 重做」回退。

## 标注工具详解

### 画笔

**用途**：自由手绘，适合圈画不规则区域、手写补充说明。

**操作步骤**：

1. 点击工具栏「画笔」（高亮即选中）；
2. 在属性面板选择颜色、粗细、不透明度；
3. 按住左键在截图上拖动绘制，松开即完成一笔；
4. 可连续绘制多笔，每笔算一步，可单独撤销。

**示例**：在界面截图上手写圈出异常报错的位置。

**注意**：画笔无法选中修改，画错请用 `Ctrl + Z` 撤销后重画。

### 矩形 / 圆形

**用途**：框出规则区域，如标出按钮位置、圈出表格中的一块区域。

**操作步骤**：

1. 点击「矩形」或「圆形」；
2. 在属性面板设置颜色、粗细、不透明度；
3. 按住左键从起点拖到终点，松开完成绘制；
4. 绘制后可再次编辑（见[编辑已有标注](#编辑已有标注)）。

**示例**：用红色矩形框出表单中填写错误的输入框。

**注意**：两者均为空心描边形状，不填充；若想高亮底图而非画框，改用「荧光笔」。

### 箭头

**用途**：指向某个具体元素，说明因果关系或操作去向。

**操作步骤**：

1. 点击「箭头」；如需更换样式，点击按钮右侧的**下拉小箭头**，在 8 种样式中切换；
2. 按住左键从起点拖到终点，松开完成，箭头由起点指向终点；
3. 绘制后可整体移动、缩放。

**示例**：用箭头从「设置按钮」指向「弹出的菜单」，说明点击后的去向。

**注意**：拖拽方向决定箭头指向，画反了可撤销重画或选中后调整。

### 荧光笔

**用途**：半透明高亮，模拟真实荧光笔涂划效果，不遮挡底图内容。

**操作步骤**：

1. 点击「荧光笔」；
2. 选择颜色与粗细；
3. 按住左键在需要强调的文字、区域上涂抹。

**示例**：用黄色荧光笔涂划合同截图中的关键条款文字。

**注意**：荧光笔本身即半透明，无需也不提供不透明度调节。

### 马赛克

**用途**：块状像素化处理，遮挡敏感信息。

**操作步骤**：

1. 点击「马赛克」；
2. 在属性面板调整笔刷**粗细**；
3. 按住左键在需要遮挡的内容上涂抹，涂过的区域立即像素化。

**示例**：涂抹聊天记录中的手机号、头像。

**注意**：涂抹区域不可恢复为原图（只能撤销整笔）；请确认遮挡完全，必要时多涂几笔。

### 高斯模糊

**用途**：柔和模糊处理，效果比马赛克更平滑，适合不想明显暴露「被打码」轮廓的场景。

**操作步骤**：与「马赛克」相同——选中工具、调整粗细、涂抹目标区域。

**示例**：模糊背景中的个人信息面板，保留整体画面感。

**注意**：同样只有「粗细」可调；强遮挡需求建议选马赛克。

### 文字

**用途**：在截图上直接添加文字说明。

**操作步骤**：

1. 点击「文字」；
2. 在属性面板设置颜色、粗细（即字号）、不透明度；
3. 在目标位置**单击**落点，出现输入框后直接输入；
4. 输入中按 `Enter` 换行，滚动**滚轮**可实时调整文字粗细；
5. 按 `Ctrl + Enter`（macOS 为 `Cmd + Enter`）提交，按 `Esc` 放弃本次编辑。

**示例**：在按钮旁添加「点击这里登录」的指引文字。

**注意**：提交前别点输入框以外的区域；未提交就按 `Esc` 会丢失已输入的内容。

### 序号

**用途**：生成数字徽标标记操作顺序，适合多步骤操作教程。

**操作步骤**：

1. 点击「序号」；如需指定起始数字或关闭自动递增，点击按钮右侧的**下拉小箭头**设置；
2. 依次单击各个落点，生成 1、2、3…徽标，**自动递增**；
3. 徽标颜色、粗细在属性面板调整，已生成的徽标可选中移动。

**示例**：在设置页面截图上依次标出 ①②③ 三步操作位置。

**注意**：撤销会带动序号回退（如撤销 ③ 后再落点是 ③，不会跳到 ④）；「自动递增」关闭后，每次落点都使用同一数字。

## 属性面板

选中大多数工具后，面板自上而下提供三行设置：

| 设置项 | 内容 | 说明 |
| --- | --- | --- |
| 颜色 | 9 个预设色块 | 点击即切换，当前色块高亮 |
| 粗细 | 细 / 中 / 粗 / 特粗四档 | 影响线条或笔画宽度 |
| 不透明度 | 5%–100% 滑块 | 拖动实时生效 |

**例外**：马赛克与高斯模糊只使用笔刷大小，面板只显示「粗细」一行；荧光笔本身即半透明，无需不透明度调节。

## 编辑已有标注

| 操作 | 方法 |
| --- | --- |
| 选中 | 点击已绘制的标注（矩形、圆形、箭头、序号可选中；画笔笔迹不可选中） |
| 缩放 | 拖动四周的八向控制点；边框显示在图形外围，不会遮挡笔迹 |
| 移动 | 按住标注整体拖动 |
| 删除 | 选中后按 `Ctrl + Z` 撤销该步 |

**范围限制**：所有标注严格限制在框选区域内，无法画出选区之外，导出的图片不会缺角。

## 撤销与重做

| 快捷键 | 动作 |
| --- | --- |
| `Ctrl + Z`（macOS 为 `Cmd + Z`） | 撤销上一步 |
| `Ctrl + Shift + Z`（macOS 为 `Cmd + Shift + Z`） | 重做 |

工具栏上的「撤销 / 重做」按钮功能相同。撤销 / 重做同样作用于序号：撤销后序号自动回退，重做后继续，不会跳号或重复。

::::tip
不透明度通过画笔颜色生效，画笔、矩形、圆形、箭头、文字、序号均支持；荧光笔本身就是半透明效果，无需额外调整。
::::
