# 标注与编辑

## 选择标注工具

框选完成后，在工具栏中选择工具。当前使用的工具会高亮显示，工具栏下方弹出**属性面板**，可即时调整样式。

## 标注工具一览

| 工具 | 用法 |
| --- | --- |
| 画笔 | 自由绘制；属性面板可调颜色、粗细、不透明度 |
| 矩形 / 圆形 | 拖拽绘制；选中后可通过控制点缩放、整体拖动 |
| 箭头 | 拖拽绘制；点击箭头按钮右侧的下拉小箭头，可在 8 种样式间切换 |
| 荧光笔 | 半透明高亮效果，适合圈重点；不遮挡底图 |
| 马赛克 / 高斯模糊 | 在截图上涂抹，遮挡敏感信息；只有「粗细」可调 |
| 文字 | 单击落点后直接输入；编辑中按 `Ctrl + Enter` 提交，`Esc` 放弃；编辑中滚动滚轮可调整笔画粗细 |
| 序号 | 单击落点生成数字徽标，落图后自动递增；点击下拉小箭头可直接指定起始数字、开关「自动递增」 |

## 属性面板

选中大多数工具后，面板自上而下提供三行设置：

- **颜色**：9 个预设色块；
- **粗细**：细 / 中 / 粗 / 特粗四档；
- **不透明度**：5%–100% 滑块，实时生效。

马赛克与高斯模糊只使用笔刷大小，因此面板只显示「粗细」一行。

## 编辑已有标注

- **选中**：点击已绘制的标注（矩形、圆形、箭头、序号可选中）；
- **缩放**：拖动四周八向控制点，边框显示在图形外围，不会遮挡笔迹；
- **移动**：按住标注整体拖动；
- **范围限制**：所有标注严格限制在框选区域内，导出的图片不会缺角。

## 撤销与重做

| 快捷键 | 动作 |
| --- | --- |
| `Ctrl + Z`（macOS 为 `Cmd + Z`） | 撤销上一步 |
| `Ctrl + Shift + Z`（macOS 为 `Cmd + Shift + Z`） | 重做 |

撤销 / 重做同样作用于序号：撤销后序号自动回退，重做后继续，不会跳号或重复。工具栏上的「撤销 / 重做」按钮功能相同。

:::tip
不透明度通过画笔颜色生效，画笔、矩形、圆形、箭头、文字、序号均支持；荧光笔本身就是半透明效果，无需额外调整。
:::
