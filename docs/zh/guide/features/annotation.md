# 标注与编辑

框选完之后，工具栏左边九个工具用来在截图上圈重点、遮住敏感信息、加说明或标出操作步骤。这一页按工具讲**怎么画**，以及画完还能**怎么改**。

## 九个工具，怎么选

**画笔 → 矩形 → 圆形 → 箭头 → 荧光笔 → 马赛克 → 高斯模糊 → 文字 → 序号**

- 圈画不规则区域：画笔；框出一块：矩形 / 圆形；指个方向：箭头；
- 涂重点：荧光笔；遮手机号、头像：马赛克 / 高斯模糊；
- 加一句说明：文字；标「第一步、第二步」：序号。

画笔 / 矩形 / 圆形 / 箭头 / 荧光笔 / 文字 / 序号这 7 个按钮右边有个**小三角**：

- 点**主按钮**：切到这个工具开始画；
- 点**小三角**：打开它的属性弹窗，不会切走当前工具；
- 再点一次**当前工具的主按钮**：开 / 关弹窗，不用精确瞄准小三角。

马赛克 / 高斯模糊没有弹窗，换成工具栏下方一行由细到粗的线条，点一下选笔刷大小。

## 属性弹窗里能调什么

点小三角，会弹出最多三行设置；弹窗里不写行名，看图就能认出来：

| 你想调 | 怎么调 |
| --- | --- |
| 颜色 | 9 个预设色块，点一下切换，当前色会高亮；鼠标停上去能看到色值 |
| 粗细 | 细 / 中 / 粗 / 特粗四档线条预览，悬停显示如「中 (4px)」；文字工具下这一行是**字号** |
| 不透明度 | 5%–100% 滑块，拖动或滚轮；拖动时手柄上方会浮出百分比 |

箭头的弹窗最上面多一组 **8 种样式**预览，序号的弹窗最下面多一行序号设置（数值框 / − / + / 自动递增）。

- 弹窗**不抢鼠标**：可以边调边在画布上继续画，选完也不会自动关；
- 在弹窗里选任何一项，就等于**选中了这个工具**，可以直接开画；
- **一次只会开一个弹窗**；打开弹窗时，马赛克 / 模糊那一行会先收起来，关掉弹窗再回来；
- 关掉弹窗：再点一次小三角 / 主按钮，或按 `Esc`。重新框选、切到 GIF 录制、拖动贴图窗口时也会自动收起；**在画布上落笔不会关**，可以调一半去画，再回来接着调。

:::tip
弹窗里的颜色和粗细，跟「设置 → 标注设置」是同一套。截图这一轮里改的只影响这张图，不会改掉你的默认值（见[标注默认值](#标注默认值)）。
:::

## 各工具怎么用

### 画笔

按住左键拖着画，松开算一笔，可以单独撤销。画错的笔迹**选不中修改**，`Ctrl + Z` 撤销后重画。

### 矩形 / 圆形

拖拽画出来，画的时候按住 `Shift` 会变成**正方形 / 正圆**（中途按下或松开都立刻生效）。松手后图形自动选中，出现八个控制点：

| 你想做什么 | 怎么做 |
| --- | --- |
| 缩放、翻转 | 拖四角控制点；按住 `Shift` 同样保持正方形 / 正圆 |
| 只动一条边 | 拖四边中间的控制点（`Shift` 对它没用） |
| 整个挪走 | 按住图形内部拖动 |
| 调边框粗细 | 在图形上滚轮（1–40） |

两者都是**空心描边**，想给底图上色请用荧光笔。

### 箭头

点「箭头」拖一下，箭头从起点指向终点。要换样式，在弹窗最上面的 8 种预览里点一个。松手后出现起点 / 中点 / 终点三个控制点：

| 你想做什么 | 怎么做 |
| --- | --- |
| 改尾部或指向 | 拖起点 / 终点 |
| 把箭头掰弯 | 拖中点，往哪拖就往哪弯 |
| 整个挪走 | 拖箭杆或箭头本体 |
| 调粗细 | 在箭头上滚轮（1–40） |

**箭头配文字**：箭头弹窗右下角有个文字图标开关「文字标注」。打开后画完箭头，会**在箭头起点自动打开输入框**；写完字，文字和箭头绑成一组：

- 拖箭头或文字，另一个跟着走；
- 拖文字时整支箭头绕终点转（箭头还在选中状态时才拖得动）；
- 双击文字可以改字；
- 撤销 / 重做两个一起进退，不会出现「字还在、箭头没了」；
- 这个开关每轮截图开始时都会复位为关。

### 荧光笔

半透明涂划，不遮住底下的内容；线宽是所选粗细的 2 倍，颜色 / 粗细 / 不透明度都能调。

### 马赛克 / 高斯模糊

1. 选中工具，在工具栏下方点一个线条档位（就是笔刷大小）；
2. 按住左键涂抹，涂过的地方立刻被打码。

只有笔刷大小可调，没有颜色和不透明度。马赛克是块状像素化，遮得更彻底；高斯模糊更柔和，不容易看出「这里被打码了」。涂抹**不能局部还原**，只能整笔撤销。

### 文字

1. 选「文字」，在弹窗里设颜色 / 字号 / 不透明度；
2. 在要写字的地方**单击**，出现输入框后直接输入；
3. `Enter` 换行，`Ctrl + Enter`（macOS 用 `Cmd + Enter`）提交；
4. 已写好的字：单击选中（这时点弹窗色块就能改它的颜色），双击进入改字；
5. 输入中滚滚轮可以微调字号（3–40，比弹窗四档更细）。

| 你做了什么 | 会怎样 |
| --- | --- |
| `Ctrl + Enter` | 提交 |
| 点选区内的空白处 | 先提交，再在点击处另起一段 |
| 点选区外 | 只提交，不再开新框 |
| 点另一条文字 | 先提交；单击选中它（可改色 / 拖动），双击改字 |
| 切到别的工具 | 提交，字不会丢 |
| 输入中点弹窗色块 | 只换这段的颜色，**输入不中断** |
| 清空后提交 | 相当于删掉这段文字（可用重做找回） |
| `Esc` | 放弃这次编辑；改字时还原原文 |

### 序号

1. 选「序号」，弹窗里用 −/+ 或直接输入设置**当前序号**（1–9999），也能关掉「自动递增」。每轮截图从几开始（1–999）在「设置 → 标注设置」里改；
2. **按住拖一下**：在按下点放圆形徽章、箭头指向松开点；**单击**：只放一个圆徽章；
3. 每放一个自动 +1（1、2、3…）；
4. 松手后拖**尖端的控制点**改指向，按住**徽章**整体挪走；单击放下的纯圆徽章没有尖端；
5. 在选中的序号上滚滚轮：指针在徽章上改徽章大小（2–40），在箭头上改箭头粗细（1–40），互不影响。

序号不跨截图保留，每轮都从起始值开始；撤销 / 重做会带着序号回退 / 前进，不会跳号；关掉「自动递增」后，每次都是同一个数字。

## 画完还能改吗

规则很简单：**只有最近画的那一个能改**。

| 状态 | 你能做什么 |
| --- | --- |
| 刚画完、还选中着 | 拖控制点缩放、拖本体移动、滚轮调粗细，都行 |
| 又画了新图形、切了工具、撤销 / 重做过 | 旧的就冻结了，按上去等同点在空白处，会开始新的一笔 |

所以要改旧标注，撤销后重画；趁当前这一笔还选中，直接拖控制点最快。

标注不会画到框选区域外面，导出的图不会缺角；选中时冒出来的控制点和描边可以露在选区外，但**不会进导出的图**。马赛克 / 模糊靠边涂抹时会稍微超出选区，超出部分导出后自然裁掉。

## 撤销与重做

| 按键 | 动作 |
| --- | --- |
| `Ctrl + Z`（macOS 用 `Cmd + Z`） | 撤销上一步 |
| `Ctrl + Shift + Z`（Windows 也能用 `Ctrl + Y`） | 重做 |

工具栏上的两颗按钮作用一样，没得撤销 / 重做时会变灰。

## 标注默认值

每个工具的**默认颜色 / 粗细 / 不透明度 / 箭头样式 / 序号起始值与自动递增**，都在「**设置 → 标注设置**」里改；截图和贴图共用这一套。

| 工具 | 颜色 | 粗细 | 不透明度 | 其他 |
| --- | --- | --- | --- | --- |
| 画笔 | `#F43F5E` | 粗（6） | 100% | — |
| 矩形 | `#F43F5E` | 粗（6） | 100% | — |
| 圆形 | `#F43F5E` | 粗（6） | 100% | — |
| 箭头 | `#F43F5E` | 粗（6） | 100% | 样式：实心 |
| 荧光笔 | `#F43F5E` | 粗（6） | 100% | — |
| 马赛克 | — | 粗（6） | — | — |
| 高斯模糊 | — | 粗（6） | — | — |
| 文字 | `#F43F5E` | 粗（6，即字号） | 100% | — |
| 序号 | `#F43F5E` | 粗（6） | 100% | 起始值 1、自动递增开 |

- 粗细只有四档：细 2 / 中 4 / 粗 6 / 特粗 10；
- 默认值在**开始标注时**才生效，截图过程中的临时调整不会写回设置；
- 想全部还原，点标注设置页的「恢复默认设置」。
