# 标注与编辑

## 九个标注工具

框选完成后，工具栏左侧是 9 个标注工具，从左到右依次为：

**画笔 → 矩形 → 圆形 → 箭头 → 荧光笔 → 马赛克 → 高斯模糊 → 文字 → 序号**

其中 **画笔 / 矩形 / 圆形 / 箭头 / 荧光笔 / 文字 / 序号** 这 7 个按钮右侧带一个小三角：

- 点**主按钮** = 切到该工具并开始绘制；
- 点**小三角** = 展开该工具的属性弹窗（不切换当前工具）；
- **再点一次「已经是当前工具」的主按钮** = 开 / 关它的属性弹窗（不用精确瞄准小三角）。

**马赛克 / 高斯模糊**没有弹窗，改用工具栏下方的小面板，只提供「粗细」一行。

## 属性弹窗

7 个带弹窗的工具按需显示下面三行（顺序固定）：

| 行 | 内容 | 说明 |
| --- | --- | --- |
| 颜色 | 9 个预设色块 | 点击切换，当前色高亮；鼠标悬停显示十六进制色值 |
| 粗细 | 细 / 中 / 粗 / 特粗 四档 | 以对应粗细的线条预览图标呈现，悬停提示如「中 (4px)」；文字工具下这一行是**字号**，马赛克 / 模糊下是**笔刷大小** |
| 不透明度 | 5% – 100% 滑块 | 拖动或滚轮调节，拖动时在手柄上方浮出百分比读数 |

- 弹窗打开时**不抢鼠标**：可以边调参数边在画布上继续画，选项后弹窗不会自动关闭；
- 在弹窗里选任何一项（色块、粗细、滑块、开关）即视为**选中该工具**并进入绘制态；
- 关闭弹窗：再点小三角 / 主按钮，或按 `Esc`。

:::tip
弹窗里的颜色与粗细就是「设置 → 标注设置」中的同一套取值。当前截图会话内的改动只影响这一次截图，不会写回默认值（见[标注默认值](#标注默认值)）。
:::

## 各工具用法

### 画笔

自由手绘，适合圈画不规则区域、手写补充说明。

1. 选择「画笔」（或展开属性弹窗挑颜色 / 粗细 / 不透明度）；
2. 按住左键拖动绘制，松开完成一笔；
3. 每笔算一步，可单独撤销。

画错的笔迹**无法选中修改**，请用 `Ctrl + Z` 撤销后重画。

### 矩形 / 圆形

框出规则区域，如标出按钮位置、圈出表格中的一块。

1. 选择「矩形」或「圆形」；
2. 拖拽绘制；绘制中按住 `Shift` 收敛为**正方形 / 正圆**（中途按下或松开实时生效）；
3. 松开后图形**自动进入选中态**，出现八个控制点。

绘制完成后（仍在选中态）可以：

| 操作 | 效果 |
| --- | --- |
| 拖动四角控制点 | 以对角为锚缩放，可翻转 |
| 拖动四边中点控制点 | 只调整该边 |
| 按住图形内部拖动 | 整体移动 |
| 在图形上滚动滚轮 | 调整边框粗细（±1，1–40） |

两者都是**空心描边**、不填充；想高亮底图而非画框，请用「荧光笔」。

### 箭头

用于指向具体元素、说明因果或操作去向。

1. 点「箭头」；需要换样式时展开属性弹窗，在 **8 种样式预览**中点选；
2. 拖拽绘制，箭头由起点指向终点；
3. 松开后自动进入选中态，出现**起点 / 中点 / 终点三个控制点**：

| 操作 | 效果 |
| --- | --- |
| 拖起点 / 终点控制点 | 调整尾部与指向 |
| 拖中点控制点 | 把箭头弯成二次贝塞尔曲线，拖哪弯哪 |
| 拖箭杆 / 箭头本体 | 整体平移 |
| 在箭头上滚动滚轮 | 调整箭头粗细（±1，1–40） |

**箭头 + 文字（联动）**：箭头属性弹窗右下角有一个文字图标开关「文字标注」。打开后，画完箭头（拖拽距离足够）会在**箭头起点**自动打开一段文字输入框；落字后文字与箭头**绑成一体**：

- 拖动箭头或文字，另一个跟着走；拖起点时文字留在起点侧；
- 拖动联动文字 = 整支箭头绕终点旋转（文字工具与箭头工具下都可拖）；
- 双击联动文字可直接改字；
- 撤销 / 重做同进同退，不会出现「文字还在、箭头没了」的半截状态；
- 该开关在每轮截图开始时复位为关。

### 荧光笔

半透明高亮，模拟真实荧光笔涂划，不遮住底图内容。线宽按设定粗细的 2 倍绘制，可调颜色 / 粗细 / 不透明度，适合涂划文字重点。

### 马赛克 / 高斯模糊

用于遮挡手机号、头像、身份证号等敏感信息。

1. 选择工具；
2. 在工具栏下方的面板里选「粗细」（即笔刷大小）；
3. 按住左键涂抹，涂过的区域立即被像素化 / 模糊。

- 两者都只有「粗细」可调，没有颜色与不透明度；
- 马赛克是块状像素化，遮挡更彻底；高斯模糊更柔和，适合不想暴露「被打码」轮廓的场景；
- 涂抹不可局部还原，只能整笔撤销。

### 文字

在截图上直接添加文字说明。

1. 选择「文字」，在属性弹窗里设置颜色 / 字号（粗细行）/ 不透明度；
2. 在目标位置**单击**落点，出现输入框后直接输入；
3. `Enter` 换行，`Ctrl + Enter`（macOS 为 `Cmd + Enter`）提交；
4. 已落图的文字：在文字工具下**单击选中**（点属性弹窗色块即可改这条文字的颜色），**双击进入改字**；
5. 输入中滚动**滚轮**可实时微调字号（3–40，比属性弹窗的四档更细）。

提交与出口：

| 操作 | 结果 |
| --- | --- |
| `Ctrl + Enter` | 提交 |
| 点画布别处 / 点另一条文字 | 先提交上一段，再在点击处继续 |
| 切换到其他工具 | 提交（不丢字） |
| 输入中点属性弹窗色块 | 只换这一段的颜色，**输入不中断** |
| 清空内容后提交 | 相当于**删除**这段文字（可用重做找回） |
| `Esc` | 放弃本次编辑（改字时还原为原文；清空后按 `Esc` 是还原，不是删除） |

### 序号

生成数字徽标标记操作顺序，适合多步骤教程。

1. 选择「序号」；需要指定起始值或关闭自动递增时，展开属性弹窗设置（「起始值」1–999，当前序号数值框可设 1–9999、自动递增开关）；
2. **按下并拖动** = 在按下点放圆形徽章、箭头指向松开点；**单击**（不拖动）= 只放一个纯圆形徽章；
3. 每落一个自动递增（1、2、3…）；
4. 松开后进入选中态：拖**尖端控制点**改指向，按住**徽章**整体拖动；
5. 在选中序号上滚动滚轮：指针在徽章上改**徽章大小**，在箭头杆 / 箭头头上改**箭头粗细**（两者互不影响）。

- 序号值不跨截图保留：每轮截图从起始值重新开始；
- 撤销 / 重做会带动序号回退 / 前进，不会跳号；手动改过的值不会被重算抹掉；
- 关闭「自动递增」后，每次落点都用同一个数字。

## 编辑已有标注

标注遵循「**只有最近画的那一个可以编辑**」的规则（冻结规则）：

| 状态 | 行为 |
| --- | --- |
| 刚画完，仍在选中态 | 可拖控制点缩放、拖本体移动、滚轮调粗细 |
| 又画了新图形 / 切了工具 / 撤销重做后 | 旧图形**冻结**，按下它等同于按下空白处，开始新的一笔 |

因此要改旧标注，常用做法是撤销后重画；调整当前这一笔则直接拖控制点。

**范围限制**：标注图形本体（马赛克 / 高斯模糊除外）严格限制在框选区域内，画不出选区之外，导出的图片不会缺角。选中图形的控制点与描边等装饰画在图形笔迹**外围**，允许越出选区显示，但**不会进入导出的图片**；马赛克 / 模糊的笔刷落点按原位置生效，靠边涂抹时边缘可能超出选区（超出部分导出后自然裁掉）。

## 撤销与重做

| 快捷键 | 动作 |
| --- | --- |
| `Ctrl + Z`（macOS 为 `Cmd + Z`） | 撤销上一步 |
| `Ctrl + Shift + Z`（macOS 为 `Cmd + Shift + Z`） | 重做 |

工具栏上的「撤销 / 重做」按钮功能相同，无可撤销内容时按钮为禁用态。

## 标注默认值

每个工具的**默认颜色 / 粗细 / 不透明度 / 箭头样式 / 序号起始值与自动递增**都可以在「**设置 → 标注设置**」里修改，截图浮层与贴图窗口共用这一套默认值。

| 工具 | 颜色 | 粗细 | 不透明度 | 其他 |
| --- | --- | --- | --- | --- |
| 画笔 | `#F43F5E` | 粗（6） | 100% | — |
| 矩形 | `#F43F5E` | 粗（6） | 100% | — |
| 圆形 | `#F43F5E` | 粗（6） | 100% | — |
| 箭头 | `#F43F5E` | 粗（6） | 100% | 样式：实心 |
| 荧光笔 | `#F43F5E` | 粗（6） | 100% | — |
| 马赛克 | — | 粗（6） | — | — |
| 高斯模糊 | — | 粗（6） | — | — |
| 文字 | `#F43F5E` | 粗（6，即字号） | 100% | — |
| 序号 | `#F43F5E` | 粗（6） | 100% | 起始值 1、自动递增开 |

- 粗细只有四档：细 2 / 中 4 / 粗 6 / 特粗 10；
- 默认值只在**开始标注时**生效（新一轮截图 / 新选中工具时铺开），标注过程中的临时改动不写回设置；
- 想全部恢复出厂设置，点标注设置页的「恢复默认设置」。
