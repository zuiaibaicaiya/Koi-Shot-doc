# 长截图、GIF 与录屏

## 长截图

当一屏放不下网页、聊天记录或列表时，用长截图自动滚动拼接成一张长图。

### 使用步骤

1. 按 `F1` 进入截图，先框选要截取的起始区域（后续滚动都在这个宽度内拼接）；
2. 点击工具栏「长截图」按钮，选区外出现**控制条**与**「长截图预览」窗口**，控制条提示「点击开始后，滑动内容自动拼接」；
3. 点控制条上的「**开始**」，然后**滚动原始内容**（鼠标滚轮、拖动滚动条、触控板均可），koiShot 会自动识别滚动并逐段拼接；
4. 控制条与预览窗实时显示已捕获的帧数与拼接效果；
5. 滚动到目标位置后点「**完成**」，长图会**自动保存为 `long_日期_时间.png` 并同时复制到剪贴板**（保存位置见[保存与输出](/zh/guide/features/output)）。

- 还没开始就改变主意：点控制条「关闭」，或按 `Esc`；
- 录制中按 `Esc` 等同点「完成」停止并出图；
- 若一直没检测到有效滚动，会提示「未检测到有效滚动」，请先激活目标窗口（例如点一下浏览器）再重试。

### 使用建议

- 滚动保持**匀速、幅度适中**，拼接更稳；
- 页面里的**吸顶导航 / 固定页脚**只会在长图里出现一次，不会每屏重复；
- 适合静态内容；页面含动画、视频或滚动时自身有视差效果时可能出现错位，可分段截取后用多张拼接；
- 长截图按帧累积，内容很长时建议分段，避免单张图过大。

## GIF 录制

把选区内的操作过程录成 GIF 动图，适合在聊天、工单里展示简短交互。

### 使用步骤

1. 按 `F1` 进入截图，框选录制区域（即 GIF 的画面范围）；
2. 点击工具栏「录制 GIF」——**不会立即开录**，只弹出录制条进入**待开始**状态：红色选区框保持显示，计时与帧数为 0，可再确认或调整范围；
3. 点录制条上的「**开始录制**」正式开始抓帧，进行要展示的操作；录制条实时显示状态、时长与已捕获帧数；
4. 点「**完成录制**」停止，录制条显示「导出中」，GIF 生成并自动保存为 `gif_日期_时间.gif`；
5. 中途放弃点「取消录制」，已捕获的帧直接丢弃，不生成文件。

### 录制条位置

录制条默认贴在选区下方、与选区右对齐，空间不足时自动退让：

- 选区贴近屏幕底部时，自动翻转到选区上方；
- 选区盖住任务栏（macOS 为菜单栏与 Dock）时，自动避开系统区域；
- 极端情况下（如接近全屏录制）自动夹回屏幕内，始终完整可见。

### 录制上限

GIF 有**帧数与总像素双重上限**，不会生成超大文件：

- 帧数上限 = 帧率 × 30，即单次最多约 **30 秒**（默认 15 帧/秒时 450 帧）；
- 选中区域越大，允许的帧数越少（按总像素量计算），达到上限会**自动停止录制**；
- 建议框选只包含要演示的内容，避免全屏录制。

### 帧率与体积预设

可在「设置 → 通用设置 → GIF 录制」中调整（详见[设置与托盘](/zh/guide/settings)）：

| 设置项 | 说明 |
| --- | --- |
| 帧率 | 5 / 10 / 15 / 20 / 25 / 30 帧/秒（默认 15）。帧率越高画面越流畅、文件越大 |
| 体积预设 | 高质量（抖动更细腻、文件较大）/ 均衡（推荐日常使用）/ 小体积（适合聊天窗口、工单附件等有大小限制的场合） |

## 录屏（MP4）

需要**带声音**、**时长更长**或**画质更好**时，用录屏代替 GIF。

### 使用步骤

1. 按全局快捷键 `Alt + R`（或在截图工具栏点「录屏」）；
2. 框选要录制的区域——**快捷键入口松手即出现录制条**（待开始状态），工具栏入口则是点「录屏」后出现；
3. 点「**开始录制**」正式开始，进行要演示的操作；录制条显示 `REC`、已录制秒数与帧数；
4. 点「**完成录制**」停止，录制条显示「正在导出视频」，完成后自动保存为 `koiShot_日期_时间.mp4`；
5. 中途放弃点「取消录制」，半成品文件会被删除。

### 规则与限制

| 项 | 说明 |
| --- | --- |
| 时长上限 | 单次最长 **10 分钟**，到达上限自动停止并导出 |
| 帧率 | 10–30 帧/秒（默认 30），在「设置 → 通用设置 → 录屏（MP4）」中调整 |
| 声音 | 默认采集麦克风；关闭开关或未授权麦克风时自动降级为无声录制，画面不受影响 |
| 选区 | 开始录制即锁定编码分辨率，**录制中不能改选区** |
| 抓帧 | macOS 走系统原生抓帧（30fps），其它情况回退到兼容抓帧（约 10fps） |

::::tip
录制区域越小、时间越短，成品越清晰、体积越小。GIF 适合几秒的短演示；需要讲解、配音或超过 30 秒时请用录屏。
::::
