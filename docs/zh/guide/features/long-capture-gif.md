# 长截图、GIF 与录屏

一屏放不下的内容、一段要给别人看的操作，用这一页的三种功能。先挑一个：

| 你想做什么 | 用哪个 |
| --- | --- |
| 把整页网页、聊天记录存成一张长图 | **长截图** |
| 录几秒操作，发到聊天或工单里 | **GIF 录制**（自动循环、体积小） |
| 需要声音、讲解，或超过 30 秒 | **录屏（MP4）** |

三种都是先框选、再点工具栏按钮，最后点「完成」自动存到保存目录。

## 长截图

### 怎么用

1. 按 `F1`，框选要截取的起始区域（长图的宽度就是它）；
2. 点工具栏「长截图」，选区旁出现**控制条**和**预览窗**：控制条在右下角（放不下会翻到上方），预览窗优先在右侧；
3. 点控制条上的「**开始**」（▶），然后**滚动原来的页面**（滚轮、滚动条、触控板都行），koiShot 会边滚边拼；
4. 预览窗里能实时看到已经拼进去的内容；
5. 滚到想要的位置，点「**完成**」（✓）——长图自动保存为 `long_日期_时间.png`，**同时已经复制到剪贴板**，可以直接粘贴（保存位置见[保存与输出](/zh/guide/features/output)）。

:::tip
点「开始」之前，鼠标在选区里滚动会被拦住（防止误操作）：先把页面滚到起点，再把光标移出选区滚动。点「开始」之后就恢复正常。待开始阶段按住选区内部拖动，可以整体挪动截取范围。
:::

控制条上只有三颗图标按钮，悬停会显示名称：开始 ▶ / 完成 ✓ / 取消 ✕。

| 你遇到什么 | 怎么做 |
| --- | --- |
| 还没开始就不想截了 | 点「取消」（✕）或按 `Esc` |
| 滚到一半想放弃 | 点「取消」——已截的内容全部丢弃，不出图也不进剪贴板 |
| 想保留已经拼好的部分 | 点「完成」，或按 `Esc`（录制中等同「完成」） |
| 提示「未检测到有效滚动」 | 先点一下目标窗口（比如浏览器）让它处于前台，再点「开始」重新匀速滚动 |

### 拼得更稳的小技巧

- 匀速、幅度适中地滚，别猛地一甩；
- 中途往回滚看一眼也没关系，重复的部分会自动去掉；
- 吸顶导航、固定页脚在长图里只出现一次；
- 个别画面接不上时 koiShot 会等下一次滚动，宁可少一帧也不会拼歪；
- 动画、视频、滚动视差容易错位，建议分段截；内容特别长时也分段，免得单张图太大。

## GIF 录制

### 怎么用

1. 按 `F1`，框住要录的区域（这就是 GIF 的画面范围）；
2. 点工具栏「录制 GIF」——**不会立刻开录**，先出现录制条和带主题色描边的选区，方便你再确认一次范围；
3. 点录制条上的「**开始录制**」，开始演示操作；条上会显示时长和已录帧数；
4. 点「**完成录制**」，显示「导出中」，生成后自动保存为 `gif_日期_时间.gif`；
5. 中途不想要了，点「取消录制」，已录的全部丢弃。

录制条的按钮都是图标，悬停看名称：待开始时只有开始和取消，开录后开始变成完成，导出中完成与取消都会置灰。

### 开始前可以调整

待开始时按住选区内部拖动，可以整体平移画面范围（只移动、不缩放）；点「开始录制」后就锁定了。**尽量在一块屏幕里框选**：框到两块屏幕上时，只录得到其中一块屏里的部分。

录制条默认贴在选区下方居中，贴近屏幕底边会自动翻到上方，靠边时也会自动夹回屏幕内，始终完整可点。

### 录多久、画质怎么选

- 一次最多约 **30 秒**；画面越大，能录的时间越短，到了上限会自动停止并把已录的部分导出。想录更久请用录屏；
- 照片、视频、渐变这类画面也不会出现大片色带或花屏；
- 「设置 → 通用设置 → GIF 录制」里可以调：

  | 设置项 | 怎么选 |
  | --- | --- |
  | 帧率 | 5–30 帧/秒，默认 15。越高越流畅、文件越大 |
  | 体积预设 | 要清楚选「高质量」；日常用「均衡」；聊天 / 工单有大小限制选「小体积」（画面会更小、帧数更少，文件最小） |

- 录制条上也有帧率下拉：**点「开始录制」之前改就行，这一轮立刻生效**；开录后就不能改了。设置页里改的只是下一次录制的默认值。

## 录屏（MP4）

### 怎么用

1. 按 `Alt + R`，或在截图工具栏点「录屏」；
2. 框选要录的区域，松手后出现录制条（待开始状态）；
3. 确认范围后点「**开始录制**」；
4. 录制条显示 `REC` 和已录时长。需要停一下就点「**暂停录制**」（❚❚），再点「**继续录制**」（▶）接着录——**暂停的时间不算进时长，成片里也不会出现一段静止画面**；
5. 点「**完成录制**」，等「正在导出视频」结束，文件自动保存为 `koiShot_日期_时间.mp4`；
6. 中途放弃点「取消录制」，半成品会被删掉。

录制条的按钮和 GIF 一样是图标 + 悬停提示；录屏多了「暂停 / 继续」和帧率下拉。

### 录之前知道这几点

| 项目 | 说明 |
| --- | --- |
| 最长多久 | 一次 **10 分钟**（暂停不计时），到点自动停止并导出 |
| 声音 | 默认录麦克风；关掉开关或系统没给麦克风权限时，会录成无声视频，画面不受影响 |
| 帧率 | 10–60 帧/秒，默认 30。点开始前在录制条下拉里选，开录后不能再改 |
| 系统要求 | Windows 10 1903 以上、无需额外授权；macOS 需 12.3 以上并授予「屏幕录制」权限；Linux 或老机器上画面可能只有约 10 帧/秒 |
| 画面范围 | 开录后不能改；成品宽高可能与框选差 1 像素。跨屏框选会明显掉帧，尽量单屏录 |
| HDR 屏幕 | 亮部不再一片白。录到一半去改系统的 HDR 开关，这一段可能录不到画面或重新泛白，重新录一次就好 |
| 导出期间 | 上一段还在导出时不能开始新录制，等提示消失即可 |

:::tip
框得越小、录得越短，成片越清楚、文件也越小。演示操作用 30–60 帧/秒就够了；如果点「开始录制」后约 5 秒还没进入录制，会提示编码器启动超时——把帧率调低或关掉麦克风再试一次。

Windows 上录 GIF 时，某些半透明悬浮窗可能不在画面里，普通窗口不受影响。
:::
