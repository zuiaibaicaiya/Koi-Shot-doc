# 长截图、GIF 与录屏

## 长截图

当一屏放不下网页、聊天记录或列表时，用长截图自动滚动拼接成一张长图。

### 使用步骤

1. 按 `F1` 进入截图，先框选要截取的起始区域（后续滚动都在这个宽度内拼接）；
2. 点击工具栏「长截图」按钮，选区外出现**控制条**与**「长截图预览」窗口**：控制条贴在选区右下角（下方放不下时翻到上方），预览窗优先出现在选区右侧（右侧放不下翻到左侧），控制条提示「点击开始后，滑动内容自动拼接」；
3. 点控制条上的「**开始**」（▶，悬停提示「开始长截图」），然后**滚动原始内容**（鼠标滚轮、拖动滚动条、触控板均可），koiShot 会自动识别滚动并逐段拼接；
4. 控制条与预览窗实时显示已捕获的帧数与拼接效果；
5. 滚动到目标位置后点「**完成**」（✓，悬停提示「完成长截图」），长图会**自动保存为 `long_日期_时间.png` 并同时复制到剪贴板**（保存位置见[保存与输出](/zh/guide/features/output)）。

:::tip
点「开始」**之前**，选区范围内的滚轮会被选区装饰框截住（用来防止误操作）。请先把页面滚到想开始的位置、再把光标移出选区去滚动内容；点「开始」之后滚轮恢复正常滚动。待开始阶段还可以**按住选区内部拖动**整体平移录制范围（只移动、不改大小）。
:::

控制条是三颗**纯图标按钮**，名称靠悬停提示辨认：开始 ▶ / 完成 ✓ / 取消 ✕。开始与完成按状态互斥显示，取消始终可用。

- 还没开始就改变主意：点控制条「取消」（✕），或按 `Esc`；
- **运行中想放弃**：点「取消」——已采样的帧直接丢弃，既不出图也不写剪贴板，这是唯一「什么都不产出」的出口；
- 录制中按 `Esc` 等同点「完成」：停止并生成当前已拼接的长图；
- 若一直没检测到有效滚动，点「完成」会提示「未检测到有效滚动」，请先激活目标窗口（例如点一下浏览器）再重试。

### 使用建议

- 滚动保持**匀速、幅度适中**，拼接更稳；
- **上下往返滚动都可以**：中途向上滚动回看不会产生错乱内容，回滚部分会被正确去重；
- 页面里的**吸顶导航 / 固定页脚**只会在长图里出现一次，不会每屏重复；
- 个别帧匹配不上时 koiShot 会**等待下一次有效滚动**，宁可丢帧也不产出拼错的内容；
- 适合静态内容；页面含动画、视频或滚动时自身有视差效果时可能出现错位，可分段截取后用多张拼接；
- 长截图按帧累积，内容很长时建议分段，避免单张图过大。

## GIF 录制

把选区内的操作过程录成 GIF 动图，适合在聊天、工单里展示简短交互。

### 使用步骤

1. 按 `F1` 进入截图，框选录制区域（即 GIF 的画面范围）；
2. 点击工具栏「录制 GIF」——**不会立即开录**，只弹出录制条进入**待开始**状态：选区以**主题主色描边**保持显示，计时与帧数为 0，可再确认或调整范围（按住选区内部可拖动位置，见下方「录制条与录制范围」）；
3. 点录制条上的「**开始录制**」图标正式开始抓帧，进行要展示的操作；录制条实时显示状态、时长与已捕获帧数；
4. 点「**完成录制**」停止，录制条显示「导出中」，GIF 生成并自动保存为 `gif_日期_时间.gif`；
5. 中途放弃点「取消录制」，已捕获的帧直接丢弃，不生成文件。

录制条上的三颗按钮都是**纯图标按钮**（开始 / 完成 / 取消），悬停会显示名称：待开始态只显示开始与取消，开录后开始换成完成，导出中完成与取消都置灰。

### 录制条与录制范围

录制条默认贴在选区下方、**水平相对选区居中**，与选区边框间距 12px；空间不足时自动退让：

- 选区贴近屏幕底部时，自动翻转到选区上方；
- 选区盖住任务栏（macOS 为菜单栏与 Dock）时，自动避开系统区域；
- 极端情况下（如接近全屏录制）自动夹回屏幕内，始终完整可见。

:::tip
之所以居中而不是贴右对齐：条的右端正是取消按钮，按住选区右下角想调整范围时很容易误触，把整条录制浮层收掉。

**待开始态可以调整录制范围**：按住选区内部拖动即可整体平移（只移动、不缩放；不能移出当前屏幕）。开录后选区锁定，不能再改。
:::

### 录制上限

GIF 有**帧数与总像素双重上限**，不会生成超大文件：

- 帧数上限 = 帧率 × 30，即单次最多约 **30 秒**（默认 15 帧/秒时 450 帧）；
- 还有**累计总像素预算**（约 3.2 亿像素）：按「帧数 × 选区面积」逐帧累计，选中区域越大，允许录的时间越短（例如 4K 全屏区域约 1 秒内就会触顶）。任一上限达到都会**自动停止录制**并正常导出已录内容；
- 建议框选只包含要演示的内容，避免全屏录制。

### 帧率与体积预设

**录制条上也有帧率下拉**（与录屏共用一套帧率选项）：待开始状态可直接改，正式开录后锁定、录制 / 导出中不可改；设置页里的帧率是默认值，两边取最后一次的选择。

可在「设置 → 通用设置 → GIF 录制」中调整（详见[设置与托盘](/zh/guide/settings)）：

| 设置项 | 说明 |
| --- | --- |
| 帧率 | 5 / 10 / 15 / 20 / 25 / 30 帧/秒（默认 15）。帧率越高画面越流畅、文件越大 |
| 体积预设 | 高质量（抖动更细腻、文件较大）/ 均衡（推荐日常使用）/ 小体积（适合聊天窗口、工单附件等有大小限制的场合） |

## 录屏（MP4）

需要**带声音**、**时长更长**或**画质更好**时，用录屏代替 GIF。

### 使用步骤

1. 按全局快捷键 `Alt + R`（或在截图工具栏点「录屏」）；
2. 框选要录制的区域——**快捷键入口松手即出现录制条**（待开始状态），工具栏入口则是点「录屏」后出现；
3. 待开始态可按住选区内部拖动位置（只平移、不缩放），确认范围后点录制条上的「**开始录制**」图标；
4. 开始后录制条显示 `REC`、已录制时长与「帧率 | MP4」，进行要演示的操作；需要停顿时点「**暂停录制**」（❚❚），录制条切换为「已暂停」，再点「**继续录制**」（▶）接着录——**暂停期间不计入录制时长，也不会被录成静止画面**，成片仍然连贯；
5. 点「**完成录制**」停止，录制条显示「正在导出视频」，导出完成后自动保存为 `koiShot_日期_时间.mp4`；
6. 中途放弃点「取消录制」，半成品文件会被删除。

录制条按钮与 GIF 录制相同：纯图标 + 悬停提示，待开始 / 录制中 / 导出中三种状态的按钮组合会自动切换。

### 规则与限制

| 项 | 说明 |
| --- | --- |
| 时长上限 | 单次最长 **10 分钟**（按实际录制时间累计，**暂停期间不计时**），到达上限自动停止并导出 |
| 暂停 / 继续 | 录制中可随时暂停、继续，次数不限；成片不含暂停时段 |
| 帧率 | 10–60 帧/秒（默认 30），可在录制条下拉或「设置 → 通用设置 → 录屏（MP4）」中调整；可选 10 / 15 / 20 / 24 / 25 / 30 / 50 / 60；开录后锁定 |
| 声音 | 默认采集麦克风；关闭开关或未授权麦克风时自动降级为无声录制（事后会有通知提示），画面不受影响 |
| 选区 | 开始录制即锁定编码分辨率，**录制中不能改选区**；待开始态可平移选区。因视频编码要求尺寸为偶数，成品宽高可能与选区相差 1px。跨屏选区会回退到兼容抓帧（约 10fps） |
| 抓帧 | Windows 走系统图形捕获（WGC，**无需额外授权**，Win10 1903+）；macOS 走 ScreenCaptureKit（需 **macOS 12.3+** 与屏幕录制权限）；Linux 或原生抓帧不可用时回退兼容抓帧（约 10fps） |
| HDR | Windows 在 HDR 显示器上会做色调映射，输出标准 SDR 视频（亮部不再发白）；不会产出 HDR 视频。录制中切换系统 HDR 开关不会生效，需重新开始录制 |
| 导出 | 停止后进入「导出中」，此期间无法开始新录制，会提示「上一段视频仍在导出中」；超时未完成时会强制收口，已成形的文件正常保留 |

:::tip
录制区域越小、时间越短，成品越清晰、体积越小。GIF 适合几秒的短演示；需要讲解、配音或超过 30 秒时请用录屏。帧率越高画面越流畅，但更吃 CPU / 显卡——录操作演示 30–60 帧/秒即可；若点开始后约 5 秒仍未进入录制，koiShot 会提示编码器启动超时，可降低帧率或关闭麦克风后重试。

Windows 上录制 GIF 时，**半透明窗口**（部分悬浮挂件、透明特效窗）可能不会出现在画面里，这是系统抓屏机制的性能取舍，普通窗口不受影响。
:::
