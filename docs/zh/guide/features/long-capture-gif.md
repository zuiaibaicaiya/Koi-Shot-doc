# 长截图与 GIF 录制

## 长截图

当一屏放不下网页、聊天记录或列表时，使用长截图自动滚动拼接。

### 使用步骤

1. 按 `F1` 进入截图，先框选要截取的起始区域；
2. 点击工具栏「长截图」按钮；
3. **滚动原始内容**（鼠标滚轮或拖动滚动条），koiShot 会自动识别滚动并逐段拼接；
4. 屏幕上会出现控制条与**预览浮窗**，随时查看拼接结果；
5. 滚动到目标位置后点击「完成」，长图自动复制到剪贴板，可继续保存为 PNG 文件（命名规则见[保存与输出](/zh/guide/features/output)）。

:::tip
滚动时保持匀速、不要滚动过快，拼接效果更稳定。长截图适合静态内容，页面中有动画或视频时可能出现拼接错位。
:::

## GIF 录制

将选区内的操作过程录制成 GIF 动图，适合展示简短交互。

### 使用步骤

1. 按 `F1` 进入截图，框选录制区域（即 GIF 的画面范围）；
2. 点击工具栏「录制 GIF」按钮，出现**录制条**并进入待开始状态——此时**尚未开始录制**，选区红框保持显示，可确认或重新调整录制范围；
3. 点击录制条上的「开始录制」按钮，正式开始抓帧，进行要展示的操作；录制条上实时显示状态、时长与已捕获帧数；
4. 点击「完成录制」停止，录制条显示「导出中」，GIF 自动生成并保存为 `gif_日期_时间.gif`；
5. 中途想放弃时，点击「取消录制」即可丢弃已捕获的帧，不会生成文件。

### 录制条位置

录制条默认贴在选区下方、与选区右对齐，空间不足时自动退让：

- 选区贴近屏幕底部时，自动翻转到选区上方；
- 选区盖住任务栏（macOS 为菜单栏与 Dock）时，自动避开系统区域；
- 极端情况下（如接近全屏录制）自动夹回屏幕内，始终完整可见。

### 录制上限

GIF 录制有**帧数与总像素双重上限**，不会生成超大文件：

- 帧数上限 = 帧率 × 30，即单次最多录约 **30 秒**（默认 15 帧/秒时为 450 帧）；
- 选中区域越大，允许的帧数越少（按总像素量计算），达到上限会**自动停止录制**并提示；
- 建议框选只包含要演示的内容，避免全屏录制。

### 帧率与体积预设

可在「设置 → GIF 录制」中调整（详见[设置与托盘](/zh/guide/settings)）：

| 设置项 | 说明 |
| --- | --- |
| 帧率 | 5 / 10 / 15 / 20 / 25 / 30 帧/秒（默认 15）。帧率越高画面越流畅、文件越大；低帧率适合静态演示 |
| 体积预设 | 高质量（画面更细腻、文件较大）/ 均衡（推荐日常使用）/ 小体积（适合聊天窗口、工单附件等有大小限制的场合） |

:::tip
录制区域越小、时间越短，GIF 质量越好。需要长时间演示时，建议分段录制。
:::
