# 截图翻译

看到外文界面、外文报错或论文截图，框一下就能拿到译文：**框选 → 识别文字 → 翻译 → 左图右文对照**。翻译取的是框选时的原图，后加的标注不算进去。

结果窗会一直浮在最上面，切到别的窗口也不会被盖住，方便对照着看。

## 第一次用：填一次凭据

翻译服务由阿里云提供，所以第一次使用前要填一次账号凭据（识别文字仍在本机完成）：

1. 打开「**设置 → 通用设置 → 翻译设置**」，用一个已开通阿里云机器翻译的账号；
2. 填入 **AccessKey ID** 与 **AccessKey Secret**：两栏默认掩码，点右侧「眼睛」可以临时看明文；
3. 选**目标语言**（中 / 英 / 日 / 韩 / 法 / 德 / 西 / 俄），这是结果窗默认翻成的语言；
4. 点「**保存**」，再点「**测试翻译**」——它会真的翻一句样例文字，成功或失败直接显示在卡片里。

改完立刻生效，不用重启、也不用重新截图。凭据只保存在这台电脑的本地配置里，不会跟着截图或识别内容上传。

## 怎么翻

1. 按 `F1`，把外文框紧一点，少带无关画面；
2. 点工具栏「**翻译**」（在 OCR 右侧）；
3. 截图界面收起，弹出**结果窗**：左边是「截屏原图」，右边是「译文」，上方状态行依次显示「正在识别截屏文字…」→「正在翻译为英语…」→「已翻译为英语（源语言 日语）」；
4. 点底部「**复制译文**」拿走整段，或右键译文复制选中的几句。

## 结果窗里能做什么

| 你想做什么 | 怎么做 |
| --- | --- |
| 看清原图的小字 | 在左图上滚滚轮放大（100%–800%，以指针位置为中心） |
| 看放大后的另一处 | 按住**右键**拖动平移 |
| 换一种目标语言 | 底部「翻译为」下拉，已识别到原文时会**立刻重翻**，不用重新截图 |
| 复制译文 | 点「复制译文」，或右键译文复制选中 / 全部 / 全选 |
| 挪动、调整窗口 | 拖页眉，或拖右下角改大小 |
| 关掉窗口 | 点页眉 × 或按 `Esc`，下次翻译还用这个窗口 |

放大后的缩放和位置，换一张图或关窗后会回到 100%；窗口没有滚动条，靠右键拖动看细节。识别还没结束时语言下拉是灰的，等原文出来再换。

:::warning
**翻译还没出结果就关掉窗口，这一次就作废了**，窗口也不会自己弹回来，重新点一次「翻译」即可。OCR 和表格识别不一样：那两个关窗不会中断识别，结果出来时窗口会自动弹回来。
:::

## 状态行在说什么

| 你看到的提示 | 可以怎么做 |
| --- | --- |
| 请先填写阿里云 AccessKey ID 和 AccessKey Secret。 | 到「设置 → 翻译设置」填好，点「测试翻译」验证 |
| 没有识别到可翻译的文字，请重新框选后再试。 | 框紧文字重试，或先看左图是否清晰 |
| 文字识别失败：… | 点工具栏「OCR」单独跑一次，看具体原因 |
| 翻译失败：… | 常见是文字太长、凭据无权限 / 欠费、网络不通 |
| 已翻译为英语（源语言 日语） | 翻译成功，括号里是自动识别出的原文语种 |

## 和 OCR、表格识别有什么不同

| 你想要 | 用哪个 | 会得到 |
| --- | --- | --- |
| 原样取出画面里的字 | OCR 文字识别 | 带行号的结果窗，可整段或单行复制 |
| 看懂外文内容 | 截图翻译 | 左图右文，右栏只有译文 |
| 把表格做成 Excel | 表格识别 | 可改的网格，导出 xlsx / CSV |

## 用之前知道这几点

- **只翻文字**：图片、图标里的信息不会翻，译文是纯文本，不保留原来的排版；
- **一次翻一段，不切分**：超过约 5000 字会被拒绝，长内容请分几块框选、翻几次；
- **右栏不显示原文**：需要原文对照时，用工具栏「OCR」另开一个结果窗；
- **译文质量取决于识别**：竖排、艺术字、低对比度、被遮挡的文字容易认错，先看左图确认；
- **需要联网**：接口不通会直接报错、不会自动重试，换语言或重新点「翻译」即可再试；
- 目标语言目前有中 / 英 / 日 / 韩 / 法 / 德 / 西 / 俄 八种。

:::tip
识别始终在本机完成，**图片不会上传**；只有识别出的那段文字会送去翻译。处理敏感内容时请留意这一点。译文看着不对，多半是识别错了——重新框一块更干净的区域通常就好了。
:::
