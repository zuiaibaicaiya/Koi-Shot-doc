# 截图翻译

把画面里的外文直接变成译文：**框选 → 本地 OCR → 阿里云机器翻译 → 左图右文结果窗**。适合看外语界面、外文报错、论文截图、境外网站。

翻译取的是**框选区域的原图**（不含后加的标注）——标注笔画只会干扰识别，这一点与 OCR、表格识别一致。

## 先配好凭据

翻译的识别在本机完成，机器翻译调用阿里云服务，所以首次使用前需要填一次凭据：

1. 打开「**设置 → 通用设置 → 翻译设置**」（需要已开通阿里云机器翻译服务的账号）；
2. 填入 **AccessKey ID** 与 **AccessKey Secret**：两个输入框默认掩码显示，点右侧「眼睛」可临时查看明文，再点一次恢复掩码；
3. 选择**目标语言**（中文 / 英语 / 日语 / 韩语 / 法语 / 德语 / 西班牙语 / 俄语），作为「翻译」的默认目标；
4. 点「**保存**」落盘，再点「**测试翻译**」——它用一句样例文本真发一次请求，成功与失败都直接显示在卡片里。

改完凭据**立刻生效**，不用重启，也不用重新截图。凭据只保存在**本机配置文件**里（Secret 以明文写入本机配置），界面上默认掩码显示，也不会随截图或识别内容上传。

## 使用步骤

1. 按 `F1` 截图，框选包含外文的区域（尽量框紧文字，少带无关画面）；
2. 点击工具栏「**翻译**」按钮（在 OCR 右侧）；
3. 截图浮层收起，**翻译结果窗**出现在框选区域所在的屏幕上：
   - 左侧「**截屏原图**」，可缩放、平移对照；
   - 右侧「**译文**」，上方状态行依次显示「正在识别截屏文字…」→「正在翻译为英语…」→「已翻译为英语（源语言 日语）」；
4. 点底部「**复制译文**」，或右键译文复制选中片段 / 全部译文。

## 结果窗操作

| 操作 | 效果 |
| --- | --- |
| 滚轮（指针在左侧原图上） | 缩放原图 **100%–800%**，以指针位置为中心缩放 |
| 放大后右键拖动 | 平移原图（左键留给窗口拖动与文字选择），指针变为抓手 |
| 底部「翻译为」下拉 | 切换目标语言；已识别到原文时**立即按新语言重翻**，不必重新截图 |
| 「复制译文」按钮 | 复制整段译文，并浮出「已复制到剪贴板」提示 |
| 右键译文 | 复制（选中项）/ 复制全部译文 / 全选 |
| 拖动页眉或空白处 | 移动窗口 |
| 拖动右下角 | 调整窗口大小 |
| 页眉「×」或 `Esc` | 关闭窗口并释放本次结果，下次翻译复用同一个窗口 |

- 缩放与滚动位置在**新图 / 关窗后复位到 100%**，不会带着上一张的缩放；
- 窗口没有可见滚动条，放大后靠右键拖动查看细节；
- OCR 进行中语言下拉是禁用的（原文还没拿到，换语言没有意义）。

## 状态行提示

| 提示 | 含义与处理 |
| --- | --- |
| 请先填写阿里云 AccessKey ID 和 AccessKey Secret。 | 还没配凭据 → 到「设置 → 翻译设置」填写后点「测试翻译」验证 |
| 没有识别到可翻译的文字，请重新框选后再试。 | 选区内没识别出文字 → 框紧文字重试，或先确认左侧原图是否清晰 |
| 文字识别失败：… | 本地 OCR 出错 → 可点「OCR」单独跑一次看具体原因 |
| 翻译失败：… | 接口返回错误，常见为**文本超长**（单次上限约 5000 字符）、凭据无权限 / 欠费、网络不通 |
| 已翻译为英语（源语言 日语） | 成功；括号里是自动检测到的源语言 |

## 与 OCR、表格识别的区别

| 能力 | 是否联网 | 输出 | 适合 |
| --- | --- | --- | --- |
| OCR 文字识别 | 否（本地） | 带行号的结果窗，可整段 / 单行复制 | 提取画面里的原文 |
| 截图翻译 | 是（只发文字） | 左图右文结果窗，只显示译文 | 读懂外文内容 |
| 表格识别 | 否（本地） | 可编辑网格，导出 xlsx / CSV | 表格转 Excel |

## 限制说明

- **只翻文字**：图片、插图、图标里的信息不会翻译，译文是纯文本，不保留原文排版；
- **单次请求、不切分**：整段识别文本一次发出，超过阿里云 `TranslateGeneral` 的上限（约 5000 字符）会被拒绝——超长内容请分块框选、翻多次；
- **不保留原文**：结果窗右栏只有译文；需要原文对照时，用工具栏「OCR」另开一个结果窗；
- **质量取决于识别**：竖排、艺术字、低对比度、被遮挡的文字识别不准，译文同样不可靠——先看左侧原图确认；
- **网络依赖**：接口不可达时报错且不自动重试，换语言、重新框选或再次点「翻译」都会重新发起；
- 目标语言目前提供中 / 英 / 日 / 韩 / 法 / 德 / 西 / 俄 八种。

:::tip
识别始终在本机完成，**图片不会上传**；只有识别出的那段文字会发给阿里云机器翻译。处理敏感内容时请留意这一点。
:::

:::tip
译文不准时，先确认左图（原图）里的文字是否被正确识别——多数「翻错」其实来自识别；重新框选更干净的区域通常就能解决。
:::
