# 保存与输出

截图、贴图、长截图、GIF、录屏与表格导出最终都要「落地」——本页统一说明输出到哪里、文件如何命名、各自是什么格式。

## 输出方式

| 输出方式 | 说明 |
| --- | --- |
| 复制到剪贴板 | 复制后直接粘贴到聊天窗口、文档、工单系统，不产生文件 |
| 保存到文件 | 写入「设置 → 通用设置 → 保存路径」指定的文件夹 |
| 贴图到桌面 | 以置顶悬浮窗展示，需要文件时再从贴图窗口保存（见[贴图](/zh/guide/features/pin)） |
| 结果窗口 | OCR / 表格识别 / 截图翻译会弹出独立结果窗，可复制或在窗内导出（见[OCR 与表格识别](/zh/guide/features/ocr-table)、[截图翻译](/zh/guide/features/translate)） |

## 文件命名规则

所有保存文件统一按 `名称_日期_时间` 格式命名（24 小时制）；同一秒内保存多个文件时会自动追加 `_1`、`_2` 序号，**不会互相覆盖**：

| 内容 | 文件名示例 |
| --- | --- |
| 截图保存 / 贴图保存 | `koiShot_20261002_153045.png` |
| 录屏（MP4） | `koiShot_20261002_153045.mp4` |
| 长截图 | `long_20261002_153045.png` |
| GIF 录制 | `gif_20261002_153045.gif` |
| 表格导出 | `table_20261002_153045.xlsx` / `table_20261002_153045.csv` |

## 默认保存位置

- 默认保存在系统「图片」文件夹下的 `koiShot` 子目录（如 Windows 为 `图片\koiShot`）；
- 在「设置 → 通用设置 → 保存路径」中点击「浏览」可改为任意文件夹；
- 开启「保存后打开文件夹」后，每次保存成功会自动打开文件所在文件夹（默认关闭，避免连续截图时反复抢焦点）。

## 各功能的落盘行为

| 功能 | 是否自动保存 | 说明 |
| --- | --- | --- |
| 截图（保存 / `Alt + S`） | 是 | 直接写入保存目录；写盘失败会弹「保存失败」提示，不会静默丢弃 |
| 截图（复制） | 否 | 只进剪贴板 |
| 贴图 | 按需 | 点「保存标注后的图片」或右键「保存原图」才落盘 |
| 长截图 | 是 | 点「完成」后**同时**写入 `long_*.png` 并复制到剪贴板 |
| GIF 录制 | 是 | 点「完成录制」后编码并写入 `gif_*.gif` |
| 录屏（MP4） | 是 | 点「完成录制」后导出并写入 `koiShot_*.mp4`；遵循「保存后打开文件夹」开关 |
| 表格识别 | 是 | 点「导出 Excel」/「导出 CSV」写入保存目录；开启「保存后打开文件夹」时同时打开目录 |
| 截图翻译 | 否 | 不产生文件：译文通过「复制译文」或右键复制进剪贴板 |

## 文件格式

- 截图、长截图、贴图统一保存为 **PNG**（无损，适合截图与标注）；
- 录屏保存为 **MP4**（H.264 视频，可选 AAC 麦克风音轨）；
- GIF 录制保存为 **GIF**；
- 表格识别可导出 **xlsx（Excel，含真实合并单元格）** 与 **CSV（UTF-8 BOM）**，也可把整张表以 **TSV** 复制到剪贴板（详见[OCR 与表格识别](/zh/guide/features/ocr-table)）。

:::tip
截图后习惯直接粘贴的用户，可以不开启「保存后打开文件夹」；需要归档留底的用户，建议开启该选项以便每次保存后立刻确认文件位置。
:::
