# 保存与输出

截图、长截图、GIF 与表格导出最终都要「落地」——本页统一说明输出到哪里、文件如何命名。

## 输出方式

| 输出方式 | 说明 |
| --- | --- |
| 复制到剪贴板 | 复制后直接到聊天窗口、文档、工单系统中粘贴，不产生文件 |
| 保存到文件 | 写入「设置 → 通用设置 → 保存路径」指定的文件夹 |
| 贴图到桌面 | 以置顶悬浮窗展示，需要文件时再从贴图窗口保存（见[贴图](/zh/guide/features/pin)） |

## 文件命名规则

所有保存文件统一按 `名称_日期_时间` 格式命名（24 小时制），同一秒内保存多张时会自动追加 `_1`、`_2` 序号，**不会互相覆盖**：

| 内容 | 文件名示例 |
| --- | --- |
| 截图 / 贴图保存 | `koiShot_20261002_153045.png` |
| 长截图 | `long_20261002_153045.png` |
| GIF 录制 | `gif_20261002_153045.gif` |
| 表格导出 | `table_20261002_153045.csv`（xlsx / tsv 同理） |

## 默认保存位置

- 默认保存在系统「图片」文件夹下的 `koiShot` 子目录（如 Windows 为 `图片\koiShot`）；
- 在「设置 → 通用设置 → 保存路径」中点击「浏览」可改为任意文件夹；
- 开启「保存后打开文件夹」后，每次保存成功会自动打开文件所在文件夹（默认关闭，避免连续截图时反复抢焦点）。

## 图片格式

- 截图、长截图统一保存为 **PNG**（无损，适合截图与标注）；
- GIF 录制保存为 **GIF**；
- 表格识别支持导出 **xlsx（Excel）/ CSV / TSV** 三种格式（详见[OCR 与表格识别](/zh/guide/features/ocr-table)）。

:::tip
截图后习惯直接粘贴的用户，可以不开启「保存后打开文件夹」；需要归档留底的用户，建议开启该选项以便每次保存后立刻确认文件位置。
:::
