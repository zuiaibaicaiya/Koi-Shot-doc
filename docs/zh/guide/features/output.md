# 保存与输出

截图做完之后，你要么直接粘贴出去，要么得到一个文件。这一页告诉你**文件存在哪、叫什么、怎么改**，以及每个功能会给你什么。

## 三种拿走结果的方式

| 你想要 | 怎么做 | 会得到 |
| --- | --- | --- |
| 直接发到聊天 / 文档里 | 点「复制」 | 内容进剪贴板，不产生文件，直接粘贴 |
| 留一份文件 | 点「保存」或按 `Alt + S` | 存进「设置 → 通用设置 → 保存路径」指定的文件夹 |
| 一直放在眼前 | 点「贴图」 | 置顶小窗；想要文件时再从贴图窗口保存（见[贴图](/zh/guide/features/pin)） |
| 取出文字 / 表格 / 译文 | 点 OCR、表格或翻译 | 弹出结果窗，在窗里复制或导出（见[OCR 与表格识别](/zh/guide/features/ocr-table)、[截图翻译](/zh/guide/features/translate)） |

## 文件都叫什么名字

统一按 `名称_日期_时间` 命名（24 小时制）；同一秒存了多个文件会自动加 `_1`、`_2`，**不会互相覆盖**：

| 内容 | 文件名示例 |
| --- | --- |
| 截图 / 贴图保存 | `koiShot_20261002_153045.png` |
| 录屏 | `koiShot_20261002_153045.mp4` |
| 长截图 | `long_20261002_153045.png` |
| GIF | `gif_20261002_153045.gif` |
| 表格导出 | `table_20261002_153045.xlsx` 或 `.csv` |

## 存到哪里，怎么改

- 默认在系统「图片」文件夹下的 `koiShot` 子目录；
- 想换位置：「设置 → 通用设置 → 保存路径」点「浏览」；
- 想每次保存后自动打开文件夹：开启「**保存后打开文件夹**」（默认关闭，免得连续截图时一直弹窗口）。

## 每个功能会不会自动存文件

| 功能 | 自动存？ | 你会得到什么 |
| --- | --- | --- |
| 截图（保存 / `Alt + S`） | 会 | 直接写进保存目录；写失败会弹提示，不会悄悄丢掉 |
| 截图（复制） | 不会 | 只在剪贴板里 |
| 贴图 | 看你点不点 | 点「保存标注后的图片」或右键「保存原图」才生成文件 |
| 长截图 | 会 | 点「完成」后存成 `long_*.png`，**同时已经复制到剪贴板** |
| GIF | 会 | 点「完成录制」后生成 `gif_*.gif` |
| 录屏 | 会 | 点「完成录制」后生成 `koiShot_*.mp4` |
| 表格识别 | 会 | 点「导出 Excel」/「导出 CSV」写入保存目录 |
| 截图翻译 | 不会 | 只给译文，用「复制译文」或右键复制拿走 |

## 都是什么格式

- 截图、长截图、贴图：**PNG**，清晰无损，标注也保留；
- 录屏：**MP4**，可以带麦克风声音，普通播放器都能打开；
- GIF 录制：**GIF**，聊天窗口里会自动循环播放；
- 表格：**Excel（`.xlsx`，保留合并单元格）** 或 **CSV**，也可以把整张表复制到剪贴板，粘进 Excel / WPS 会自动分好列。

:::tip
习惯了截完直接粘贴，就不用开「保存后打开文件夹」；需要归档留底的话，打开它，每次存完能立刻看到文件在哪。
:::
