# 截图

这一页讲**从按下快捷键到把图拿走**的全过程：怎么框选、框选时那些提示是什么意思、工具栏上每颗按钮做什么。

## 开始截图

任选一种：

- 按 `F1`（截图）、`Alt + S`（截图并保存）或 `Alt + R`（框选录屏）；
- **左键单击**托盘图标，直接开始截图；
- 托盘右键菜单 →「截图」/「截图并保存」；
- koiShot 已经在运行时再启动一次程序（比如双击桌面图标），会**直接触发一次截图**。

进入截图后屏幕会变暗，**默认选中鼠标所在屏幕的工作区**（整屏去掉任务栏 / Dock / 菜单栏）。不动鼠标直接单击就能截这块区域；鼠标一动，选区预览就变成光标下那个矩形。

## 框选操作

| 你想做什么 | 怎么做 |
| --- | --- |
| 框一块任意大小 | 按住左键拖 |
| 框一个正方形 | 拖的时候按住 `Shift`（中途按下 / 松开都立刻生效；贴屏幕边缘时会被收回来） |
| 正好选中一个按钮或输入框 | 把鼠标停上去，看到高亮描边后**单击** |
| 调整选区大小 | 拖边 / 角上的手柄，八个方向都行 |
| 挪动选区 | 拖选区内部 |
| 调选中的标注粗细 / 大小 | 在它上面滚滚轮 |
| 放弃这次截图 | `Esc` |

### 光标形状在告诉你什么

不用记规则，看光标就知道按下去会发生什么：

| 光标长这样 | 意味着 |
| --- | --- |
| 十字 | 可以从这里落笔 / 定位一个点：空白处、已经画完不再选中的旧图形、箭头端点、还没框选时的画面 |
| 四向抓手 | 这一整块可以拖走：当前选中的图形、箭杆、序号徽章、选区内部 |
| 双向缩放箭头 | 可以拉大拉小：选中图形的八个控制点、选区的边框和手柄 |
| I 型 | 贴图窗口里，这里有一段可以划选复制的文字 |
| 箭头 / 小手 | 工具栏空白处是箭头；按钮、色块、滑块上是小手，表示可以点（灰色按钮仍是箭头） |

抓手只属于**当前选中、还能改**的那一条；图形一旦冻结，按上去就是新的一笔，光标也变回十字。

### 让鼠标帮你选中控件

还没框选时，把鼠标停在窗口、按钮、图片上，它会被描边高亮，**单击就把这块选中**，不用手动对齐像素。

- Windows、macOS 都支持，macOS 需要授予「辅助功能」权限；
- Linux 暂不支持，会退回普通框选；
- 没授权或被系统拒绝时不报错，只是不再高亮，别的截图功能照常能用。

### 放大镜取色

框选时移动鼠标，屏幕角落会出现放大镜：放大光标附近的像素、显示像素栅格，下面还有 **RGB 色值**和坐标。想精确对齐边界或顺便取个颜色，看它就行。

### 左侧的快捷键提示

屏幕左列有一块半透明面板，列出**当前这一步能按哪些键**：

| 阶段 | 面板上写什么 |
| --- | --- |
| 还没框选 | 拖拽框选 · Shift+拖拽 正方形 · 单击选区块 · Esc 取消 |
| 选区已定、工具栏出现 | 拖选区移动 / 调整 · 滚轮调标注粗细 · Ctrl+Z 撤销 · Enter 完成 · Esc 取消 |

面板优先待在左下角，左下被挡才换到左上；两个角都被选区、工具栏之类压住时会暂时让路。拖拽过程中会隐藏，松手恢复；GIF / 录屏录制时不显示。

## 工具栏

框选完成后，选区下方弹出工具栏。按钮从左到右：

| 分组 | 按钮 | 点它会怎样 | 详细说明 |
| --- | --- | --- | --- |
| 标注 | 画笔 / 矩形 / 圆形 / 箭头 / 荧光笔 / 马赛克 / 高斯模糊 / 文字 / 序号 | 在截图上画标注，带小三角的还能展开属性弹窗 | [标注与编辑](/zh/guide/features/annotation) |
| 编辑 | 撤销 / 重做 | 回退或恢复一步，`Ctrl + Z` / `Ctrl + Shift + Z`（Windows 也能 `Ctrl + Y`） | [撤销与重做](/zh/guide/features/annotation#撤销与重做) |
| 输出 | 贴图 | 把这块钉在桌面置顶显示 | [贴图](/zh/guide/features/pin) |
| 输出 | OCR | 把图里的字变成可复制的文字 | [OCR 与表格识别](/zh/guide/features/ocr-table) |
| 输出 | 翻译 | 把外文翻成译文，左图右文对照 | [截图翻译](/zh/guide/features/translate) |
| 输出 | 二维码识别 | 解码二维码，内容进剪贴板 | [OCR 与表格识别](/zh/guide/features/ocr-table) |
| 输出 | 表格 | 把表格变成能改的网格，导出 Excel | [OCR 与表格识别](/zh/guide/features/ocr-table) |
| 输出 | 长截图 | 滚动页面自动拼成长图 | [长截图、GIF 与录屏](/zh/guide/features/long-capture-gif) |
| 输出 | 录制 GIF | 把框选区域录成动图 | [长截图、GIF 与录屏](/zh/guide/features/long-capture-gif) |
| 输出 | 录屏 | 把框选区域录成 MP4（可带声音） | [长截图、GIF 与录屏](/zh/guide/features/long-capture-gif) |
| 收尾 | 保存 / 取消 / 复制 | 存到文件夹、放弃、复制到剪贴板（最右边） | [保存与输出](/zh/guide/features/output) |

按钮都是图标，**把鼠标停一下就会显示名字**；靠近屏幕底边时提示会翻到按钮上方，灰色按钮不显示提示。当前选中的工具会高亮，再点一次它能打开属性弹窗。

工具栏默认贴在选区下方，放不下就翻到上方，靠屏幕边缘时会自动夹回屏内；拖选区时它会暂时隐藏，松手再出现。多显示器时整条工具栏留在「和选区重叠最多」的那块屏里，不会一半在这屏、一半在那屏。

## 完成与取消

**直接按 `Enter`，会执行你这次入口对应的那个动作**（按钮以蓝色实底标出来）：

| 你是怎么进来的 | 按 `Enter` 会做什么 |
| --- | --- |
| `F1` / 托盘「截图」/ 再次启动程序 | 复制到剪贴板 |
| `Alt + S` / 托盘「截图并保存」 | 保存到文件（框选松手就存，不弹工具栏） |
| `Alt + P` / 托盘「贴图到桌面」 | 贴到桌面（松手就贴） |
| `Alt + R` | 松手后出现录屏录制条，等你点「开始录制」 |

也可以直接点「复制」/「保存」/「贴图」等按钮；点「取消」或按 `Esc` 放弃（正在输入文字标注时，`Esc` 只退出输入，不会关掉整张截图）。
