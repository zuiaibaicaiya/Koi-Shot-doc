# 截图

## 开始截图

任选一种方式：

- 按全局快捷键 `F1`（截图）或 `Alt + S`（截图并保存）、`Alt + R`（框选录屏）；
- 点击系统托盘图标（**左键单击**直接开始截图）；
- 托盘右键菜单 →「截图」/「截图并保存」；
- koiShot 已在运行时再次启动程序（如双击桌面图标）会**直接触发一次截图**。

启动截图后，屏幕进入压暗的框选状态，**默认选中鼠标所在屏幕的工作区**（整屏去掉任务栏 / Dock / 菜单栏等系统区域），不动鼠标直接单击即可截取该区域；鼠标一移动，选区预览就切换为光标下的可用矩形。

## 框选操作

| 操作 | 效果 |
| --- | --- |
| 按住鼠标左键拖拽 | 框选任意矩形区域 |
| `Shift` + 拖拽 | 框选正方形区域（中途按下 / 松开 `Shift` 实时切换；贴近屏幕边缘时会被边界夹取） |
| 单击某个界面控件 | 选中该控件（按钮、输入框、图片等）的精确边界 |
| 拖动选区的边 / 角手柄 | 八个方向调整选区大小 |
| 拖动选区内部 | 整体移动选区（不改大小） |
| 滚轮（选中标注后） | 调整当前选中标注的粗细 / 大小 |
| `Esc` | 取消本次截图 |

### 智能控件识别

鼠标悬停且尚未框选时，光标下的窗口、按钮、图片等界面元素会被描边高亮，**单击即落成选区**，不用手动对齐像素。该能力基于系统辅助接口：

- Windows：UI Automation（UIA）；
- macOS：辅助功能（AX），需在系统设置中授权；
- Linux：暂未实现，退化为普通框选。

未授权或被系统拒绝时不会报错，只是不再出现控件高亮，其余截图功能不受影响。

### 放大镜取色

框选过程中移动鼠标，屏幕角落会出现放大镜：放大显示光标附近的像素、像素栅格，并在下方给出 **RGB 色值**与坐标，方便精确对齐选区边界或直接读取颜色。

### 快捷键提示面板

截图界面**屏幕左列**会显示一块半透明提示面板，列出当前阶段可用的按键：

| 阶段 | 提示内容 |
| --- | --- |
| 尚未框选 | 拖拽框选截图区域 · Shift+拖拽 正方形选区 · 单击选中区块 · Esc 取消截图 |
| 选区已提交（工具栏已弹出） | 拖拽选区 移动/调整位置 · 滚轮 调整选中标注粗细/大小 · Ctrl+Z 撤销标注 · Enter 完成截图 · Esc 取消截图 |

面板**左下角优先**，左下放不下才换到左上；如果左列上下两角都被其它浮层（选区、工具栏、放大镜等）压住，会暂时隐藏让路。拖拽进行中（框选、移动、缩放选区）会临时隐藏，松手后自动恢复；工具栏弹出后的编辑阶段它仍会显示，方便随时查看快捷键；GIF / 录屏录制态不显示。

## 工具栏

框选完成后，选区下方弹出**工具栏**；当前工具高亮显示，可再点一次展开它的属性弹窗。全部按钮从左到右：

| 分组 | 按钮 | 作用 | 详细说明 |
| --- | --- | --- | --- |
| 标注工具 | 画笔 / 矩形 / 圆形 / 箭头 / 荧光笔 / 马赛克 / 高斯模糊 / 文字 / 序号 | 在截图上添加各类标注；带小三角的按钮可展开属性弹窗 | [标注与编辑](/zh/guide/features/annotation) |
| 编辑 | 撤销 / 重做 | 回退或恢复上一步标注，快捷键 `Ctrl + Z` / `Ctrl + Shift + Z`（macOS 用 `Cmd`） | [撤销与重做](/zh/guide/features/annotation#撤销与重做) |
| 输出 | 贴图 | 把选区钉在桌面置顶显示 | [贴图](/zh/guide/features/pin) |
| 输出 | OCR | 识别选区内的文字，结果带行号 | [OCR 与表格识别](/zh/guide/features/ocr-table) |
| 输出 | 翻译 | 识别选区内的外文并机翻，弹出左图右文结果窗 | [截图翻译](/zh/guide/features/translate) |
| 输出 | 二维码识别 | 解码选区内的二维码并复制内容到剪贴板 | [OCR 与表格识别](/zh/guide/features/ocr-table) |
| 输出 | 表格 | 把表格截图还原为可编辑表格并导出 xlsx / CSV | [OCR 与表格识别](/zh/guide/features/ocr-table) |
| 输出 | 长截图 | 滚动页面自动拼接长图 | [长截图、GIF 与录屏](/zh/guide/features/long-capture-gif) |
| 输出 | 录制 GIF | 把选区录成 GIF 动图 | [长截图、GIF 与录屏](/zh/guide/features/long-capture-gif) |
| 输出 | 录屏 | 把选区录成 MP4 视频（可带麦克风声音） | [长截图、GIF 与录屏](/zh/guide/features/long-capture-gif) |
| 收尾 | 保存 / 取消 / 复制 | 直接存到保存目录、放弃截图、复制到剪贴板（最右） | [保存与输出](/zh/guide/features/output) |

工具栏会自动避让屏幕边缘：默认贴选区下方，下方放不下就翻到选区上方；选区靠近屏幕左右边缘时水平夹回屏内。拖动选区时工具栏会临时隐藏，松手后恢复。

多显示器时，工具栏按「选区与哪块屏交叠最多」选主体屏，整条工具栏留在同一块屏幕内：选区横跨两屏交界时不会一半在这屏、一半在那屏，也不会被屏幕边缘裁掉。贴图窗口的工具栏使用同一套落位规则。

## 完成与取消

- **默认动作**取决于你是从哪个入口进来的 —— 该入口对应的按钮会以品牌蓝实底高亮：

  | 入口 | 默认动作 |
  | --- | --- |
  | `F1` / 托盘「截图」/ 再次启动程序 | 复制到剪贴板 |
  | `Alt + S` / 托盘「截图并保存」 | 保存到文件（框选松手即保存，不弹工具栏） |
  | `Alt + P` / 托盘「贴图到桌面」 | 贴图到桌面（框选松手即贴图） |
  | `Alt + R` | 框选松手即进入录屏「待开始」录制条 |

- 直接按 `Enter`：执行当前默认动作；
- 点击「复制」/「保存」/「贴图」等按钮：执行对应动作并结束本次截图；
- 点击「取消」或按 `Esc`：放弃截图（文字标注编辑中按 `Esc` 只退出编辑，不会关掉整张截图）。
