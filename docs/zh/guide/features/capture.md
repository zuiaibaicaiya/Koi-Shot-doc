# 截图

## 开始截图

任选一种方式：

- 按全局快捷键 `F1`（截图）或 `Alt + S`（截图并保存）；
- 点击系统托盘图标，选择「截图」；
- 在主窗口点击「截图」按钮。

启动截图后，**默认选中鼠标所在屏幕的整屏区域**，屏幕其余部分变暗，进入框选状态。屏幕左下角会显示快捷键提示面板，忘记操作时随时可以看它。

## 框选操作

| 操作 | 效果 |
| --- | --- |
| 按住鼠标左键拖拽 | 框选任意矩形区域 |
| `Shift` + 拖拽 | 框选正方形区域 |
| 单击某个界面控件 | 选中该控件（按钮、输入框等）的精确边界 |
| 拖拽选区的边角 / 边框手柄 | 八个方向调整选区大小 |
| `Esc` | 取消本次截图 |

**智能控件识别**：鼠标悬停时，窗口、按钮、图片等界面元素会被高亮描边，单击即可精确选中，不用手动对齐像素。该功能基于系统辅助能力（Windows UIA / macOS 辅助功能）实现，无需额外配置。

## 放大镜取色

框选过程中移动鼠标，屏幕角落会出现放大镜，放大显示光标附近的像素，方便精确对齐选区边界，也可以用来读取像素颜色。

## 确认截图

框选完成后，选区下方弹出工具栏：

```
画笔 矩形 圆形 箭头 荧光笔 马赛克 高斯模糊 文字 序号
撤销 重做 ｜ 复制 保存 贴图 OCR 表格 长截图 录制GIF ｜ 取消
```

- 直接按 `Enter`：执行当前入口的默认动作（按 `F1` 进入时默认复制，按 `Alt + S` 进入时默认保存）；
- 点击「取消」或按 `Esc`：放弃截图。
