# 贴图

## 什么是贴图

贴图（钉在桌面）会把一张截图以**置顶悬浮小窗**的形式固定在桌面上，非常适合一边看图 / 看参考内容、一边在其他窗口工作的场景。

## 创建贴图

任选一种方式：

- 截图框选完成后，点击工具栏「贴图」按钮；
- 按全局快捷键 `Alt + P`（截图后直接贴图）；
- 托盘菜单选择「贴图到桌面」。

## 贴图窗口操作

| 操作 | 效果 |
| --- | --- |
| 拖动 | 移动贴图位置 |
| 滚轮 | 缩放贴图（0.3–4.0 倍） |
| `Alt` + 滚轮 | 调节贴图透明度（5%–100%） |
| 右键菜单 | 复制、保存、关闭等常用操作 |

贴图窗口自带**完整的标注工具栏**（含荧光笔），可以直接在贴图上继续画箭头、写文字、打序号——适合边对照边补标注。

## 贴图右键菜单

在贴图窗口上右键，可使用全部贴图操作：

| 菜单项 | 作用 |
| --- | --- |
| 复制 | 把当前贴图（含标注）复制到剪贴板 |
| 保存原图 | 保存**未加标注**的原始截图 |
| 保存标注后的图片 | 保存**叠加了标注**的最终效果 |
| 隐藏 / 显示工具栏 | 收起或展开贴图上的标注工具栏，只保留纯净画面 |
| 隐藏 / 显示阴影 | 切换贴图窗口的投影边框效果 |
| 关闭 | 关闭该贴图 |

保存的文件命名与位置遵循统一规则，见[保存与输出](/zh/guide/features/output)。

## 关闭贴图

- 在贴图窗口右键菜单中选择「关闭」；
- 或选中贴图后按 `Esc`。

:::tip
给同事看「带标注的效果图」时用「保存标注后的图片」；需要交付干净原图时用「保存原图」，一次贴图两种产物。
:::

:::tip
贴图窗口始终保持置顶。如果贴图挡住了工作区域，用 `Alt` + 滚轮调低透明度即可隐约看到下方内容，不必频繁移动。
:::
