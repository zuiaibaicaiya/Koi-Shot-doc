# 贴图

想把一张截图一直放在眼前、边看边干活，就用「贴图」：它会变成一个**始终浮在最上面的小窗口**，还能接着在上面画标注。参考图、对照数据、临时记个笔记都适合。

## 怎么贴到桌面

任选一种：

- 截图框选完，点工具栏「贴图」；
- 按 `Alt + P`：框选松手就直接贴好（不弹工具栏）；
- 托盘右键菜单 →「贴图到桌面」。

## 贴好之后能做什么

| 你想做什么 | 怎么做 |
| --- | --- |
| 挪个位置 | 拖动画面（可以拖到屏幕边缘） |
| 放大 / 缩小 | 滚轮（0.3–4.0 倍），工具栏上显示当前百分比 |
| 一键回到原始大小 | 点工具栏上的缩放百分比 |
| 不挡住后面的内容 | `Alt` + 滚轮调低透明度（5%–100%） |
| 关掉这张贴图 | `Esc` / `Ctrl + W`（macOS 用 `Cmd + W`），或点工具栏「关闭」 |

:::tip
贴图挡住工作区时，先试试 `Alt` + 滚轮把透明度调低，隐约能看到下面的内容，不用来回挪窗口。当前版本不能旋转或镜像贴图。
:::

工具栏会自动换位置：默认在图片下方，放不下就翻到上方，贴着屏幕边缘时会横向收回屏幕内，保证每颗按钮都点得到。图片特别大、屏幕上下都放不下时，它可能压住一点点画面。拖动贴图时工具栏会暂时收起，松手再出现。

## 工具栏和右键菜单

| 按钮 | 作用 |
| --- | --- |
| 九个标注工具 | 在贴图上继续画，用法和截图时一样（`Shift` 画直线也支持），见[标注与编辑](/zh/guide/features/annotation) |
| 撤销 / 重做 | 回退或恢复上一步标注 |
| 复制 | 把原图复制到剪贴板（不含标注） |
| 二维码识别 | 进入框选模式，框住二维码即解码并复制内容 |
| 保存标注后的图片 | 存**带标注**的合成图 |
| 缩放百分比 | 显示当前比例，点一下回到 100% |
| 隐藏工具栏 / 关闭 | 只留纯净画面 / 关掉贴图 |

右键贴图还有「保存原图」（只存未标注的那张）、「隐藏 / 显示工具栏」、「隐藏 / 显示阴影」和「关闭」。文件存在哪、叫什么，见[保存与输出](/zh/guide/features/output)。

:::tip
要给别人看「标好的效果图」就点「保存标注后的图片」；要交付干净原图就用右键「保存原图」。一次贴图，两种产物。
:::

## 直接在图上划一段文字复制

**没有选中任何标注工具**时，可以像在网页里选字一样，把图上的文字划走：

1. 把鼠标移到有文字的地方，光标变成 **I 型**并出现淡蓝虚线；
2. 按住左键拖过要的文字，被选中的每一行会亮起淡蓝底——**亮起来的范围就是会被识别的范围**；
3. 松手，文字自动识别并**直接进剪贴板**；窗口底部会弹出提示，还带一小段识别结果，不用粘贴就能确认对不对。

选的是「一段连续的文字」，不是鼠标划过的像素：同一行只取起点到终点；跨行时首行取到行尾、中间取整行、末行取到终点。往上拖、往下拖结果一样，拖到文字上下的空白处会自动吸附到最近一行。

| 你遇到什么 | 说明 |
| --- | --- |
| 几乎没拖动 | 当作误点，不识别；把文字划完整一点 |
| 按在空白处或按右键拖 | 不进文字选区，正常用来拖动贴图 |
| 已经选了标注工具 | 同一位置照常画标注 |
| 识别中又划一次 | 提示「正在识别中，请稍候…」 |
| 没识别出字 | 提示「未识别到文字」 |
| 划了完全没反应 | 去「设置 → OCR 自检」看看识别环境是否正常；拖动贴图等其它操作不受影响 |

两点提醒：识别看的是**原始底图**，被马赛克 / 模糊盖住的地方仍能认出盖住前的字；结果是所选文字的**近似整段**，首尾可能多带几个字，只在一行内划选才最精确。

## 关掉贴图

点工具栏「关闭」、右键菜单「关闭」，或按 `Esc` / `Ctrl + W`（macOS 用 `Cmd + W`）。正在输入文字标注时，`Esc` 只退出这次输入，不会关掉贴图。
