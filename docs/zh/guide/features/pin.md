# 贴图

## 什么是贴图

贴图（钉在桌面）会把一张截图以**置顶悬浮小窗**的形式固定在桌面上，适合一边看图 / 看参考内容、一边在其他窗口工作。贴图窗口始终置于普通窗口之上（可压住任务栏 / Dock），并自带完整的标注工具栏。

## 创建贴图

任选一种方式：

- 截图框选完成后，点击工具栏「贴图」按钮；
- 按全局快捷键 `Alt + P`：框选松手即贴图（不弹工具栏）；
- 托盘右键菜单 →「贴图到桌面」。

## 贴图窗口操作

| 操作 | 效果 |
| --- | --- |
| 拖动画面 | 移动贴图位置（可拖到屏幕四边，甚至压住任务栏 / Dock） |
| 滚轮 | 缩放贴图（0.3–4.0 倍），工具栏上实时显示当前百分比 |
| `Alt` + 滚轮 | 调节贴图透明度（5%–100%） |
| `Esc` / `Ctrl + W`（macOS 为 `Cmd + W`） | 关闭这张贴图 |

- 拖动时工具栏会自动暂时收起，松手后恢复，避免挡住拖动路径；
- 工具栏默认贴内容区下方并水平居中，下方放不下会**自动翻到上方**；图片比工具栏窄、又贴着屏幕边缘时，工具栏会横向夹回屏幕内，始终整条可见、每个按钮都点得到；
- 贴图窗口**不抢焦点**：点工具栏按钮不会打断正在输入的文字标注；文字输入中 `Alt` + 滚轮不调透明度（此时滚轮用于调字号），避免误改。

## 贴图工具栏

| 按钮 | 作用 |
| --- | --- |
| 九个标注工具（画笔 / 矩形 / 圆形 / 箭头 / 荧光笔 / 马赛克 / 高斯模糊 / 文字 / 序号） | 直接在贴图上继续标注；用法与截图时完全一致，见[标注与编辑](/zh/guide/features/annotation) |
| 撤销 / 重做 | 与截图侧同一套行为 |
| 复制 | 把贴图图片复制到剪贴板（原始底图，不含标注） |
| 二维码识别 | 进入框选模式，拖矩形框住二维码即解码并复制内容到剪贴板 |
| 保存标注后的图片 | 保存**含标注**的合成图（右键里的「保存原图」则只存未标注的原始截图） |
| 缩放百分比 | 显示当前缩放比例（0.3–4.0） |
| 隐藏工具栏 | 收起工具栏只留纯净画面；右键菜单可再显示 |
| 关闭 | 关闭该贴图 |

## 贴图右键菜单

在贴图窗口上右键：

| 菜单项 | 作用 |
| --- | --- |
| 复制 | 复制贴图的原图到剪贴板（不含标注） |
| 保存原图 | 保存**未加标注**的原始截图 |
| 隐藏 / 显示工具栏 | 收起或展开标注工具栏 |
| 隐藏 / 显示阴影 | 切换贴图窗口的投影边框效果 |
| 关闭 | 关闭该贴图 |

保存的文件命名与位置遵循统一规则，见[保存与输出](/zh/guide/features/output)。

## 未选工具时框选识别文字

贴图窗口**没有选中任何工具栏工具**时，可以直接在图上「划一段文字」并复制：

1. 把鼠标移到有文字的地方，光标变为 **I 型**并出现淡蓝虚线提示；
2. 按住左键拖过要复制的文字，选中的每一行会亮起半透明淡蓝底（**屏幕上看亮的范围，就是会被识别的范围**）；
3. 松手后自动识别选区内的文字并**直接写入剪贴板**，内容区底部弹出提示（如「已复制 N 行文字到剪贴板」）。

选区语义与 Word / 浏览器一致：**连续的一段文字**，而不是指针划过的像素。

| 情形 | 选中范围 |
| --- | --- |
| 同一行内 | 起点到终点 |
| 跨行：首行 | 起点 → 行尾 |
| 跨行：中间各行 | 整行 |
| 跨行：末行 | 行首 → 终点 |

- 从下往上拖与从上往下拖，结果一致；
- 拖到文字区上下的空白处会自动吸附到最近的一行；
- 按下后几乎没移动（小于 4 个显示像素）视为误触，不识别；
- 已选中某个标注工具时不会进入文字选区，同一点位照常绘制标注；
- 识别进行中再次框选会提示「正在识别中，请稍候…」；
- 识别为空时提示「未识别到文字」。

识别口径上的几点提醒：

- 识别以**原始底图**为准：被马赛克 / 模糊标注盖住画面的地方，识别的仍是盖住前的原图文字；
- 结果是所选文字的**近似整字超集**：首尾可能各多带少量字符，选段落在单行内才精确；斜向跨行会带上经过的整行行首 / 行尾。

## 关闭贴图

- 点工具栏「关闭」按钮；
- 右键菜单选择「关闭」；
- 或按 `Esc` / `Ctrl + W`（macOS 为 `Cmd + W`）。

文字标注正在编辑时，`Esc` 只退出这次编辑，不会关掉贴图。

:::tip
给同事看「带标注的效果图」时用「保存标注后的图片」；需要交付干净原图时用右键「保存原图」，一次贴图两种产物。
:::

:::tip
贴图窗口始终保持置顶。如果贴图挡住了工作区域，用 `Alt` + 滚轮调低透明度即可隐约看到下方内容，不必频繁移动。当前版本暂不支持旋转 / 镜像贴图。
:::
