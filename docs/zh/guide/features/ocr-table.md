# OCR 与表格识别

koiShot 内置**本地离线**识别引擎（PaddleOCR + ONNX Runtime），识别所需模型随安装包一并提供，无需下载、无需联网——识别过程不上传图片。

若想确认识别环境状态，可在「设置 → OCR 自检」中点击**一键自检**，也可点击「打开模型目录」查看内置模型文件。

## 一、OCR 文字识别

1. 按 `F1` 截图并框选包含文字的区域；
2. 点击工具栏「OCR」按钮；
3. 稍等片刻，弹出**「OCR 识别结果」窗口**，逐行显示文字并带行号；
4. 点击「复制」复制全部文本，或**双击某一行只复制该行**（粘贴到目标位置即可）。

识别结果窗口操作：

| 操作 | 效果 |
| --- | --- |
| 「复制」按钮 | 复制全部识别文本，成功后提示「已复制到剪贴板」 |
| 双击某一行 | 只复制该行文字 |
| 识别失败 | 系统托盘弹出气泡提示，可重试或改框更清晰的区域 |

适用场景：提取图片中的文字、复制不可选中的文本（如弹窗提示、扫描件、视频字幕）。

## 二、表格识别（截图转 Excel）

1. 按 `F1` 截图并框选表格区域；
2. 点击工具栏「表格」按钮；
3. 识别结果以**可编辑表格**呈现：

   - 单击单元格可直接修改文字；
   - 支持人工**合并 / 拆分**单元格，修正识别误差；
   - 低置信度内容会有提示，重点核对即可。

4. 输出结果，任选一种方式：
   - 点击「复制」，以 **TSV 格式**复制整个表格——直接粘贴到 Excel / WPS 表格会**自动按列分格**，无需任何处理；
   - 点击导出，选择文件格式：**xlsx（Excel）/ CSV / TSV**，保存规则见[保存与输出](/zh/guide/features/output)。

适用场景：论文、报告中的表格数据复用，截图表格转 Excel 免手动录入。

:::tip
表格识别对**规整表格**（有清晰线条或对齐良好）效果最好；对于复杂背景或倾斜的表格，建议框选时尽量贴近表格边界，导出前先人工核对。
:::
