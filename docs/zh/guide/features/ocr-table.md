# OCR 与表格识别

这一页帮你做两件事：**把图片里不能选中的文字复制出来**，以及**把截图里的表格变成能修改、能导出的 Excel**。框选之后点一下按钮就行，不用联网、不用注册，图片只在本机处理。

结果窗和贴图一样一直浮在最上面，切到别的窗口也不会被盖住，方便你边看边复制。如果识别没反应，去「设置 → 通用设置 → OCR 自检」点「一键自检」，或点「打开模型目录」看看文件是否齐备。

## 一、把图片里的文字复制出来

1. 按 `F1`，框选有文字的区域；
2. 点工具栏「OCR」；
3. 稍等一下，结果窗弹出：左侧是行号，右侧逐行列出识别出的文字；
4. 点「复制」拿走全部，或**双击某一行只复制这一行**（行号不会进剪贴板）。

| 你想做什么 | 怎么做 |
| --- | --- |
| 复制全部文字 | 点「复制」 |
| 只要其中一行 | 双击那一行 |
| 关掉结果窗 | 点右上角 × 或按 `Esc`；识别还没结束时关窗，结果出来后窗口会自己再弹出来 |
| 识别失败了 | 托盘会弹出提示，框得更清晰一点重试 |

:::tip
文字如果是倒着的、竖排的或被旋转过，先把画面转正、把文字框紧再识别，结果会准很多。日常桌面截图里的文字基本都是正的，通常不用管这件事。
:::

适合用来：复制弹窗提示、扫描件、视频字幕、PDF 截图里不能选中的字。

需要**看懂外文**而不只是取出原文时，点工具栏「翻译」：它会把识别出的文字翻成中文或其他语言，左图右文对照着看（见[截图翻译](/zh/guide/features/translate)）。

## 二、把表格截图变成 Excel

1. 按 `F1`，把表格框紧一点，尽量不带多余内容；
2. 点工具栏「表格」；
3. 结果窗里是一张**可以直接改的表格**：

   - 双击格子就能改字；列头是 **A / B / C**，和导出后的 Excel 一一对应；
   - 选中至少两个格子 → 点「**合并**」，文字会拼到左上角；选中合并过的格子 → 点「**拆分**」还原。**合并不能撤销**，动手前先看清；
   - 拿不准的格子会带一层浅色底，鼠标停上去会提示「建议核对」；你手动改过的格子就不再标记了。
4. 改好了，选一种方式拿走：

   | 点这个 | 你会得到 |
   | --- | --- |
   | 复制 TSV | 整张表进剪贴板，粘贴到 Excel / WPS 会自动分好列 |
   | 导出 Excel | `table_日期_时间.xlsx`，合并过的格子照样保留 |
   | 导出 CSV | `table_日期_时间.csv`，用 Excel 打开不会乱码 |

文件存在「设置 → 通用设置 → 保存路径」里；如果开了「保存后打开文件夹」，保存完会自动打开那个文件夹（详见[保存与输出](/zh/guide/features/output)）。**导出的是窗口里现在这张表**——你改过的字、合并和拆分的结果都会带上。

### 什么样的表格识别得准

- 框线清晰、排版规整的表格最准，合并单元格也能还原；
- 没有框线的表格会按文字位置排出网格，合并关系需要你自己用「合并」补上；
- 深色主题、渐变、色块这类复杂底色会自动处理，但导出前建议还是核对一遍；
- 这个功能给你的是一份**能改的初稿**：文字、合并关系、列宽行高按原图来；字体、精确颜色、公式不还原。

### 这些情况要注意

- 表格至少要有 **2 行 2 列**才能成表；
- 斜线表头、表里套小表、竖排文字会被并格或摊平；
- 导出 Excel 时数字按文本写入，订单号、手机号、前导零都不会被吃掉；
- 表格歪了、被透视变形时，先截正再识别。

:::tip
框得越贴近表格边界、框线越清楚，越省事。复杂底色或倾斜的表格，导出前花半分钟核对一下最稳妥。
:::

## 三、扫二维码

框住二维码点一下按钮，内容就进剪贴板了，不弹结果窗。

### 截图时

1. 按 `F1`，框住二维码；
2. 点工具栏「二维码识别」（在 OCR 右侧、翻译之后）；
3. 成功后提示条会显示识别到的内容，截图界面随即收起——**直接粘贴即可**，后加的标注不会被算进去。

### 贴图窗口里

1. 点贴图工具栏的「二维码识别」，光标变成十字；
2. 拖一个框把二维码框进去，松手就复制好了；
3. 再点一次按钮或按 `Esc` 退出。框得太小不会识别，把整个二维码框进去就好。

### 用之前知道这几点

- 一个框里有**多个二维码**会全部识别，内容按行拼在一起，重复的只留一条；
- 只认 **QR 系列二维码**（含 Micro QR），条形码、DataMatrix 等不行；
- 复制的是原始文字：不会自动打开链接，也不会帮你解析 Wi-Fi 或名片；
- 很小的码会自动放大后再试；
- 识别失败会说明原因，且**不会覆盖**剪贴板里原有的内容；
- 如果安装包没带这个组件，点按钮会提示「当前构建未启用二维码识别」。

## 四、没达到预期时

| 你看到的情况 | 可以试试 |
| --- | --- |
| 第一次识别特别慢 | 首次使用要加载识别模型，之后就快了，一般无需干预 |
| 提示模型不可用 | 去「设置 → OCR 自检」点「一键自检」，或点「打开模型目录」检查文件，必要时重装 |
| 识别出来是乱码 | 模型目录里混进了旧版本文件，清理后重试 |
| 表格行列错乱、合并丢了 | 框得更贴近表格边界，导出前用「合并 / 拆分」修一下 |
| 二维码没解出来 | 确认是 QR 系列，把码框完整，少带周边内容 |
