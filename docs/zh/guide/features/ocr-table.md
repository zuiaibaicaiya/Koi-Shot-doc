# OCR 与表格识别

koiShot 内置**本地离线**识别引擎（PaddleOCR PP-OCRv6 + ONNX Runtime），识别所需模型随安装包一并提供，无需下载、无需联网——识别过程不上传图片。

若想确认识别环境状态，可在「设置 → 通用设置 → OCR 自检」中点击**一键自检**，也可点「打开模型目录」查看内置模型文件。

## 一、OCR 文字识别

1. 按 `F1` 截图并框选包含文字的区域；
2. 点击工具栏「OCR」按钮；
3. 稍等片刻，弹出**「OCR 识别结果」窗口**，左侧显示**行号**，右侧逐行显示文字；
4. 复制需要的文字：点「复制」复制全部，或**双击某一行只复制该行**（行号不会进入剪贴板）。

| 操作 | 效果 |
| --- | --- |
| 「复制」按钮 | 复制全部识别文本 |
| 双击某一行 | 只复制该行文字 |
| 关闭窗口按钮 / `Esc` | 关闭结果窗并释放本次结果（识别进行中关窗不会中断识别，结果回来时窗口会再次弹出） |
| 识别失败 | 系统托盘弹出气泡提示，可重试或框选更清晰的区域 |

**自动方向纠正**：文本行倒置（0°/180°）会逐行自动翻转；整张图被旋转 90°/270° 时会先整体纠正再识别。这些都自动完成，无需设置；对应模型缺失时会跳过，不影响其它识别。

适用场景：提取图片中的文字、复制不可选中的文本（弹窗提示、扫描件、视频字幕、PDF 截图）。

## 二、表格识别（截图转 Excel）

1. 按 `F1` 截图并框选表格区域（尽量只框表格本体）；
2. 点击工具栏「表格」按钮；
3. 弹出**「表格识别」窗口**，识别结果是一张**可编辑的网格**：

   - **双击单元格**即可修改文字；
   - 选中连续的多个单元格（至少 2 个）后点「**合并**」合成一个单元格；选中已合并的区域点「**拆分**」还原；
   - **低置信度**的格子会带浅色强调底，鼠标悬停提示「识别置信度 x，建议核对」；
4. 输出结果，任选一种：

   | 按钮 | 结果 |
   | --- | --- |
   | 复制 TSV | 整张表以 TSV 复制到剪贴板，粘贴进 Excel / WPS 会自动按列分格 |
   | 导出 Excel | 导出 `table_日期_时间.xlsx`，**保留真实的合并单元格** |
   | 导出 CSV | 导出 `table_日期_时间.csv`（UTF-8 BOM，Excel 打开不乱码） |

- 导出文件写入「设置 → 通用设置 → 保存路径」所在目录；开启「保存后打开文件夹」时会同时打开该目录（见[保存与输出](/zh/guide/features/output)）；
- **导出内容以窗口里当前的表格为准**：你改过的文字与合并 / 拆分结果都会带上，而不是原始识别结果。

### 识别原理与能力边界

表格还原按「谁更权威」依次尝试三条路径，任一条成表即停止：

1. **结构模型**（可选，默认关闭）：识别复杂表格结构，模型缺失时自动跳过；
2. **框线还原**（默认开启）：从像素里检出横竖框线，据此还原单元格与合并关系，对有线表格最准；
3. **几何还原**（兜底）：按文字位置聚类成行列，对无框线表格可用，但没有合并能力。

这个功能的定位是**给出一份可用的初稿**，三件事做到位：**文字、合并、尺寸**（导出的列宽行高按原图比例还原）。字体族 / 字号 / 精确颜色、公式语义重建、条件格式等不做。

::::tip
表格越规整、框线越清晰，识别越准。复杂底色（深色主题、渐变、色块）会先做背景归一化再检测框线，但仍建议导出前人工核对；倾斜、透视变形的表格请先截正。
::::

## 三、常见问题速查

| 现象 | 处理 |
| --- | --- |
| 识别很慢或首次特别慢 | 首次识别需加载模型，之后常驻；截图打开时会预热，一般无需干预 |
| 提示模型不可用 | 到「设置 → OCR 自检」点「一键自检」，或点「打开模型目录」检查文件是否完整，必要时重装 |
| OCR 出现乱码 | 只支持 PP-OCRv6 模型，模型目录里混入旧版本会明确报错，请清理后重试 |
| 表格行列错乱 / 合并丢失 | 重新框选更贴近表格边界，导出前用「合并 / 拆分」修正 |
