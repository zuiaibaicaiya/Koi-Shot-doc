# OCR 与表格识别

koiShot 内置**本地离线**识别引擎（PaddleOCR PP-OCRv6 + ONNX Runtime），识别所需模型随安装包一并提供，无需下载、无需联网——识别过程不上传图片。

若想确认识别环境状态，可在「设置 → 通用设置 → OCR 自检」中点击**一键自检**，也可点「打开模型目录」查看内置模型文件。

## 一、OCR 文字识别

1. 按 `F1` 截图并框选包含文字的区域；
2. 点击工具栏「OCR」按钮；
3. 稍等片刻，弹出**「OCR 识别结果」窗口**，左侧显示**行号**，右侧逐行显示文字；
4. 复制需要的文字：点「复制」复制全部，或**双击某一行只复制该行**（行号不会进入剪贴板）。

| 操作 | 效果 |
| --- | --- |
| 「复制」按钮 | 复制全部识别文本 |
| 双击某一行 | 只复制该行文字 |
| 关闭窗口按钮 / `Esc` | 关闭结果窗并释放本次结果（识别进行中关窗不会中断识别，结果回来时窗口会再次弹出） |
| 识别失败 | 系统托盘弹出气泡提示，可重试或框选更清晰的区域 |

**自动方向纠正（可选，默认关闭）**：koiShot 具备两类方向纠正能力——整张图被旋转 90°/270° 时先整体纠正再识别、文本行倒置（0°/180°）时逐行翻转，但对应的纠正模型**默认不随安装包提供**，缺失时自动跳过、不影响常规识别。桌面截图内容基本都是正向的，通常无需关心。

适用场景：提取图片中的文字、复制不可选中的文本（弹窗提示、扫描件、视频字幕、PDF 截图）。

需要**读懂外文**而不只是取出原文时，用工具栏「翻译」：它复用同一套本地 OCR，再把文字交给阿里云机器翻译，结果窗左图右文对照（见[截图翻译](/zh/guide/features/translate)）。

## 二、表格识别（截图转 Excel）

1. 按 `F1` 截图并框选表格区域（尽量只框表格本体）；
2. 点击工具栏「表格」按钮；
3. 弹出**「表格识别」窗口**，识别结果是一张**可编辑的网格**：

   - **双击单元格**即可修改文字；列头显示 **A / B / C** 等 Excel 列名，与导出后的表格一一对应；
   - 选中连续的多个单元格（至少 2 个）后点「**合并**」合成一个单元格；选中已合并的区域点「**拆分**」还原。**合并操作没有撤销**：格内文字会全部拼接保留在左上角，合并前请确认；
   - **低置信度**的格子会带浅色强调底，鼠标悬停提示「识别置信度 x，建议核对」；低置信度按格内**最不确定的一处**判定，你手动改过或填过的格子不再标记。
4. 输出结果，任选一种：

   | 按钮 | 结果 |
   | --- | --- |
   | 复制 TSV | 整张表以 TSV 复制到剪贴板，粘贴进 Excel / WPS 会自动按列分格 |
   | 导出 Excel | 导出 `table_日期_时间.xlsx`，**保留真实的合并单元格** |
   | 导出 CSV | 导出 `table_日期_时间.csv`（UTF-8 BOM，Excel 打开不乱码） |

- 导出文件写入「设置 → 通用设置 → 保存路径」所在目录；开启「保存后打开文件夹」时会同时打开该目录（见[保存与输出](/zh/guide/features/output)）；
- **导出内容以窗口里当前的表格为准**：你改过的文字与合并 / 拆分结果都会带上，而不是原始识别结果。

### 识别原理与能力边界

表格还原按「谁更权威」依次尝试三条路径，任一条成表即停止：

1. **结构模型**（可选，默认关闭）：识别复杂表格结构，模型缺失时自动跳过；
2. **框线还原**（默认开启）：从像素里检出横竖框线，据此还原单元格与合并关系，对有线表格最准；
3. **几何还原**（兜底）：按文字位置聚类成行列，对无框线表格可用，但没有合并能力。

这个功能的定位是**给出一份可用的初稿**，三件事做到位：**文字、合并、尺寸**（导出的列宽行高按原图比例还原，100% 缩放下与原图同尺寸）。字体族 / 字号 / 精确颜色、公式语义重建、条件格式等不做。

### 已知边界

- 表格**至少 2 行 2 列**才能成表（行数列数没有上限）；
- 不支持斜线表头、嵌套子表格与竖排文字（会并格 / 摊平）；
- 深色主题表格、低对比度框线（如白线配浅黄底）可能检不出框线，静默退回按文字位置还原——无框线表格拿不到合并信息，需手动合并；
- 导出 Excel 时**数字一律按文本写入**：订单号、手机号、前导零不会被 Excel 吃掉；能明确读出的千分位 / 百分号 / 货币 / 日期才会转为数值。

:::tip
表格越规整、框线越清晰，识别越准。复杂底色（深色主题、渐变、色块）会先做背景归一化再检测框线，但仍建议导出前人工核对；倾斜、透视变形的表格请先截正。
:::

## 三、二维码识别

识别选区内的二维码并把内容**直接复制到剪贴板**，不弹结果窗。

### 截图时使用

1. 按 `F1` 截图并框选包含二维码的区域；
2. 点击工具栏「二维码识别」按钮（OCR 右侧、翻译之后）；
3. 解码的是**框选时的原图**（不含后加的标注）；成功后提示条短暂显示识别到的内容，随后截图浮层自动收起，内容已在剪贴板。

### 贴图窗口使用

1. 在贴图工具栏点「二维码识别」，进入框选模式（光标变十字）；
2. 拖一个矩形框住二维码，松手即解码并复制；
3. 再点一次按钮或按 `Esc` 可退出框选模式；拖动距离太短视为误触，不识别。

### 行为与限制

- 选区内有**多个二维码**时全部识别，内容按行拼接复制，并提示识别到的个数；重复内容只保留一条；
- 只识别 **QR 系列二维码**（含 Micro QR / Rectangle QR）；一维条形码与 DataMatrix / Aztec / PDF417 不支持；
- 内容按**原始文本**复制：不会解析网址、Wi-Fi 或名片信息，也不会自动打开链接；
- 很小的二维码会自动放大后再识别；
- 失败时显示原因提示，且**不会覆盖**剪贴板原有内容；
- 若安装包未包含识别组件，按钮仍在，点击会提示「当前构建未启用二维码识别」。

## 四、常见问题速查

| 现象 | 处理 |
| --- | --- |
| 识别很慢或首次特别慢 | 首次识别需加载模型，之后常驻；截图打开时会预热，一般无需干预 |
| 提示模型不可用 | 到「设置 → OCR 自检」点「一键自检」，或点「打开模型目录」检查文件是否完整，必要时重装 |
| OCR 出现乱码 | 只支持 PP-OCRv6 模型，模型目录里混入旧版本会明确报错，请清理后重试 |
| 表格行列错乱 / 合并丢失 | 重新框选更贴近表格边界，导出前用「合并 / 拆分」修正 |
| 二维码没解出来 | 确认是 QR 系列二维码（不支持条形码 / DataMatrix 等）；框选时框完整一点，避免带入过多周边内容 |
