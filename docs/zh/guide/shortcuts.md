# 快捷键总表

## 全局快捷键

在任何应用前台时均可触发（可在「设置 → 快捷键设置」中修改）：

| 快捷键 | 动作 |
| --- | --- |
| `F1` | 截图 |
| `Alt + S` | 截图并保存 |
| `Alt + P` | 贴图到桌面 |
| `Alt + Q` | 显示 / 隐藏主窗口 |

## 截图过程中

| 按键 | 动作 |
| --- | --- |
| 拖拽 | 框选截图区域 |
| `Shift` + 拖拽 | 正方形选区 |
| 单击 | 选中高亮的界面控件 |
| `Enter` | 执行默认动作（复制 / 保存 / 贴图，取决于截图入口） |
| `Esc` | 取消截图 / 放弃文字编辑 |
| `Ctrl + Z` | 撤销标注 |
| `Ctrl + Shift + Z` | 重做标注 |

macOS 上 `Ctrl` 对应 `Cmd`。

## 文字标注编辑中

| 按键 | 动作 |
| --- | --- |
| `Enter` | 文字换行 |
| `Ctrl + Enter` | 提交文字 |
| `Esc` | 放弃本次编辑 |
| 滚轮 | 调整笔画粗细 |

## 贴图窗口中

| 操作 | 动作 |
| --- | --- |
| 拖动 | 移动贴图 |
| 滚轮 | 缩放（0.3–4.0 倍） |
| `Alt` + 滚轮 | 调节透明度（5%–100%） |

:::tip
所有全局快捷键都可在设置中改键并即时生效；若提示冲突，说明该组合已被其他功能或软件占用。
:::
