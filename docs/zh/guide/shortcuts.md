# 快捷键总表

按场景查按键：想截哪张图、截图过程里怎么操作、贴图窗口和结果窗里能按什么。下面的**全局快捷键在任何软件里都能用**，也都能在「设置 → 快捷键设置」里改成顺手的组合。

## 全局快捷键

在任何应用前台时均可触发（可在「设置 → 快捷键设置」中修改，改键说明见[设置与托盘](/zh/guide/settings#快捷键设置)）：

| 快捷键 | 动作 |
| --- | --- |
| `F1` | 截图（默认动作：复制） |
| `Alt + S` | 截图并保存（框选松手即保存） |
| `Alt + P` | 贴图到桌面（框选松手即贴图） |
| `Alt + Q` | 显示 / 隐藏截图界面（再次按下即取消） |
| `Alt + R` | 框选录屏（MP4，框选松手即出录制条） |

## 截图过程中

| 按键 / 操作 | 动作 |
| --- | --- |
| 拖拽 | 框选截图区域 |
| `Shift` + 拖拽 | 正方形选区（中途切换实时生效） |
| 画的过程中按住 `Shift` 拖（画笔 / 荧光笔） | 从当前笔尖画水平或垂直直线，方向锁定；松开 `Shift` 继续自由画 |
| 单击 | 选中高亮的界面控件 |
| 拖动选区内部 | 移动选区 |
| `Enter` | 执行当前默认动作（复制 / 保存 / 贴图 / 录屏，取决于截图入口） |
| `Esc` | 取消截图 / 关闭属性弹窗 / 放弃文字编辑 |
| `Ctrl + Z` | 撤销标注 |
| `Ctrl + Shift + Z`（Windows 也可用 `Ctrl + Y`） | 重做标注 |
| 滚轮（指针在选中的标注上） | 调整该标注的粗细 / 大小 |

macOS 上 `Ctrl` 对应 `Cmd`。

## 文字标注编辑中

| 按键 | 动作 |
| --- | --- |
| `Enter` | 换行 |
| `Ctrl + Enter`（macOS `Cmd + Enter`） | 提交文字 |
| `Esc` | 放弃本次编辑（改字时还原为原文） |
| 滚轮 | 调整字号 |

输入过程中点画布别处、点属性弹窗色块、切换工具都不会丢字（只有 `Esc` 丢弃）。

## 贴图窗口中

| 操作 | 动作 |
| --- | --- |
| 拖动 | 移动贴图 |
| 滚轮 | 缩放（0.3–4.0 倍） |
| `Alt` + 滚轮 | 调节透明度（5%–100%；文字输入中不生效） |
| `Ctrl + Z` / `Ctrl + Shift + Z`（Windows 也可用 `Ctrl + Y`） | 撤销 / 重做标注 |
| `Esc` / `Ctrl + W`（macOS `Cmd + W`） | 关闭贴图（文字编辑或二维码框选中 `Esc` 先退出当前模式） |
| 未选工具时拖过文字 | 框选识别文字并复制到剪贴板 |
| 「二维码识别」→ 拖矩形 | 解码二维码并复制到剪贴板（再点按钮或 `Esc` 取消） |

## 长截图 / GIF / 录屏录制中

| 按键 / 操作 | 动作 |
| --- | --- |
| `Esc` | 长截图录制中 = 停止并出图；GIF / 录屏 = 取消录制（已捕获帧丢弃）；GIF / 录屏待开始态 = 取消本次 |
| 控制条 / 录制条按钮 | 长截图：开始 ▶ / 完成 ✓ / 取消 ✕；GIF 与录屏需先点「开始录制」确认，录制中另有暂停 ❚❚ / 继续 ▶（仅录屏）。按钮都是图标，悬停显示名称 |
| 录制条帧率下拉（GIF / 录屏待开始态） | 直接调整帧率，开录后锁定 |
| 按住选区内部拖动（待开始态） | 平移录制范围（只移动、不缩放，不能移出当前屏幕；长截图待开始态同样适用） |

## 结果窗口

| 按键 / 操作 | 动作 |
| --- | --- |
| `Esc` | 关闭 OCR / 表格识别 / 翻译结果窗 |
| 双击某一行（OCR） | 只复制该行文字 |
| 滚轮（翻译结果窗左侧原图） | 缩放原图（100%–800%） |
| 右键拖动（放大后的原图） | 平移原图 |
| 右键译文（翻译结果窗） | 复制选中 / 复制全部译文 / 全选 |
| 底部「翻译为」下拉 | 切换目标语言并按新语言重翻 |

:::tip
所有全局快捷键都可在设置中改键并即时生效；若提示冲突，说明该组合已被其他功能或软件占用。
:::
